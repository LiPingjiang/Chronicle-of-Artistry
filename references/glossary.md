# 术语表 | Glossary

| 术语 | 英文 | 释义 |
|------|------|------|
| 透视法 | Perspective | 在二维平面上表现三维空间深度的技法 |
| 明暗对比 | Chiaroscuro | 利用强烈的明暗对比营造立体感和戏剧性 |
| 正面律 | Frontality | 古埃及艺术中人物头部侧面、身体正面的固定表现方式 |
| 构图 | Composition | 画面中各元素的组织与安排 |
| 笔触 | Brushstroke | 画笔在画面上留下的痕迹 |
| 色域 | Color Field | 大面积平涂单一色彩的绘画方式 |
| 现成品 | Ready-made | 杜尚提出，将日常物品直接作为艺术品展示 |
| 拼贴 | Collage | 将不同材料粘贴组合成画面 |
| 行动绘画 | Action Painting | 强调创作过程中身体动作的绘画方式 |
| 留白 | Negative Space | 中国画中有意留出的空白，以虚代实 |
| 写意 | Freehand | 中国画中不拘形似、重在神韵的画法 |
| 工笔 | Meticulous | 中国画中精细描绘、设色工整的画法 |
| 浮世绘 | Ukiyo-e | 日本江户时代的木版画，描绘世俗生活 |
| 侘寂 | Wabi-sabi | 日本美学概念，欣赏不完美与无常之美 |
| 点彩法 | Pointillism | 用细小色点并置，利用视觉混色原理 |
| 自动书写 | Automatism | 超现实主义技法，绕过理性直接表达潜意识 |
| 挪用 | Appropriation | 后现代手法，借用已有图像/作品重新语境化 |
| 沉浸式 | Immersive | 让观众身处作品之中的体验方式 |
