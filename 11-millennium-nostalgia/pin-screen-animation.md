# Pin Screen Animation 针幕动画

> **时期：** 1930年代–至今  
> **关键词：** 针板装置、光影浮雕、半色调效果、触觉雕塑、实验动画

## 概述

Pin Screen Animation（针幕动画）是亚历山大·阿列克谢耶夫于1930年代发明的独特动画技术。装置由数十万根可推拉的细针组成，通过调整针的突出程度，在侧光照射下产生不同的阴影效果，创造出类似铜版画的精细灰度图像。这种技术极其耗时，全世界仅有极少数艺术家掌握。

## 风格特征

- **半色调效果**：针的阴影创造的连续灰度
- **铜版画质感**：类似蚀刻版画的精细纹理
- **光影雕塑**：通过光线角度改变画面效果
- **梦幻氛围**：柔和朦胧的视觉特质
- **不可复制**：每一帧都是独一无二的物理状态
