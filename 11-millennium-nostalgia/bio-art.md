# Bio Art 生物艺术

> "Art that literally lives and breathes." — Eduardo Kac

## 概述

生物艺术（Bio Art / Bioart）是以活的生物体、生物技术和生命科学为媒介的艺术创作。艺术家使用细胞培养、基因工程、组织工程、微生物、植物生长等生物过程作为创作手段，创造活的、生长的、有时会死亡的艺术品。

从Eduardo Kac的荧光兔到Stelarc的体内雕塑、从组织培养的"无害皮革"到用细菌绘制的"活画"，生物艺术模糊了生命与非生命、自然与人工、科学与艺术的边界。

## 核心特征

| 特征 | 描述 |
|------|------|
| 活的媒介 | 使用活的生物体作为艺术材料 |
| 生物技术 | 运用基因工程、细胞培养等技术 |
| 生长性 | 作品会生长、变化、最终死亡 |
| 伦理挑战 | 引发关于生命操控的伦理讨论 |
| 跨学科 | 艺术家与科学家的深度合作 |
| 实验室 | 实验室成为艺术工作室 |

## 视觉特征

- **活体**：细胞、细菌、真菌、植物——活的材料
- **生长**：作品随时间生长和变化
- **微观**：显微镜下的美——细胞、DNA
- **培养皿**：实验室器具成为展示容器
- **荧光**：GFP（绿色荧光蛋白）的发光
- **有机**：不规则的、有机的、生命的形态

| 微生物艺术 | 细菌、真菌作为绘画媒介 |

| 生态艺术 | 生物修复和生态系统作为艺术 |

## 中国语境

生物艺术在中国是一个新兴但快速发展的领域。中央美术学院等设立了生物艺术相关课程。中国艺术家如梁绍基（蚕丝）长期使用活的生物体创作。中国的合成生物学研究实力为生物艺术提供了技术基础。然而，中国的生物艺术也面临伦理审查和公众接受度的挑战。中国传统的"天人合一"哲学为生物艺术提供了独特的文化语境。

## 与其他风格的关系

- **New Media Art** → 新媒体艺术的技术实验精神延伸到生物领域
- **Conceptual Art** → 概念艺术的观念性为生物艺术提供理论框架
- **Environmental Art** → 环境艺术的生态关注与生物艺术交叉
- **Body Art** → 身体艺术的身体改造在生物艺术中延续
- **Data Art** → 基因数据可视化连接数据艺术与生物艺术
- **Science Art** → 科学艺术是生物艺术的上位类别
