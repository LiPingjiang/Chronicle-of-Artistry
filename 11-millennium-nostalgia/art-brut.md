# Art Brut 原生艺术

![Art Brut 概念图](../assets/artworks/art-brut/art-brut-concept-01.png)

> **"没有学过画的人——画出了最真实的东西。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1945–至今（命名）/创作本身无时间限制 |
| 别名 | Art Brut, Outsider Art, Raw Art, 原生艺术, 素人艺术 |
| 核心色彩 | 无规则——本能的色彩选择、强烈对比 |
| 关键元素 | 未受训练、强迫性重复、密集填充、本能表达 |
| 代表人物 | Adolf Wölfli, Henry Darger, Aloïse Corbaz, 郭凤怡 |
| 关联风格 | Naive Art, Neo-Expressionism, Graffiti, Folk Art |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1922 | Hans Prinzhorn《精神病患者的艺术》出版 |
| 1945 | Jean Dubuffet命名"Art Brut" |
| 1948 | Dubuffet创立Art Brut协会 |
| 1972 | Roger Cardinal命名"Outsider Art" |
| 1976 | Collection de l'Art Brut在洛桑开馆 |
| 2000s | Art Brut进入主流艺术市场 |

### 核心哲学

原生艺术的精神是**"真正的创造力不需要学校——它来自内心的必然"**：
- Dubuffet："文化艺术是窒息的——Art Brut是呼吸的"
- "没有规则 = 没有限制 = 最大的自由"
- "强迫性的创作——不是选择，是必须"
- "这些人不知道'艺术'是什么——所以他们创造了真正的艺术"
- "Art Brut不是'差'的艺术——是'不同'的艺术"

## 视觉语法

### 特征系统

```
视觉特征：
  密集填充 — 恐惧空白(horror vacui)
  强迫重复 — 图案、符号、文字
  扭曲比例 — 非学院的人体
  强烈色彩 — 本能选择、不和谐
  混合媒介 — 任何可用材料

创作者类型：
  精神病患者 — 幻觉、内在世界
  自学者 — 孤立、执着
  灵媒 — 通灵绘画
  囚犯 — 封闭环境的创造力
  儿童 — 未被训练的纯真

规则（没有规则）：
  - 未受过艺术训练
  - 不为市场创作
  - 不受艺术史影响
  - 出于内在需要
  - 通常在社会边缘
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 填充 | 密集、强迫、无空白 |
| 重复 | 图案、符号、数字、文字 |
| 人物 | 扭曲、简化、符号化 |
| 材料 | 任何可得——铅笔、蜡笔、面包、泥土 |
| 空间 | 无透视、平面、多视点 |
| 态度 | 本能、强迫、孤独、纯粹 |

## 与千禧怀旧/当代的关系

### Art Brut的市场化悖论
- Art Brut进入画廊 = 违背了它的定义？
- "当Outsider变成Insider——它还是Art Brut吗？"
- 当代艺术市场对"原始性"的渴望

### 对当代艺术的影响
- Basquiat = Art Brut + 街头 + 画廊
- 当代"坏画"(Bad Painting) = Art Brut精神
- AI艺术 vs Art Brut = "未受训练"的两种含义
