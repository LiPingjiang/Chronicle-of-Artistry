# Cyberpunk 赛博朋克

![Cyberpunk 概念图](../assets/artworks/cyberpunk/cyberpunk-concept-01.png)

> **"高科技，低生活——霓虹雨夜中的义体改造人，在巨型企业的阴影下求生。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1980s 文学起源 / 持续至今 |
| 别名 | Cyberpunk, High Tech Low Life, Neon Noir |
| 核心色彩 | 霓虹粉、电光蓝、紫色、黑色、铬银 |
| 关键元素 | 霓虹招牌、义体改造、巨型企业、雨夜城市 |
| 代表人物 | William Gibson、Ridley Scott、CD Projekt Red |
| 关联风格 | Synthwave, Vaporwave, Dark Y2K, Chromecore |

## 历史脉络

### 1980s：文学运动

| 作品 | 年份 | 贡献 |
|------|------|------|
| 《Neuromancer》 | 1984 | 定义了赛博空间概念 |
| 《Blade Runner》 | 1982 | 定义了赛博朋克视觉 |
| 《Akira》 | 1988 | 日本赛博朋克的巅峰 |
| 《Ghost in the Shell》 | 1995 | 义体与意识的哲学 |
| 《The Matrix》 | 1999 | 将赛博朋克带入主流 |

### 2010s–2020s：游戏与流行文化

| 作品 | 年份 | 贡献 |
|------|------|------|
| 《Cyberpunk 2077》 | 2020 | 开放世界赛博朋克 |
| 《Blade Runner 2049》 | 2017 | 视觉美学的新高度 |
| 《Cyberpunk: Edgerunners》 | 2022 | 动画赛博朋克 |
| 《Altered Carbon》 | 2018 | 义体交换的世界观 |

### 核心世界观

Cyberpunk 的核心矛盾是**"高科技，低生活"**：
- 技术极度发达，但社会极度不平等
- 巨型企业控制一切，政府形同虚设
- 个人通过技术（黑客、义体）对抗系统
- 城市是美丽的（霓虹）也是肮脏的（贫民窟）

## 视觉语法

### 色彩系统

```
主色：
  霓虹粉 (#FF1493) — 招牌、灯光
  电光蓝 (#00BFFF) — 全息投影、界面
  紫色 (#8B008B) — 夜空、氛围
  黑色 (#000000) — 暗影、服装
  铬银 (#C0C0C0) — 义体、金属

辅色：
  霓虹绿 (#39FF14) — 黑客终端
  橙色 (#FF4500) — 警告、爆炸
  白色 (#FFFFFF) — 全息文字

质感：
  霓虹灯 — 城市照明
  雨水 — 反射、氛围
  金属/铬 — 义体、建筑
  全息 — 广告、界面
  电路板 — 技术纹理
```

## 与千禧怀旧的关系

### 《The Matrix》的千禧记忆
- 1999年上映 = Y2K 时代的标志性电影
- 黑色皮衣+墨镜 = 千禧一代的童年记忆
- "红色药丸还是蓝色药丸" = 文化基因

### 从幻想到现实
- 1980s 的赛博朋克是"警告"
- 2020s 我们发现自己已经生活在赛博朋克世界中
- 巨型科技公司、监控、AI、社交媒体成瘾
- "赛博朋克不是未来，是现在"
