# Mythpunk 神话朋克

![Mythpunk 概念图](../assets/artworks/mythpunk/mythpunk-concept-01.png)

> **"古老的神话被拆解、重组、颠覆——用朋克的态度重写众神的故事。"**

## 历史脉络

| 年份 | 事件 |
|------|------|
| 2006 | Catherynne M. Valente在博客上创造"Mythpunk"一词 |
| 2006 | Valente《迷宫》(The Labyrinth)——Mythpunk文学原型 |
| 2011 | Madeline Miller《阿喀琉斯之歌》——Mythpunk的大众化 |
| 2018 | Miller《喀耳刻》——Mythpunk的商业巅峰 |
| 2020s | Mythpunk从文学扩展到游戏和视觉艺术 |

### 核心哲学

Mythpunk的精神是**"神话不是死的文本——它是活的、可以被重写的、应该被颠覆的"**：
- Valente："Mythpunk = 用朋克的态度对待神话——拆解、重组、颠覆"
- "谁的故事被讲述？谁的声音被沉默？"
- "美杜莎的视角 > 珀尔修斯的视角"
- "混合不同神话体系——希腊+北欧+日本+非洲"
- "神话是第一个虚拟现实——我们可以hack它"

## 视觉语法

### 色彩系统

```
主色：
  古金 (#B8860B) — 神话、永恒
  血红 (#8B0000) — 牺牲、力量
  森林绿 (#228B22) — 自然、精灵
  星空紫 (#4B0082) — 神秘、神圣

辅色：
  骨白 (#FFF8DC) — 古老、死亡
  海蓝 (#006994) — 深海、怪物
  火焰橙 (#FF4500) — 变形、力量

视觉特征：
  混合时代 — 古代+当代元素并置
  变形/流动 — 人→动物→神的转化
  装饰性 — 凯尔特结、希腊回纹、北欧符文
  自然力量 — 藤蔓、火焰、水流、星辰
  女性力量 — 女神、女巫、女战士

规则：
  - 古老 + 当代 = 并置
  - 多神话体系混合
  - 边缘视角 > 英雄视角
  - 装饰性 + 野性
  - 变形是核心视觉主题
```

## 与千禧怀旧/当代的关系

### "BookTok神话重述"热潮
- 2020s TikTok上的神话重述小说热 = Mythpunk的大众化
- Madeline Miller、Circe、Ariadne = Mythpunk进入主流
- "从怪物的视角讲故事" = 当代读者的需求

### 与Dark Fantasy的区别
- Dark Fantasy = 原创暗黑世界观
- Mythpunk = 重写已有的神话
- 两者可以重叠——但Mythpunk必须有"源文本"
