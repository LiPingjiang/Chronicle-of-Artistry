# Wycinanki 波兰剪纸 | Wycinanki Polskie

> **"一把剪刀，一张纸——波兰农妇用对折和剪裁创造出春天的花园。"**

## 概述

Wycinanki（波兰剪纸 / 维奇南基）是波兰传统的民间剪纸艺术，起源于19世纪波兰农村。最初是贫穷的农家妇女用来装饰白色墙壁和天花板横梁的廉价替代品——代替昂贵的壁纸和绘画。不同地区发展出独特的风格：Łowicz地区的多层彩色剪纸最为华丽，Kurpie地区的单色对称剪纸最为精致。Wycinanki通常在春天制作，用来装饰复活节期间的房屋。

## 主要地区风格

| 地区 | 特征 |
|------|------|
| Łowicz | 多层彩色，公鸡和花卉，最华丽 |
| Kurpie | 单色（通常黑色），对称，极精细 |
| Lublin | 对称树形，生命之树 |
| Podlasie | 几何化，星形和圆形 |

## 核心特征

- **对折剪裁**：纸张对折后剪裁，展开后自然对称
- **多层叠加**：Łowicz风格用多层彩纸叠加
- **公鸡母题**：最经典的Wycinanki形象
- **花卉图案**：程式化的花朵和叶片
- **生命之树**：中心树形向两侧展开
- **季节性**：春天制作，装饰复活节

## 常见母题

| 母题 | 含义 |
|------|------|
| 公鸡 Kogut | 警觉、新的一天 |
| 花卉 | 春天、生命、美丽 |
| 生命之树 | 家族、生命循环 |
| 星形 | 宇宙、神圣 |
| 鸟类 | 自由、灵魂 |
| 几何圆形 | 太阳、完整 |

## 视觉特征

- 严格的对称构图
- 鲜艳的多色层叠（Łowicz）
- 精细的剪裁细节
- 平面化的装饰性
- 正负空间的精妙平衡
- 纸张的轻盈质感

## 与其他风格的关系

| 风格 | 关系 |

| 乌克兰Petrykivka | 共享东欧民间花卉传统 |
