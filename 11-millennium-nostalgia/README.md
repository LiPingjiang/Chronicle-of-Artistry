## 为什么单独成章？

这些风格诞生于互联网时代，以"怀旧"为核心情感驱动力，横跨音乐、视觉设计、时尚、游戏等领域。它们不属于传统美术史的线性叙事，却是当代视觉文化中最具辨识度和影响力的美学运动。它们共享以下特征：

- **时间错位**：用当代技术重构过去的视觉记忆
- **互联网原生**：诞生并传播于网络社区
- **跨媒介**：同时覆盖音乐、平面、时尚、空间
- **情感驱动**：怀旧、乐观、迷幻、疏离
