# Pixel Art 像素艺术

> "Pixel art is the art of limitation — creating beauty within the smallest possible grid." — eBoy

## 概述

像素艺术（Pixel Art）是以单个像素为基本单位、在低分辨率网格上逐像素创作的数字艺术形式。起源于1970-80年代电子游戏和早期计算机图形的技术限制，像素艺术在技术进步后不再是必需，却作为一种独立的美学风格存续至今——它的魅力在于用最少的信息传达最多的内容。

像素艺术是"少即是多"的极致体现——每一个像素都是经过深思熟虑的设计决策。

## 核心特征

| 特征 | 描述 |
|------|------|
| 像素级 | 以单个像素为创作单位 |
| 低分辨率 | 在有限的网格中创作 |
| 限制美学 | 有限的颜色和分辨率 |
| 精确性 | 每个像素都经过精心放置 |
| 怀旧感 | 唤起早期游戏的记忆 |
| 可读性 | 在极小尺寸下保持可辨识 |

## 视觉特征

- **网格**：可见的像素网格结构
- **锯齿**：像素的阶梯状边缘
- **有限色板**：通常使用有限的颜色数量
- **抖动**：用像素模式模拟渐变
- **清晰**：每个像素边界清晰
- **图标性**：高度简化的图形符号

## 中国语境

像素艺术在中国有活跃的社区——从独立游戏开发到像素插画，从像素风格的表情包到像素艺术展览。中国的独立游戏如《太吾绘卷》等使用像素风格。中国的像素艺术家在国际像素艺术社区中也有一定影响力。像素风格在中国的"复古"和"怀旧"文化中占有一席之地。

## 与其他风格的关系

- **Digital Art** → 像素艺术是最早的数字艺术形式之一
- **Minimalism** → 像素的限制与极简精神相通
- **Pop Art** → 像素艺术的大众文化属性
- **Mosaic Art** → 马赛克与像素共享网格逻辑
- **Pointillism** → 点彩派的点与像素有视觉相似性
- **Crypto Art** → CryptoPunks等NFT项目使用像素风格
