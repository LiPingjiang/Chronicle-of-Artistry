# Keith Haring 凯斯·哈林

> "Art is for everybody." — Keith Haring

## 概述

凯斯·哈林（Keith Haring，1958–1990）是美国波普艺术家和社会活动家，以简洁的粗线条人物和符号闻名。他从纽约地铁的粉笔画起步，用跳舞的小人、吠叫的狗和放射线创造了一种人人可读的视觉语言，将艺术从画廊带到街头、T恤和公共空间，传达爱、包容和社会正义的信息。

## 核心特征

| 特征 | 描述 |
|------|------|
| 粗线条人物 | 简化的跳舞小人 |
| 放射线 | 能量辐射的动态线条 |
| 吠叫的狗 | 标志性的动物符号 |
| 婴儿爬行 | Radiant Baby的标志 |
| 公共艺术 | 地铁、墙壁、T恤 |
| 社会信息 | 反种族歧视、反艾滋 |

## 代表作品

| 作品 | 年代 | 意义 |
|------|------|------|
| *Radiant Baby* | 1982 | 最具辨识度的符号 |
| *Crack is Wack* | 1986 | 公共健康的街头宣言 |
| *Tuttomondo* | 1989 | 比萨的永久壁画 |
| *Subway Drawings* | 1980–85 | 地铁粉笔画的民主艺术 |
