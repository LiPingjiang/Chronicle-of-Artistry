# Techwear 机能风

![Techwear 概念图](../assets/artworks/techwear/techwear-concept-01.png)

> **"防水面料、磁吸扣、模块化口袋——当服装变成可穿戴的建筑。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2010s–至今 |
| 别名 | Techwear, Technical Wear, Urban Ninja |
| 核心色彩 | 黑色、深灰、橄榄绿、偶尔荧光点缀 |
| 关键元素 | Gore-Tex、磁吸扣、模块化系统、多口袋、束带 |
| 代表人物 | ACRONYM、Stone Island Shadow Project、Nike ACG |
| 关联风格 | Gorpcore, Cyberpunk, Darkwear, Utility |

## 历史脉络

### 从功能到美学

| 年份 | 事件 |
|------|------|
| 1990s | Stone Island 开始探索技术面料 |
| 2002 | Errolson Hugh 创立 ACRONYM |
| 2010s | Techwear 从小众走向互联网社区 |
| 2017 | r/techwearclothing 社区壮大 |
| 2019 | 《死亡搁浅》游戏推动美学主流化 |
| 2020s | 从纯黑走向多元化表达 |

### 它追求什么？

| 传统服装 | Techwear |
|---------|----------|
| 装饰性 | 功能性 |
| 季节性 | 全天候 |
| 固定结构 | 模块化 |
| 被动穿着 | 主动交互 |
| 面料是载体 | 面料是技术 |

### 核心哲学

Techwear 的精神是**"为未来的城市环境做准备"**：
- 服装是工具，不是装饰
- 每个口袋、每条拉链都有存在的理由
- 防水、透气、耐用是基本要求
- 模块化 = 适应性
- "城市忍者"——在混凝土丛林中自如移动

## 视觉语法

### 色彩系统

```
主色：
  黑色 (#000000) — 绝对主角
  深灰 (#333333) — 层次
  橄榄绿 (#556B2F) — 军事遗产
  炭灰 (#36454F) — 技术感

辅色（点缀）：
  荧光绿 (#39FF14) — 可见性
  荧光橙 (#FF6600) — 警示
  白色 (#FFFFFF) — 对比

规则：
  - 黑色为主（90%+）
  - 色彩只用于功能标识
  - 材质差异创造层次（哑光vs光泽）
  - 反光条作为设计元素

质感：
  Gore-Tex — 防水、哑光
  尼龙 — 轻量、耐磨
  Schoeller — 弹力、防水
  网眼 — 透气、层次
  3M反光 — 夜间可见
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 外套 | 硬壳冲锋衣、模块化夹克 |
| 裤装 | 束脚裤、多口袋工装裤、防水裤 |
| 鞋 | Nike ACG、Salomon、防水靴 |
| 包 | 胸包、模块化背包、MOLLE系统 |
| 配件 | 磁吸扣、束带、面罩、手套 |
| 细节 | 热压接缝、止水拉链、激光切割 |

## 与千禧怀旧的关系

### 赛博朋克的现实版
- Cyberpunk 是虚构的未来城市
- Techwear 是"现在就可以穿的赛博朋克"
- 两者共享"城市生存"的叙事
- 但 Techwear 更务实、更可穿

### 与 Gorpcore 的区别
| Techwear | Gorpcore |
|----------|----------|
| 城市 | 户外 |
| 黑色 | 自然色 |
| 未来感 | 功能感 |
| ACRONYM | Arc'teryx |
| 设计驱动 | 品牌驱动 |
| 贵 | 也贵 |
