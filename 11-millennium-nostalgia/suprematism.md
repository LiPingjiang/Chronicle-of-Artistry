# Suprematism 至上主义

![Suprematism 概念图](../assets/artworks/suprematism/suprematism-concept-01.png)

> **"黑色方块在白色背景上——这就是一切——纯粹的感觉、纯粹的形式、纯粹的无。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1913–1930s/影响至今 |
| 别名 | Suprematism, 至上主义 |
| 核心色彩 | 黑、白、红——最基本的色彩 |
| 关键元素 | 纯几何形（方、圆、十字）、白色空间、无物象、纯粹感觉 |
| 代表人物 | Kazimir Malevich, El Lissitzky, Olga Rozanova |
| 关联风格 | Constructivism, De Stijl, Minimalism, Bauhaus, Abstract Art |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1913 | Malevich 设计歌剧《太阳的征服》——至上主义萌芽 |
| 1915 | 《黑色方块》展出——至上主义宣言 |
| 1918 | 《白上白》——至上主义的极致 |
| 1920s | El Lissitzky 将至上主义带入设计 |
| 1930s | 苏联社会主义现实主义压制至上主义 |
| 2020s | 至上主义精神在极简设计中延续 |

### 核心哲学

至上主义的精神是**"艺术的最高形式 = 纯粹的感觉——不需要任何物象"**：
- 纯粹 = 至上（"方块不代表任何东西——它就是它自己"）
- 无物象 = 自由（"不画苹果、不画人——画纯粹的形式"）
- 感觉 = 一切（"黑色方块 = 感觉的至上"）
- 零 = 开始（"从零开始——在零之后重建一切"）
- Malevich: "我把自己变成了形式的零——从零之外拉出了创造"

## 视觉语法

### 色彩系统

```
核心三色：
  黑色 (#000000) — 绝对、虚无
  白色 (#FFFFFF) — 无限、空间
  红色 (#FF0000) — 能量、革命

辅色：
  黄色 (#FFFF00) — 光
  蓝色 (#0000FF) — 深度
  绿色 (#00FF00) — 偶尔

规则：
  - 最少的颜色
  - 纯色、平涂
  - 白色 = 无限空间
  - 色彩 = 纯粹感觉

质感：
  平涂 — 无笔触
  几何 — 精确边缘
  漂浮 — 无重力
  纯净 — 无装饰
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 形状 | 方块、圆、十字、三角、线 |
| 空间 | 白色无限空间、漂浮、无重力 |
| 构图 | 动态平衡、对角线、不对称 |
| 态度 | 纯粹、绝对、革命、哲学、极端 |
| 精神 | 无物象、纯感觉、零度、至上 |
| 遗产 | → Minimalism → 当代极简设计 |

## 与千禧怀旧的关系

### 极简设计的精神源头
- 至上主义 → Bauhaus → Swiss Design → Apple → 当代极简
- "Malevich的黑色方块 = 所有极简设计的精神祖先"
- iOS的白色空间 = 至上主义的数字后代
- "Less is more"的最极端版本

### 对当代艺术的影响
- 《黑色方块》= 20世纪最重要的画之一
- "一个黑色方块改变了'艺术是什么'的定义"
- 概念艺术、极简主义 = 至上主义的后代
- "Malevich证明了：最简单的形式可以承载最深的意义"
