# Thangka 唐卡 | ཐང་ཀ

> **"丝绸上的佛国——藏族画师用矿物颜料和金粉绘制可以卷起来的寺庙。"**

## 概述

唐卡（Thangka / ཐང་ཀ）是藏传佛教的传统卷轴画，在棉布或丝绸上用矿物颜料和金粉绘制佛像、曼陀罗、护法神和宗教叙事场景。"Thangka"藏语意为"平坦的画"或"可以卷起来的"。唐卡既是宗教修行的辅助工具（观想对象），也是藏族艺术的最高成就。传统唐卡的绘制遵循严格的度量经（造像量度经），每一尊佛像的比例、手印、法器都有精确的规定。唐卡使用的矿物颜料（朱砂、石青、石绿、金粉）可以保持数百年不褪色。

## 主要类型

| 类型 | 特征 |
|------|------|
| 彩绘唐卡 | 矿物颜料，最常见 |
| 金唐卡 | 金底描线 |
| 黑唐卡 | 黑底金线 |
| 红唐卡 | 朱砂底 |
| 刺绣唐卡 | 丝线刺绣 |
| 堆绣唐卡 | 布料拼贴 |

## 核心特征

- **宗教功能**：修行观想的对象
- **严格度量**：遵循造像量度经
- **矿物颜料**：永不褪色的天然颜料
- **金粉描绘**：大量使用金粉
- **丝绸装裱**：锦缎边框装裱
- **可卷收藏**：便于携带和收藏

## 视觉特征

- 鲜艳的矿物颜料色彩
- 金粉的神圣光辉
- 精细的线条描绘
- 严格对称的构图
- 丰富的象征符号
- 层层叠叠的云彩和火焰
