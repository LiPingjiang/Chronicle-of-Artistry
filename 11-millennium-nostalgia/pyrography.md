# Pyrography 烙画

> "Pyrography is drawing with fire — the heated tip scorches wood into permanent marks, each line a controlled burn that can never be undone." — Unknown

## 概述

烙画（Pyrography）是使用加热的金属笔尖在木材、皮革、纸张或葫芦等材料表面烧灼出图案的艺术。"Pyrography"源自希腊语"pyro"（火）和"graphos"（书写），意为"用火书写"。烙画的原理简单而直接——加热的金属尖端接触有机材料表面时，会使材料碳化变色，产生从浅棕到深黑的色调变化。通过控制温度、压力和接触时间，艺术家可以创造出从精细的线条到柔和的阴影等丰富的效果。烙画是一种不可逆的艺术——每一笔烧灼都是永久的，无法擦除。

烙画的哲学在于：火的书写——用最原始的元素在自然材料上留下永恒的印记。

## 中国语境

烙画在中国有悠久的历史——中国的烙画（也称"烫画"或"火笔画"）可追溯到汉代。中国传统烙画以葫芦烙画最为著名——在葫芦表面烙制山水、花鸟、人物等图案，是重要的民间工艺。河南、山东等地的葫芦烙画是省级非物质文化遗产。中国的木板烙画也有独特的传统——一些艺术家能在木板上烙出如同水墨画般的效果。当代中国的烙画艺术家将传统技法与现代题材结合，在国内外展览中展示中国烙画的独特魅力。
