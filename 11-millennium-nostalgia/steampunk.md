# Steampunk 蒸汽朋克

![Steampunk 概念图](../assets/artworks/steampunk/steampunk-concept-01.png)

> **"齿轮、黄铜、蒸汽机——如果维多利亚时代发明了计算机。"**

## 历史脉络

### 文学起源 (1980s)

| 年份 | 事件 |
|------|------|
| 1987 | K.W. Jeter 首次使用"Steampunk"一词 |
| 1990 | Gibson & Sterling《The Difference Engine》 |
| 2000s | 从亚文化到主流视觉风格 |
| 2009 | 《雨果》《福尔摩斯》电影推动流行 |
| 2010s | Cosplay、手工艺、室内设计 |

### 核心设定

| 问题 | 回答 |
|------|------|
| 如果什么？ | 如果蒸汽机从未被内燃机取代 |
| 时代 | 维多利亚时代 (1837–1901) 的平行宇宙 |
| 技术 | 蒸汽动力 + 精密机械 = 一切 |
| 美学 | 工业革命的浪漫化 |
| 精神 | 手工艺 vs 大规模生产 |

### 核心哲学

Steampunk 的精神是**"技术应该是可见的、可理解的、美丽的"**：
- 反对黑箱——每个齿轮都暴露在外
- 反对一次性——每件物品都值得修理
- 反对无聊——功能性也可以是装饰性的
- 手工 > 工厂
- 黄铜 > 塑料

## 与千禧怀旧的关系

### 对数字化的反叛
- 触摸屏太"无形" → 渴望"可触摸"的技术
- 云计算太抽象 → 渴望"看得见"的机械
- 计划性报废 → 渴望"永恒"的物品
- 这是对硅谷极简主义的浪漫反叛

### 与 Maker 文化的交叉
- DIY/创客运动 = 现代蒸汽朋克精神
- Arduino/树莓派 = 可见的、可理解的技术
- 3D打印 = 个人制造的复兴
