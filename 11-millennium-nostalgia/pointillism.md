# Pointillism 点彩派

> "Some say they see poetry in my paintings; I see only science." — Georges Seurat

## 概述

点彩派（Pointillism / Divisionism）是1886年由乔治·修拉（Georges Seurat）和保罗·西涅克（Paul Signac）创立的新印象主义（Neo-Impressionism）绘画技法。画家不在调色板上混合颜料，而是将纯色的小点并置在画布上，让观者的眼睛在一定距离外自动进行"光学混色"——产生比物理混色更明亮、更纯净的色彩效果。

这一技法将印象派对光线的直觉观察提升为科学系统——基于谢弗勒尔的色彩对比理论和赫尔姆霍茨的光学研究。

## 核心特征

| 特征 | 描述 |
|------|------|
| 纯色小点 | 用纯色的小圆点构建画面 |
| 光学混色 | 颜色在观者眼中混合，而非在画布上 |
| 科学基础 | 基于色彩理论和光学科学 |
| 互补色 | 大量使用互补色并置增强亮度 |
| 系统性 | 极其系统化、有纪律的创作过程 |
| 耗时 | 一幅画可能需要数月甚至数年 |

## 视觉特征

- **笔触**：均匀的、规则的纯色小点
- **色彩**：极高的色彩纯度和亮度
- **光线**：闪烁的、振动的光线效果
- **距离**：近看是色点，远看融合为图像
- **表面**：均匀的、织物般的表面质感
- **氛围**：宁静的、几乎凝固的时间感

## 科学基础

| 理论 | 来源 | 应用 |
|------|------|------|
| 同时对比 | Chevreul (1839) | 互补色并置增强彼此 |
| 光学混色 | Helmholtz | 小色点在视网膜上混合 |
| 色彩分割 | Ogden Rood | 将色彩分解为组成成分 |
| 色轮 | 牛顿/歌德 | 系统化的色彩关系 |

## 历史背景

1. **1884年**：修拉开始实验点彩技法
2. **1886年**：《大碗岛的星期天下午》在第八届印象派展览展出
3. **1886年**：评论家 Félix Fénéon 命名"新印象主义"
4. **1891年**：修拉去世，年仅31岁
5. **1890年代**：西涅克继续推广，影响了野兽派和未来主义

## 与其他风格的关系

- **Impressionism** → 将印象派的直觉提升为科学系统
- **Fauvism** → 马蒂斯早期受点彩派影响
- **Futurism** → 意大利分割主义是未来主义的基础
- **Op Art** → 光学艺术继承了点彩的视觉振动效果
- **Digital Pixels** → 数字图像的像素原理与点彩相通
- **Divisionism** → 意大利分割主义是点彩的变体
