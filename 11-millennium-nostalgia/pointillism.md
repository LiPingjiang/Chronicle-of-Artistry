# Pointillism 点彩派

![Pointillism 概念图](../assets/artworks/pointillism/pointillism-concept-01.png)

> **"不混合颜料——让眼睛混合——无数彩色小点在视网膜上融合成光。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1886–1910/影响至今 |
| 别名 | Pointillism, Neo-Impressionism, Divisionism, 点彩主义 |
| 核心色彩 | 纯色小点、光谱色、互补色并置 |
| 关键元素 | 纯色圆点、光学混色、科学色彩理论、精确笔触 |
| 代表人物 | Georges Seurat, Paul Signac, Camille Pissarro |
| 关联风格 | Impressionism, Post-Impressionism, Op Art, Pixel Art |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1884 | Seurat 开始研究色彩科学理论 |
| 1886 | 《大碗岛的星期天下午》展出——点彩派诞生 |
| 1891 | Seurat 去世——年仅31岁 |
| 1890s | Signac 继续发展——更大的色块 |
| 1900s | 点彩派影响野兽派和未来主义 |
| 2020s | 像素艺术 = 数字时代的点彩派 |

### 核心哲学

点彩派的精神是**"用科学的方法画出最纯净的光"**：
- 科学 = 美（"色彩理论不是限制——是通往纯净光线的路"）
- 纯色 = 光（"不在调色板上混合——让光在眼睛里混合"）
- 耐心 = 虔诚（"一个点一个点——像修行一样画画"）
- 系统 = 自由（"有了系统——就不需要犹豫"）
- Seurat: "有些人在我的画中看到诗意——我只看到科学"

## 视觉语法

### 色彩系统

```
原理：
  光学混色 — 纯色点在视网膜上混合
  互补色 — 红+绿、蓝+橙并置
  光谱色 — 只用纯色，不混合

主色（纯色点）：
  纯红 (#FF0000)
  纯蓝 (#0000FF)
  纯黄 (#FFFF00)
  纯绿 (#00FF00)
  纯橙 (#FF8C00)
  纯紫 (#800080)

规则：
  - 不在调色板上混合颜色
  - 用纯色小点并置
  - 互补色增强亮度
  - 距离决定混合效果

质感：
  点状 — 均匀圆点
  精确 — 系统化排列
  发光 — 光学混色效果
  远看 — 融合；近看 — 分离
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 技法 | 纯色小点、系统化排列、光学混色 |
| 效果 | 远看融合、近看分离、发光感 |
| 题材 | 风景、河岸、公园、海滨、人物 |
| 科学 | 色彩理论、互补色、光谱 |
| 态度 | 科学、精确、耐心、系统、纯净 |
| 遗产 | → 像素艺术、数字显示原理 |

## 与千禧怀旧的关系

### 像素 = 数字时代的点
- 点彩派的"点" = 屏幕的"像素"
- "Seurat在1886年预言了数字显示的原理"
- Pixel Art = 点彩派的数字后代
- RGB显示器 = 光学混色的工业化

### 对当代设计的影响
- 点彩派 → 半调印刷(halftone) → Ben-Day dots → Pop Art
- → 像素艺术 → 数字马赛克
- "从Seurat的点到你屏幕上的像素——同一个原理"
