# Etching 蚀刻版画

> "Etching is drawing with acid — the line bites into metal as thought bites into consciousness." — Unknown

## 概述

蚀刻版画（Etching）是一种凹版印刷技法——在金属板上涂覆防腐蚀层，用针在其上刻画图案，然后用酸液腐蚀露出的金属线条，最后上墨印刷。从丢勒的精密线条到伦勃朗的光影魔术，从戈雅的黑暗幻想到毕加索的实验探索，蚀刻版画以其精细的线条、丰富的层次和独特的印刷质感成为最具表现力的版画形式。

蚀刻的魅力在于它的间接性——艺术家不是直接在纸上画，而是通过酸的"咬合"来创造线条，这种间接性带来了意想不到的效果。

## 核心特征

| 特征 | 描述 |
|------|------|
| 凹版 | 凹版印刷——墨填入凹线 |
| 酸蚀 | 用酸液腐蚀金属 |
| 精细 | 极其精细的线条 |
| 层次 | 通过腐蚀时间控制深浅 |
| 间接 | 间接的创作过程 |
| 复制 | 可印刷多份 |

## 视觉特征

- **线条**：精细而自由的线条
- **层次**：丰富的明暗层次
- **质感**：印刷的独特压痕质感
- **边缘**：板痕（plate mark）
- **墨色**：深沉的黑色墨迹
- **纸质**：通常在优质纸上印刷

## 中国语境

蚀刻版画在中国主要通过美术学院的版画系传承。中国当代版画家在蚀刻技法上有独特探索，将其与中国的线描传统结合。中国的铜版画教育体系完善，培养了大量蚀刻版画家。当代中国蚀刻版画在国际版画展中有重要地位。

## 与其他风格的关系

- **Engraving** → 雕版是蚀刻的前身
- **Woodcut** → 木刻是凸版，蚀刻是凹版
- **Drypoint** → 干刻是蚀刻的变体
- **Aquatint** → 飞尘法是蚀刻的面积技法
- **Lithography** → 石版画是另一种版画形式
- **Drawing** → 蚀刻的线条接近素描
