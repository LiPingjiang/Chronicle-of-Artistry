# Linocut 麻胶版画

> "The linocut is direct, bold, and democratic — anyone can carve a story." — Unknown

## 概述

麻胶版画（Linocut/Linoleum cut）是在亚麻油地毡（linoleum）上雕刻图案再印刷的版画技法。与木刻相比，麻胶更柔软、更容易雕刻，且没有木纹的方向限制，因此能创造更流畅的曲线和更大胆的设计。从马蒂斯的简洁剪影到毕加索的多色套印，从非洲的政治海报到当代的独立出版，麻胶版画以其直接、大胆和民主的特性成为最受欢迎的版画形式之一。

麻胶版画的精神在于它的直接性——从构思到成品只需要一块麻胶、一把刻刀和一管油墨。

## 核心特征

| 特征 | 描述 |
|------|------|
| 凸版 | 凸版印刷——刻去的部分不着墨 |
| 柔软 | 材料比木头柔软易刻 |
| 大胆 | 适合大胆的图形设计 |
| 对比 | 强烈的黑白对比 |
| 可复制 | 可以印刷多份 |
| 民主 | 材料便宜、技术门槛低 |

## 视觉特征

- **粗犷**：大胆粗犷的线条
- **对比**：强烈的黑白或色彩对比
- **平面**：平面化的图形设计
- **流畅**：比木刻更流畅的曲线
- **质感**：刀痕产生的独特质感
- **图形**：倾向于图形化的表现

## 中国语境

麻胶版画在中国美术教育中是版画入门的常用媒介——因为材料便宜、操作简单，适合教学。中国的版画传统以木刻为主（鲁迅推动的新兴木刻运动），但麻胶版画作为补充媒介也有一定的实践。当代中国的独立出版和手工书运动中，麻胶版画是常见的插图技法。
