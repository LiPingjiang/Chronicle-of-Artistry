# Linocut 麻胶版画

> "The linocut is a bold, direct medium — there is no room for timidity." — Traditional saying

## 概述

麻胶版画（Linocut / Linoleum Cut）是一种凸版印刷技法，在亚麻油地毡（linoleum）上雕刻图案，涂墨后印刷。它比木刻更容易雕刻，线条更流畅，是20世纪最民主化的版画媒介之一。

麻胶版画的魅力在于它的直接性和大胆——刀刻入材料的每一刀都是不可逆的决定，这种果断产生了独特的视觉力量。

## 核心特征

| 特征 | 描述 |
|------|------|
| 凸版印刷 | 未刻去的部分着墨印刷 |
| 材料柔软 | 比木头更容易雕刻 |
| 大胆线条 | 粗犷的、有力的线条和色块 |
| 高对比 | 黑白对比的戏剧性 |
| 可及性 | 工具简单、材料便宜 |
| 多色套印 | 可以多版套色或减版法 |

## 视觉特征

- **线条**：粗犷的、有刀痕感的线条
- **对比**：强烈的黑白或色彩对比
- **平面**：平涂的色块——无渐变
- **质感**：刀痕的方向性纹理
- **边缘**：略带粗糙的、手工感的边缘
- **构图**：大胆的、简化的形体
