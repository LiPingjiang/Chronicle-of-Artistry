### 什么是"阈限"？

| 概念 | 解释 |
|------|------|
| 阈限 (Liminal) | 拉丁语 "limen" = 门槛 |
| 过渡空间 | 走廊、楼梯、停车场——你不会"停留"的地方 |
| 时间错位 | 凌晨3点的商场——不该在这个时间看到 |
| 无人 | 本应有人的地方空无一人 |
| 似曾相识 | 你确定来过，但记忆模糊 |

### 核心哲学

Liminal Space 的精神是**"熟悉中的陌生"**：
- 恐怖不来自怪物——来自"不对劲"
- 空间本身成为情感的载体
- 记忆是不可靠的
- 童年的空间在成年后变得诡异
- "过渡"本身就是一种存在状态

## 视觉语法

### 色彩系统

```
主色：
  荧光灯白 (#F5F5DC) — 人工照明
  米黄 (#F5DEB3) — 老旧墙壁
  暗绿 (#2F4F4F) — 地毯、瓷砖
  褪色蓝 (#B0C4DE) — 泳池、天花板
  灰色 (#808080) — 混凝土、金属

规则：
  - 人工照明（荧光灯）
  - 褪色、老旧
  - 没有自然光
  - 低饱和度
  - 轻微过曝或欠曝

质感：
  地毯 — 90s办公室/酒店
  瓷砖 — 泳池/浴室
  混凝土 — 停车场/楼梯间
  壁纸 — 褪色的花纹
  荧光灯 — 嗡嗡作响
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 空间 | 走廊、楼梯、停车场、商场、泳池 |
| 照明 | 荧光灯、出口标志、应急灯 |
| 材质 | 地毯、瓷砖、混凝土、壁纸 |

## 与千禧怀旧的关系

### 童年空间的"闹鬼"
- 90s/00s 的商场、游乐场、学校——现在空了
- 这些空间承载着千禧一代的童年记忆
- 当它们空无一人时，记忆变成了恐怖
- Liminal Space = 千禧怀旧的"暗面"

### 与 Mallsoft 的交叉
- Mallsoft = 商场的声音记忆（音乐）
- Liminal Space = 商场的视觉记忆（空间）
- 两者都在处理"消失的公共空间"
- 都是对 90s/00s 消费空间的哀悼
