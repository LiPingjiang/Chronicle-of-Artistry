# Video Art 录像艺术

![Video Art 概念图](../assets/artworks/video-art/video-art-concept-01.png)

> **"电视不是家具——是画布。录像不是记录——是创造。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1960s–至今 |
| 别名 | Video Art, 录像艺术, 影像艺术, 视频艺术 |
| 核心色彩 | 屏幕光——蓝光、扫描线、像素、信号噪声 |
| 关键元素 | 时间性、循环、多屏、信号处理、身体与屏幕 |
| 代表人物 | Nam June Paik, Bill Viola, Pipilotti Rist, Bruce Nauman, 张培力 |
| 关联风格 | Fluxus, New Media Art, Installation Art, Performance Art |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1963 | Nam June Paik用磁铁干扰电视——录像艺术诞生 |
| 1965 | Sony Portapak便携摄像机——艺术家获得工具 |
| 1969 | "TV as a Creative Medium"展 |
| 1970s | 录像艺术进入美术馆体系 |
| 1980s | Bill Viola——录像艺术的精神性 |
| 1990s | 多屏装置、投影成为主流 |
| 2000s | 数字视频取代模拟——新可能性 |

### 核心哲学

录像艺术的精神是**"时间是可以雕塑的——屏幕是可以绘画的"**：
- Nam June Paik："电视一直在攻击我们——现在我们要反击"
- "录像不是电影——没有叙事义务——可以是纯粹的时间体验"
- "循环 = 永恒——录像可以没有开始和结束"
- "屏幕是窗户——也是镜子——也是牢笼"
- "在注意力经济时代——慢录像是最激进的反抗"

## 视觉语法

### 技术系统

```
模拟时代（1960s–1990s）：
  CRT显示器 — 扫描线、磷光、曲面
  信号处理 — 反馈、失真、色彩偏移
  磁带 — 降解、噪声、时间痕迹

数字时代（2000s–至今）：
  投影 — 大尺幅、沉浸、多面
  LED — 高亮、户外、建筑表面
  屏幕矩阵 — 多屏、碎片化、同步

时间结构：
  循环 — 无始无终
  慢动作 — 时间的拉伸
  实时 — 监控、直播
  多时间 — 多屏不同时间线

规则：
  - 时间是核心媒介
  - 可以没有叙事
  - 声音是平等的元素
  - 空间展示方式是作品的一部分
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 硬件 | CRT电视墙、投影、LED、多屏 |
| 时间 | 循环、慢动作、实时、长时间 |
| 图像 | 身体、自然、抽象、信号 |
| 声音 | 环境音、电子音、沉默、噪声 |
| 空间 | 黑暗房间、多屏装置、建筑投影 |
| 态度 | 反电视、反叙事、时间雕塑 |

## 与千禧怀旧/当代的关系

### CRT美学的怀旧
- VHS质感 = 千禧怀旧的核心视觉元素
- 扫描线+信号噪声 = Vaporwave/Retrowave的视觉来源
- "CRT的温暖 vs LCD的冷——怀旧的物质基础"

### 短视频时代的录像艺术
- TikTok/抖音 = 民主化的录像艺术？
- "每个人都是录像艺术家——但大多数人不知道"
- 竖屏、循环、15秒 = 新的时间结构
