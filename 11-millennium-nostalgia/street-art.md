# Street Art 街头艺术

![Street Art 概念图](../assets/artworks/street-art/street-art-concept-01.png)

> **"城市是画布、喷漆是画笔——不需要画廊的许可，墙壁就是展览。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1960s–至今 |
| 别名 | Street Art, Urban Art, Mural Art, 城市艺术 |
| 核心色彩 | 高饱和喷漆色、黑白模板、任何颜色 |
| 关键元素 | 公共空间、喷漆/模板/贴纸/小麦糊、社会评论、匿名 |
| 代表人物 | Banksy, Shepard Fairey, JR, Invader, Os Gemeos |
| 关联风格 | Graffiti, Pop Art, Propaganda Art, Punk, Lowbrow |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1960s | 费城/纽约——早期涂鸦标签(tagging) |
| 1970s | 纽约地铁涂鸦黄金时代 |
| 1980s | Keith Haring, Basquiat——从街头到画廊 |
| 2000s | Banksy——街头艺术全球化 |
| 2010s | 街头艺术成为城市更新工具 |
| 2020s | NFT+街头艺术——数字与物理的融合 |

### 核心哲学

街头艺术的精神是**"艺术属于所有人——不属于画廊和收藏家"**：
- 公共 = 民主（"不需要买票——走在街上就能看到"）
- 非法 = 自由（"没有许可 = 没有审查"）
- 短暂 = 真实（"明天可能就被涂掉——这就是生命"）
- 匿名 = 力量（"不知道是谁画的——但每个人都在讨论"）
- Banksy: "版权是给失败者的"

## 视觉语法

### 色彩系统

```
主色：
  喷漆黑 (#000000) — 模板、轮廓
  喷漆红 (#FF0000) — 力量、警告
  喷漆黄 (#FFFF00) — 注意、能量
  墙壁灰 (#808080) — 背景、城市

辅色：
  任何喷漆色 — 自由
  荧光色 — 夜间可见
  金属色 — 标签

规则：
  - 高对比（远距离可见）
  - 与环境互动
  - 快速执行（非法时）
  - 大尺幅（建筑尺度）

质感：
  喷漆 — 雾化、渐变
  模板 — 硬边、重复
  小麦糊 — 纸张、层叠
  墙壁 — 砖、混凝土、剥落
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 技法 | 喷漆、模板、贴纸、小麦糊、马赛克 |
| 内容 | 社会评论、政治讽刺、幽默、美化 |
| 场所 | 墙壁、桥洞、废弃建筑、火车 |
| 互动 | 与建筑结构互动、与环境对话 |
| 身份 | 匿名、化名、标签 |
| 态度 | 反体制、民主、短暂、公共、自由 |

## 与千禧怀旧的关系

### 从犯罪到文化
- 1970s: 涂鸦 = 犯罪、破坏
- 2020s: 街头艺术 = 城市文化资产
- Banksy 作品拍卖价超千万美元
- "最反商业的艺术形式——变成了最商业的"

### 城市更新与士绅化
- 街头艺术 → 吸引游客 → 房价上涨 → 原住民被迫搬离
- "街头艺术是城市更新的先锋——还是士绅化的帮凶？"
- 这个矛盾本身就是当代城市文化的核心议题
