# Woodblock Print 木版画

> "Every cut of the knife is a decision that cannot be undone." — Traditional saying

## 概述

木版画（Woodblock Print）是人类最古老的印刷技法之一，通过在木板上雕刻图案、涂墨后印刷在纸上。从中国唐代的佛经插图到日本浮世绘，从德国表现主义到当代艺术，木版画跨越了千年和大陆。

木版画的力量在于木头本身——木纹的方向、硬度的变化、刀与木的对抗，都成为画面的一部分。

## 核心特征

| 特征 | 描述 |
|------|------|
| 凸版原理 | 刻去的部分不着墨，留下的部分印刷 |
| 木纹参与 | 木头的天然纹理成为画面元素 |
| 黑白力量 | 黑白对比的原始力量 |
| 可复制 | 一版可印多张——民主化的艺术 |
| 东西方传统 | 中国、日本、欧洲各有传统 |
| 刀法表现 | 不同刀法产生不同线条性格 |

## 视觉特征

- **线条**：有力的、带有木纹方向感的线条
- **对比**：强烈的黑白对比
- **质感**：木纹的自然纹理
- **平面**：平涂的色块和线条
- **边缘**：木头纤维产生的微妙毛边
- **力量感**：粗犷的、原始的视觉冲击

- **Chinese Ink Painting** → 中国水印木刻融合水墨传统
