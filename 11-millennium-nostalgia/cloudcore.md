### 核心哲学

Cloudcore 的精神是**"向上看——天空永远在变化，永远美丽"**：
- 云 = 自由（没有固定形状）
- 天空 = 无限（没有边界）
- 轻盈 = 解脱（放下重力）
- "每一片云都是独一无二的"
- 短暂 = 珍贵（日落只有几分钟）

## 视觉语法

### 色彩系统

```
主色：
  天蓝 (#87CEEB) — 晴天
  白色 (#FFFFFF) — 云朵
  粉色 (#FFB6C1) — 日出/日落
  淡紫 (#E6E6FA) — 黄昏
  金色 (#FFD700) — 阳光

辅色：
  深蓝 (#191970) — 夜空
  橙色 (#FF8C00) — 黄昏
  灰色 (#808080) — 阴天（也有美）

质感：
  蓬松 — 积云
  丝滑 — 卷云
  渐变 — 天空色彩过渡
  光线 — 丁达尔效应、光芒
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 云 | 积云、卷云、层云、乳状云 |
| 天空 | 日出、日落、蓝天、星空 |
| 光线 | 丁达尔效应、彩虹、光晕 |
| 飞行 | 飞鸟、飞机尾迹、气球 |
| 物件 | 棉花糖、蓬松织物、羽毛 |
| 态度 | 轻盈、自由、梦幻、平静 |
