# Expressionism 表现主义

![Expressionism 概念图](../assets/artworks/expressionism/expressionism-concept-01.png)

> **"不画世界的样子——画世界让我感受到的样子。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1905–1930s/影响至今 |
| 别名 | Expressionism, German Expressionism, 表现主义 |
| 核心色彩 | 非自然色、高饱和、情绪化用色、强烈对比 |
| 关键元素 | 扭曲变形、情绪化笔触、非自然色彩、内心世界外化 |
| 代表人物 | Edvard Munch, Ernst Ludwig Kirchner, Egon Schiele, Wassily Kandinsky |
| 关联风格 | Fauvism, Abstract Expressionism, Neo-Expressionism, Gothic |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1893 | Munch《呐喊》——表现主义精神的预言 |
| 1905 | Die Brücke (桥社) 成立——德国表现主义开始 |
| 1911 | Der Blaue Reiter (蓝骑士) 成立——走向抽象 |
| 1920s | 德国表现主义电影——《卡里加里博士》 |
| 1930s | 纳粹将表现主义列为"堕落艺术" |
| 1980s | Neo-Expressionism 复兴——Basquiat, Baselitz |
| 2020s | 表现主义精神在当代艺术中持续 |

### 核心哲学

表现主义的精神是**"真实不在外面——在里面"**：
- 情感 = 真实（"我的恐惧比你的风景更真实"）
- 扭曲 = 诚实（"世界本来就是扭曲的——只是你假装它不是"）
- 色彩 = 情绪（"天空可以是红色的——如果我的愤怒是红色的"）
- 粗暴 = 力量（"精细是谎言——粗暴才是真相"）
- Munch: "我不画我看到的——我画我感受到的"

## 视觉语法

### 色彩系统

```
主色：
  血红 (#8B0000) — 焦虑、愤怒
  毒绿 (#00FF00) — 疾病、不安
  深蓝 (#00008B) — 忧郁、深渊
  焦黄 (#FFD700) — 疯狂、能量

辅色：
  黑色 (#000000) — 死亡、恐惧
  紫色 (#4B0082) — 神秘、痛苦
  橙色 (#FF4500) — 爆发、热情

规则：
  - 非自然色彩
  - 情绪决定颜色
  - 高饱和+高对比
  - 色彩冲突而非和谐

质感：
  粗暴 — 厚涂、刮刀
  扭曲 — 变形、拉伸
  焦虑 — 旋转、不稳定
  原始 — 木刻、粗线
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 人物 | 扭曲面部、夸张表情、瘦长身体 |
| 线条 | 粗暴、不稳定、情绪化 |
| 空间 | 扭曲透视、不稳定、压迫 |
| 题材 | 焦虑、孤独、城市、死亡、性 |
| 技法 | 厚涂、木刻、粗笔触、刮刀 |
| 态度 | 情绪化、主观、反理性、内省、原始 |

## 与千禧怀旧的关系

### 永恒的情绪表达
- 《呐喊》= 全球最被引用的"焦虑"图像
- 表现主义 = 每一代人面对焦虑时的视觉语言
- "在社交媒体焦虑的时代——表现主义比以往更相关"
- Neo-Expressionism → 当代街头艺术 → 数字表现主义

### 对流行文化的影响
- 德国表现主义电影 → 黑色电影 → 哥特美学
- Tim Burton 的视觉语言 = 表现主义的后代
- 恐怖游戏的视觉设计 = 表现主义的数字化
