# Fluxus 激浪派

![Fluxus 概念图](../assets/artworks/fluxus/fluxus-concept-01.png)

> **"艺术不在画廊里——艺术在你刷牙、走路、呼吸的每一刻。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1960s–1970s（影响至今） |
| 别名 | Fluxus, 激浪派, 激浪艺术 |
| 核心色彩 | 无固定色彩——日常材料的本色 |
| 关键元素 | 反艺术、跨媒介、偶发事件、幽默、日常即艺术 |
| 代表人物 | George Maciunas, Yoko Ono, Nam June Paik, Joseph Beuys |
| 关联风格 | Dadaism, Conceptual Art, Performance Art, Happenings |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1961 | George Maciunas在纽约组织第一次Fluxus活动 |
| 1962 | 威斯巴登Fluxus国际音乐节——正式命名 |
| 1963 | Yoko Ono《Cut Piece》——行为艺术经典 |
| 1964 | Nam June Paik——视频艺术先驱 |
| 1965 | Fluxus邮件艺术网络 |
| 1978 | Maciunas去世——Fluxus精神延续 |

### 核心哲学

Fluxus的精神是**"打破艺术与生活的边界——一切都是艺术，一切都不是艺术"**：
- "Fluxus = 流动——艺术应该像水一样流过生活"
- "反对艺术的精英化——艺术属于所有人"
- "一个微笑是艺术——一次呼吸是音乐——一次散步是舞蹈"
- "幽默是最严肃的武器"
- "过程比结果重要——体验比物品重要"

## 视觉语法

### 材料系统

```
核心材料：
  日常物品 — 邮票、盒子、食物、衣服
  文字 — 指令、诗歌、清单
  身体 — 行为、姿态、声音
  时间 — 事件、过程、偶发

形式：
  Event Score — 文字指令（"想象一朵花"）
  Fluxbox — 装满小物件的盒子
  Mail Art — 邮寄的艺术品
  Performance — 偶发行为

规则：
  - 没有规则
  - 简单 > 复杂
  - 幽默 > 严肃
  - 过程 > 产品
  - 参与 > 观看
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 形式 | Event Score、Fluxbox、邮件艺术、行为 |
| 材料 | 日常物品、廉价材料、文字、身体 |
| 态度 | 反精英、反商业、幽默、民主 |
| 跨界 | 音乐+视觉+文学+行为+生活 |
| 精神 | Dada的继承者——但更温和、更幽默 |

## 对当代的影响

- **互联网艺术** = Fluxus的数字化（参与、网络、民主）
- **社交媒体** = 每个人都是艺术家（Fluxus的预言）
- **开源文化** = Fluxus的反商业精神
- **Meme文化** = Fluxus幽默+日常+传播
