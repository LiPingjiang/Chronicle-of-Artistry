# Regionalism 地方主义

> "I had to go to France to appreciate Iowa." — Grant Wood

## 概述

地方主义（Regionalism）是1930年代美国大萧条时期兴起的艺术运动，以描绘美国中西部乡村生活和风景为核心。它是对欧洲现代主义抽象潮流的有意反叛——在全球化和都市化的浪潮中，地方主义画家选择回归本土、回归具象、回归"真正的美国"。

三位核心人物——格兰特·伍德（Grant Wood）、托马斯·哈特·本顿（Thomas Hart Benton）和约翰·斯图尔特·柯里（John Steuart Curry）——被称为"地方主义三杰"。

## 核心特征

| 特征 | 描述 |
|------|------|
| 本土题材 | 美国中西部的农场、小镇、劳动 |
| 反欧洲 | 有意拒绝巴黎前卫艺术的影响 |
| 具象写实 | 清晰可读的叙事性绘画 |
| 民族主义 | 强调"美国性"和本土文化价值 |
| 大众可及 | 面向普通美国人而非精英 |
| 壁画传统 | 大型公共壁画——艺术属于人民 |

## 视觉特征

- **色彩**：温暖的大地色——金色麦田、红色谷仓、蓝天
- **形态**：圆润的丘陵、整齐的农田、坚实的人体
- **构图**：稳定的、对称的、纪念碑式的
- **光线**：清澈的中西部阳光
- **细节**：精确的农具、建筑、服饰描绘
- **氛围**：宁静、庄严、略带讽刺

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1929 | 大萧条开始，美国转向内省 |
| 1930 | Grant Wood的*American Gothic*引起轰动 |
| 1933 | 罗斯福新政——WPA艺术项目资助公共壁画 |
| 1934 | Time杂志封面故事将地方主义推向全国 |
| 1935-43 | WPA/FAP项目期间地方主义达到高峰 |
| 1942 | Grant Wood去世 |
| 1940s后期 | 抽象表现主义兴起，地方主义被边缘化 |

## 子类型

| 子类型 | 特征 |
|--------|------|
| 爱荷华学派 | Grant Wood——精确的、略带讽刺的乡村描绘 |
| 密苏里学派 | Benton——动态的、壁画式的叙事 |
| 堪萨斯学派 | Curry——戏剧性的自然和宗教场景 |
| WPA壁画 | 公共建筑中的大型叙事壁画 |
| 南方地方主义 | 描绘美国南方生活和风景 |

## 中国语境

地方主义的"回归本土"精神与中国多次出现的"民族化"艺术运动相通。1940年代延安木刻运动强调"为工农兵服务"，与地方主义的大众可及性理念一致。当代中国的"乡土写实"传统（罗中立《父亲》）和近年的"新乡土"艺术也体现了类似的本土关怀。全球化时代，中国艺术家如何在国际语言和本土经验之间找到平衡，是一个持续的命题。

## 争议与遗产

- **争议**：被批评为"孤立主义"和"反智"——拒绝现代主义是进步还是倒退？
- **政治暧昧**：地方主义的民族主义色彩与1930年代的法西斯美学有令人不安的相似
- **American Gothic之谜**：是赞美还是讽刺？至今争论不休
- **遗产**：确立了"美国场景"作为合法艺术题材
- **当代回响**：当代美国乡村题材艺术、地方认同政治

## 与其他风格的关系

- **Social Realism** → 社会现实主义共享大萧条时代的社会关怀
- **Precisionism** → 精确主义共享美国本土题材但更现代化
- **Mexican Muralism** → 墨西哥壁画运动影响了地方主义的公共壁画传统
- **Ashcan School** → 垃圾箱画派是地方主义的城市前驱
- **Folk Art** → 民间艺术的朴素和直接影响了地方主义
- **Hudson River School** → 哈德逊河画派是美国风景画传统的先驱
