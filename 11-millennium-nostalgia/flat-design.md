# Flat Design 扁平设计

![Flat Design 概念图](../assets/artworks/flat-design/flat-design-concept-01.png)

> **"无阴影、无渐变、纯色块——当设计决定诚实面对屏幕。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2012–至今 |
| 别名 | Flat Design, Flat UI, Metro Design |
| 核心色彩 | 高饱和纯色、白色、深灰 |
| 关键元素 | 纯色块、无阴影、几何图标、大字体 |
| 代表人物 | Microsoft Metro、iOS 7、Google Material |
| 关联风格 | Minimalism, Corporate Memphis, Brutalism (数字) |

---

## 历史脉络

### 从拟物到扁平

| 年份 | 事件 |
|------|------|
| 2006 | Microsoft Zune 播放器——扁平UI雏形 |
| 2010 | Windows Phone Metro 设计语言 |
| 2012 | Microsoft Windows 8 全面扁平化 |
| 2013 | Apple iOS 7——拟物设计死亡 |
| 2014 | Google Material Design——"有深度的扁平" |
| 2017 | 扁平设计成为行业默认 |
| 2020s | 向"新拟物"(Neumorphism) 和 Glassmorphism 演变 |

### 它反对什么？

| 拟物设计 (Skeuomorphism) | 扁平设计 |
|--------------------------|----------|
| 模拟真实材质 | 承认这是屏幕 |
| 皮革纹理、木纹 | 纯色块 |
| 阴影、高光 | 无阴影 |
| "像真的一样" | "我就是数字的" |
| 复杂 | 简单 |
| 装饰性 | 功能性 |

### 核心哲学

Flat Design 的精神是**"屏幕不需要假装是别的东西"**：
- 像素就是像素——不需要模拟纸张
- 内容 > 装饰
- 清晰 > 花哨
- "诚实的设计"——不伪装
- 减少认知负担

## 视觉语法

### 色彩系统

```
主色（取决于品牌）：
  蓝色 (#007AFF) — iOS
  绿色 (#4CAF50) — Material
  紫色 (#6200EE) — Material You
  红色 (#FF3B30) — 警告/删除

基础色：
  白色 (#FFFFFF) — 背景
  深灰 (#333333) — 文字
  浅灰 (#F5F5F5) — 分区

规则：
  - 高饱和度纯色
  - 无渐变（早期）
  - 大色块分区
  - 白色为主背景
  - 颜色有功能含义

质感：
  无质感 — 这就是重点
  纯色 — 平面
  偶尔微妙阴影 — Material Design
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 图标 | 几何化、线性、单色 |
| 按钮 | 圆角矩形、纯色填充 |
| 字体 | 无衬线、大字号、粗细对比 |
| 布局 | 卡片式、网格、大量留白 |
| 动效 | 简洁过渡、有意义的动画 |
| 插画 | 几何化人物、纯色块 |

## 与千禧怀旧的关系

### iOS 7 的"革命"
- 2013年6月 = 设计界的"分水岭"
- 一夜之间所有app都变"扁"了
- 千禧一代设计师的集体记忆
- "那天之后，拟物设计就死了"

### 现在回看
- 早期扁平设计太"平"——缺乏层次
- Material Design 加回了阴影（"有深度的扁平"）
- 2020s = Glassmorphism、Neumorphism = "后扁平"
- 但扁平的核心原则仍然是主流

---

## 中国语境

- 中国互联网产品全面采用扁平设计
- 微信、支付宝、美团 = 扁平设计的中国实践
- "扁平化"成为设计行业的基本功
- 与"国潮插画"的融合
