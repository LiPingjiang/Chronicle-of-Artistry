# Generative Art 生成艺术

> "The artist creates the system, the system creates the art." — Philip Galanter

## 概述

生成艺术（Generative Art）是使用自主系统——算法、数学规则、随机过程或人工智能——作为创作过程的核心驱动力的艺术形式。艺术家设计规则和系统，然后让系统自主运行产生作品。从1960年代的早期计算机艺术到当代的AI生成艺术，生成艺术探索的是人类创造力与机器自主性之间的边界。

生成艺术的哲学核心是：艺术家不直接创造最终形式，而是创造产生形式的过程。

## 核心特征

| 特征 | 描述 |
|------|------|
| 系统性 | 基于规则或算法的系统 |
| 自主性 | 系统具有一定的自主决策能力 |
| 不可预测 | 结果不完全可预测 |
| 过程性 | 重视过程而非单一结果 |
| 可重复 | 系统可以反复运行产生变体 |
| 涌现性 | 简单规则产生复杂结果 |

## 视觉特征

- **模式**：重复但有变化的模式
- **复杂性**：简单规则产生的视觉复杂性
- **有机感**：算法模拟的自然形态
- **精确**：计算机生成的精确线条和形状
- **变体**：同一系统的多种输出
- **动态**：常以动态或交互形式呈现

## 代表作品

| 作品/艺术家 | 年代 | 特征 |
|-------------|------|------|
| Georg Nees | 1965 | 最早的计算机生成艺术展 |
| Vera Molnár | 1960s+ | 算法几何的先驱 |
| Harold Cohen (AARON) | 1973+ | AI绘画系统的先驱 |
| Casey Reas (Processing) | 2001+ | 创意编程工具和生成艺术 |
| Refik Anadol | 2010s+ | AI数据雕塑 |
| Art Blocks | 2020+ | 链上生成艺术平台 |

## 中国语境

生成艺术在中国的发展与全球数字艺术浪潮同步。中国的新媒体艺术家如曹斐、陆扬等在生成艺术领域有重要探索。中国的AI艺术社区活跃，从学术研究到商业应用都有广泛实践。中国的"算法艺术"和"数据可视化艺术"正在形成独特的创作语言。

## 与其他风格的关系

- **Digital Art** → 数字艺术是生成艺术的技术基础
- **Op Art** → 欧普艺术的视觉模式与生成艺术相通
- **Minimalism** → 极简规则产生复杂结果
- **Data Art** → 数据艺术是生成艺术的重要分支
- **Crypto Art** → NFT为生成艺术提供了新的分发模式
- **Systems Art** → 系统艺术是生成艺术的思想先驱
