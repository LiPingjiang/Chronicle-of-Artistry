# Webcore / Old Web

> **别名**：Early Internet, Retro Web, Web 1.0, "Wild West" Internet Era, GeoCities Aesthetic  
> **活跃年代**：1995 – 2005（原生期）；2018 – 至今（怀旧复兴期）  
> **关键平台**：GeoCities、Angelfire、Tripod、早期论坛、个人主页

![Webcore 概念图](../assets/artworks/webcore/webcore-concept-01.png)

---

## 一句话定义

Webcore 是对早期互联网视觉文化的怀旧美学——那个充满动态 GIF、访客计数器、"Under Construction"标志、霓虹背景和蓝色下划线链接的时代，代表着互联网尚未被公司化、算法化之前的**野生个人主义**。

---

## 视觉语言

| 元素 | 描述 |
|------|------|
| 动态 GIF | 旋转的信封图标、跳舞的婴儿、燃烧的文字 |
| 像素化图形 | 低分辨率剪贴画、像素字体、马赛克背景 |
| 霓虹色彩 | 亮绿色文字配黑色背景、彩虹渐变横幅 |
| HTML 表格布局 | 嵌套表格、框架页面、滚动字幕 `<marquee>` |
| 交互元素 | 访客计数器、留言簿、"Sign My Guestbook" 按钮 |
| 施工标志 | "Under Construction" 配一个挖掘机 GIF |
| ASCII Art | 用字符拼成的图案和签名 |

### 技术考古：为什么它长这样？

Webcore 的每一个视觉特征都可以追溯到具体的技术限制：

| 视觉特征 | 技术原因 |
|----------|----------|
| 256 色 GIF | 56K 调制解调器带宽限制 |
| 像素字体 | 800×600 屏幕分辨率 |
| 表格布局 | CSS 尚未成熟，`<table>` 是唯一的排版工具 |
| 平铺背景 | 小图片重复平铺以节省加载时间 |
| `<blink>` 闪烁文字 | Netscape 独有标签，当时最酷的"动画" |
| `<marquee>` 滚动 | IE 独有标签，模拟电子告示牌 |
| 框架页面 `<frameset>` | 在无 AJAX 时代实现"局部刷新" |
| MIDI 背景音乐 | 文件极小（几KB），可在拨号网络下播放 |

这些限制反而创造了一种独特的、不可复制的视觉语言——正如 8-bit 游戏的像素美学源于硬件限制，却成为了永恒的风格。

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1993 | Mosaic 浏览器发布，`<img>` 标签让网页可以显示图片 |
| 1994 | GeoCities 前身 Beverly Hills Internet 上线 |
| 1995 | GeoCities 正式命名；Angelfire、Tripod 等免费主页服务涌现 |
| 1995-1996 | "个人主页"概念爆发——每个人都可以有自己的网站 |
| 1996 | 动态 GIF 成为网页装饰标配；Web Ring 连接同好网站 |
| 1997 | GeoCities 成为全球第三大网站；Flash 2.0 发布 |
| 1998 | GeoCities 用户突破 200 万；Google 成立 |
| 1999 | Yahoo 以 $3.57B 收购 GeoCities |
| 2000-2001 | 互联网泡沫破裂，大量个人网站消失 |
| 2003-2004 | 博客（Blogger、LiveJournal）取代个人主页 |
| 2004-2007 | MySpace 继承了部分自定义精神（CSS 皮肤） |
| 2009 | **Yahoo 关闭 GeoCities**——互联网历史上最大规模的文化灭绝事件之一 |
| 2013 | Archive Team 发布 GeoCities 存档（约 1TB 数据） |
| 2018 | Neocities 复兴运动开始；Webcore 作为 Tumblr 美学标签流行 |
| 2020+ | "小网站"运动（Small Web）、IndieWeb 社区活跃 |
| 2023+ | AI 生成内容泛滥，人们更加怀念"手工制作"的互联网 |

## 文化内核

### 数字房间：互联网作为个人空间

早期互联网的核心隐喻是**房间**——你的个人主页就是你的数字卧室。你可以：
- 选择壁纸（背景图片）
- 摆放家具（GIF 装饰）
- 贴海报（喜欢的乐队/动漫图片）
- 邀请朋友来签名（留言簿）
- 挂门牌（"Welcome to my homepage!"）

GeoCities 甚至用**城市/社区**的隐喻来组织网站：
- Hollywood = 娱乐
- SiliconValley = 技术
- Tokyo = 动漫
- Area51 = 科幻/超自然

这种空间感在 Facebook/Instagram 的时间线界面中完全消失了。今天的社交媒体是一条**河流**（信息流），而不是一个**房间**（个人空间）。

### 技术限制即美学

Webcore 的视觉特征很多源于技术限制，但这些限制反而创造了独特的表现力：

- **256 色 GIF** → 抖动（dithering）产生独特的颗粒质感
- **像素字体** → 在低分辨率下反而比矢量字体更清晰
- **平铺背景** → 创造了无限延伸的图案空间
- **表格布局** → 产生了独特的"格子"结构感

这与日本的"侘寂"美学有相似之处：**不完美本身成为了美的来源**。

### 去中心化的乌托邦

早期互联网没有算法推荐、没有信息流、没有"关注"按钮。你需要**主动寻找**内容：
- **Web Ring**：同主题网站互相链接形成环状网络
- **链接页面**：每个网站都有一个"Links"页面推荐其他网站
- **搜索引擎**：AltaVista、Lycos、Yahoo 目录
- **口耳相传**：在论坛和聊天室中分享 URL

这种结构鼓励了探索和发现，而不是被动消费。每次上网都像一次**冒险**，而不是一次**喂食**。

### "Under Construction" 的哲学

几乎每个 90 年代的个人主页都有一个"Under Construction"标志。这不仅是技术状态的说明，更是一种**存在主义宣言**：

> "我的网站永远在建设中，因为我永远在成长。"

这种"永远未完成"的态度与今天社交媒体要求的"完美呈现"形成了鲜明对比。

## 中国语境：中文互联网的 Webcore

中国的早期互联网有自己独特的 Webcore 记忆：

**1998-2003：个人主页时代**
- 网易/搜狐免费个人主页
- "榕树下"文学网站
- Flash 动画热潮（小小作品、东北人都是活雷锋）

**2003-2008：QQ 空间时代**
- 自定义皮肤、背景音乐、访客计数器
- "踩空间"文化（相当于 GeoCities 的留言簿）
- 闪图、挂件、播放器——QQ 空间是中国的 MySpace

**2005-2010：论坛/贴吧时代**
- 百度贴吧的自定义头像和签名档
- 天涯/猫扑的 ASCII 表情和楼层文化
- "火星文"——一种视觉化的文字变形

**共同点**：
- 都强调个人化和自定义
- 都有"越花哨越好"的装饰倾向
- 都在移动互联网时代被标准化界面取代

## GeoCities 的消亡：一次数字文化灭绝

2009 年 Yahoo 关闭 GeoCities 是互联网历史上最重要的文化事件之一：

- **规模**：约 3800 万个网页被删除
- **不可逆性**：大量内容没有备份，永久消失
- **文化意义**：相当于烧毁了一座数字时代的亚历山大图书馆

Archive Team 的紧急抢救行动保存了约 1TB 的数据，但仍有大量内容永久丢失。这一事件直接催生了数字保存运动和 Internet Archive 的重要性认知。

## 为什么它在 2020s 回潮？

1. **对算法的厌倦**：人们怀念不被推荐系统控制的互联网
2. **对个性的渴望**：千篇一律的社交媒体模板 vs. 完全自定义的个人主页
3. **数字考古**：Internet Archive 让人们重新发现被遗忘的网站
4. **Neocities 运动**：新一代年轻人开始手写 HTML，重建个人网站
5. **AI 焦虑**：当 AI 可以生成"完美"内容时，手工制作的粗糙感反而成为真实性的证明
6. **平台疲劳**：Twitter/X 的衰落让人们重新思考"去中心化"的价值
