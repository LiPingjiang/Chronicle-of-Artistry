# Social Realism 社会现实主义

![Social Realism 概念图](../assets/artworks/social-realism/social-realism-concept-01.png)

> **"艺术为人民——画工人的汗水、农民的土地、社会的真相。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1930s–1960s（西方）/1930s–1980s（社会主义国家） |
| 别名 | Social Realism, Socialist Realism, 社会现实主义, 社会主义现实主义 |
| 核心色彩 | 土色、红色、工业灰——劳动者的色彩 |
| 关键元素 | 劳动者形象、社会批判、写实技法、宣传功能 |
| 代表人物 | Diego Rivera, Ben Shahn, 董希文, 罗中立 |
| 关联风格 | Realism, Expressionism, Mexican Muralism, Propaganda Art |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1930s | 美国大萧条——社会现实主义兴起 |

| 1930s | Diego Rivera墨西哥壁画运动 |
| 1940s | 中国延安文艺座谈会——艺术为人民服务 |
| 1950s | 中国社会主义现实主义高峰 |
| 1960s | 西方社会现实主义与波普艺术交汇 |
| 1980s | 中国"伤痕美术"——社会现实主义的反思 |

### 核心哲学

社会现实主义的精神是**"艺术不是象牙塔里的游戏——是改变社会的武器"**：
- "画人民看得懂的画——为人民说话"
- "美不在形式——在内容、在真相、在正义"
- "艺术家是社会的良心——不是市场的商品"
- "写实不是保守——是让所有人都能理解"
- "一幅好的社会现实主义作品——能让人行动"

```
西方社会现实主义：
  土色 (#8B7355) — 大地、劳动
  工业灰 (#696969) — 工厂、城市
  暗红 (#8B0000) — 血、革命
  天空蓝 (#4682B4) — 希望

社会主义现实主义：
  红色 (#FF0000) — 革命、胜利
  金色 (#FFD700) — 光明、未来
  绿色 (#228B22) — 丰收、自然
  蓝天 (#87CEEB) — 乐观

规则：
  - 写实技法——让所有人看懂
  - 人物必须有尊严
  - 劳动场景是核心
  - 光明的色调（社会主义现实主义）
  - 批判的色调（西方社会现实主义）
```

## 与千禧怀旧/当代的关系

### 中国宣传画美学的怀旧
- 红色经典 = 中国千禧一代的视觉记忆
- "大字报体""工农兵"= 当代设计的怀旧元素
- 中国独立游戏中的社会主义美学

### 当代社会批判艺术
- Banksy = 当代的社会现实主义？
- 社交媒体时代的"社会现实主义"
- 纪录片美学 = 社会现实主义的影像延续
