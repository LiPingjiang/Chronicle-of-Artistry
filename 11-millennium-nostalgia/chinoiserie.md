# Chinoiserie 中国风 | Chinoiserie

> **"欧洲人梦中的东方——18世纪的想象比真实更迷人。"**

## 概述

中国风（Chinoiserie）是17-18世纪欧洲对中国和东亚艺术的想象性诠释，并非真正的中国艺术，而是欧洲人基于有限的东方知识创造的装饰风格。"Chinoiserie"源自法语"chinois"（中国的）。这种风格在路易十五时期的法国和乔治三世时期的英国达到巅峰，广泛应用于室内装饰、家具、瓷器、壁纸、纺织品和园林设计。Chinoiserie混合了中国、日本和东南亚的视觉元素，创造出一个充满异域幻想的"东方"世界。

## 核心特征

- **想象性**：基于想象而非真实的东方
- **异域情调**：追求异国风情和神秘感
- **混合元素**：中日韩东南亚元素混合
- **装饰性**：高度装饰化的风格
- **不对称**：受中国画影响的不对称构图
- **自然主题**：花鸟、竹子、山水、宝塔

## 常见元素

| 元素 | 特征 |
|------|------|
| 宝塔 | 多层塔楼，东方建筑 |
| 龙 | 东方龙的欧洲诠释 |
| 竹子 | 竹节家具和装饰 |
| 花鸟 | 牡丹、梅花、仙鹤 |
| 人物 | 穿长袍的东方人物 |
| 山水 | 想象中的东方风景 |

| 纺织 | Toile de Jouy中国风 |
| 园林 | 中国亭、拱桥 |

## 视觉特征

- 蓝白色调（仿青花瓷）
- 金色和漆红色
- 精细的花鸟描绘
- 不对称的构图
- 异域建筑元素
- 华丽的装饰细节
