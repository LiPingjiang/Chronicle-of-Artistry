# Sound Art 声音艺术

![Sound Art 概念图](../assets/artworks/sound-art/sound-art-concept-01.png)

> **"闭上眼睛——用耳朵看世界——声音本身就是雕塑。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1960s–至今 |
| 别名 | Sound Art, 声音艺术, Audio Art, Sonic Art |
| 核心色彩 | 无视觉色彩——声波、频率、振动 |
| 关键元素 | 声音作为媒介、空间声学、聆听体验、声音装置 |
| 代表人物 | John Cage, Alvin Lucier, Janet Cardiff, Ryoji Ikeda, 池田亮司 |
| 关联风格 | Fluxus, Installation Art, New Media Art, Minimalism |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1913 | Luigi Russolo《噪音的艺术》——未来主义噪音 |
| 1952 | John Cage《4'33"》——沉默即音乐 |
| 1969 | Alvin Lucier "I Am Sitting in a Room"——空间共振 |
| 1970s | 声音装置进入画廊 |
| 1990s | 数字技术扩展声音艺术可能性 |
| 2000s | 声音艺术成为独立学科 |
| 2010s | ASMR、Field Recording流行化 |

### 核心哲学

声音艺术的精神是**"声音不是音乐的附属——它是独立的艺术媒介"**：
- Cage："到处都是音乐——你只需要学会听"
- "声音占据空间——就像雕塑一样"
- "聆听是一种创造性行为——不是被动接收"
- "噪音和沉默都是材料——没有等级之分"
- "声音艺术不在音乐厅——在画廊、在城市、在自然中"

## 视觉语法

### 声音系统

```
声音类型：
  环境音 — Field Recording、城市、自然
  电子音 — 合成、算法、数据声音化
  物理音 — 共振、振动、材料
  人声 — 语言、呼吸、身体

空间：
  声音装置 — 多声道、空间化
  声音雕塑 — 发声的物理对象
  声音漫步 — 城市中的聆听路径
  沉浸式 — 全包围声场

技术：
  多声道 — 空间定位
  传感器 — 互动触发
  算法 — 生成式声音
  物理 — 共振、反馈

规则：
  - 声音是主角不是配角
  - 空间是乐器
  - 时间是结构
  - 聆听是参与
```

## 与千禧怀旧/当代的关系

### ASMR——声音艺术的大众化
- ASMR = 声音的亲密体验 = 声音艺术的流行版本
- "百万人戴着耳机听人切肥皂——这是声音艺术的胜利"

### Lo-fi/环境音乐
- Lo-fi hip hop = 背景声音作为生活方式
- 白噪音App = 声音设计的日常化
- "声音不再只是听——是居住的空间"
