## 历史脉络

### 从山顶到街头

| 年份 | 事件 |
|------|------|
| 2017 | "Gorpcore" 一词出现（GORP = Good Old Raisins & Peanuts） |
| 2018 | Arc'teryx 开始被潮人穿着 |
| 2019 | Salomon 跑鞋成为时尚单品 |
| 2020 | 疫情推动户外活动热潮 |
| 2021 | 奢侈品牌 × 户外品牌联名爆发 |
| 2022–至今 | 从趋势变成永久的穿衣类别 |

### 为什么户外装备变时尚了？

| 驱动力 | 解释 |
|--------|------|
| 功能性 | 防水、透气、耐用——真的好用 |
| 疫情 | 封锁后人们涌向户外 |
| 可持续 | 户外品牌的环保叙事 |
| 反时尚 | "我穿这个是因为好用，不是好看" |
| 阶级信号 | Arc'teryx 不便宜——是"隐形奢侈" |

### 核心哲学

Gorpcore 的精神是**"为任何天气做好准备"**：
- 功能 > 形式
- 耐用 > 当季
- 准备 > 展示
- 户外 > 室内
- "我随时可以去爬山"（即使只是去咖啡店）

## 视觉语法

### 色彩系统

```
主色：
  橄榄绿 (#556B2F) — 自然、军事
  黑色 (#000000) — 技术感
  卡其 (#C3B091) — 大地
  橙色 (#FF8C00) — 安全、可见性
  灰色 (#808080) — 石头、混凝土

辅色：
  深蓝 (#191970) — 夜空
  红色 (#FF0000) — 警示、品牌色
  黄色 (#FFD700) — 高可见度

规则：
  - 自然色+技术色
  - 色块拼接
  - 反光条
  - 不追求"搭配"——追求"功能"

质感：
  Gore-Tex — 防水、哑光
  尼龙 — 轻量、耐磨
  Fleece — 保暖、柔软
  网眼 — 透气
  Cordura — 耐用
```

## 与千禧怀旧的关系

### 对"精致"的反叛
- 2010s = 精致、修身、"好看"
- Gorpcore = "我不在乎好不好看，我在乎能不能防水"
- 这是千禧一代对"永远在线"的逃离
- "户外"= 没有WiFi的自由

### 与 Quiet Luxury 的交叉
- Arc'teryx = 户外版的 Quiet Luxury
- 不需要logo（但懂的人知道价格）
- 功能性 = 另一种"品质"
- "我买这个是因为它好用"（但也因为它贵）
