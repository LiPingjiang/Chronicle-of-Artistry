# Gorpcore 户外核

![Gorpcore 概念图](../assets/artworks/gorpcore/gorpcore-concept-01.png)

> **"冲锋衣配西裤、登山鞋走红毯——户外装备就是高级时装。"**

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1960s | 户外品牌诞生（Patagonia, TNF） |
| 1990s | 户外装备 = 功能性，非时尚 |
| 2017 | "Gorpcore" 一词被 The Cut 杂志命名 |
| 2019 | Arc'teryx 成为潮流品牌 |
| 2021 | Salomon 联名爆发 |
| 2023 | 户外品牌全面时尚化 |

### 核心哲学

Gorpcore 的精神是**"功能就是美——不需要'好看'，需要'好用'"**：
- 功能 > 装饰（"这件衣服能防水"比"好看"重要）
- 户外 = 生活方式（不只是周末活动）
- 技术面料 = 新的奢侈品
- "我穿冲锋衣去上班，怎么了？"
- 实用主义的胜利

## 视觉语法

### 色彩系统

```
主色：
  黑色 (#000000) — 技术感、百搭
  橄榄绿 (#556B2F) — 自然、军事
  卡其 (#C3B091) — 大地、中性
  橙色 (#FF6600) — 安全色、亮点
  灰色 (#808080) — 技术面料

辅色：
  深蓝 (#003366) — 经典户外
  红色 (#CC0000) — 品牌色（TNF）
  紫色 (#6B3FA0) — Arc'teryx

质感：
  Gore-Tex — 防水透气
  尼龙 — 轻量、耐磨
  Cordura — 耐用
  网眼 — 透气
  反光 — 安全、科技
```

## 与千禧怀旧的关系

### 从"不时尚"到"最时尚"
- 2000s：户外装备 = "爸爸穿的"
- 2017：突然变成潮流
- 原因：对快时尚的反叛 + 功能主义回归
- "最不在乎时尚的东西，变成了最时尚的"

### 与 Techwear 的区别
- Techwear = 未来感、黑色、赛博朋克
- Gorpcore = 自然感、大地色、户外
- 两者共享"功能性面料"
- Gorpcore 更"接地气"

## 中国语境

- Arc'teryx 在中国的爆发式流行
