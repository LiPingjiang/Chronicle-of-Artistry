# Land Art 大地艺术

![Land Art 概念图](../assets/artworks/land-art/land-art-concept-01.png)

> **"地球本身就是材料——沙漠、湖泊、山脉——艺术的尺度可以是一座山。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1960s–至今 |
| 别名 | Land Art, Earth Art, Earthworks, Environmental Art, 大地艺术 |
| 核心色彩 | 自然色——泥土、岩石、水、天空、植物 |
| 关键元素 | 自然材料、巨大尺度、场地特定、短暂性、与自然对话 |
| 代表人物 | Robert Smithson, Andy Goldsworthy, Christo, James Turrell |
| 关联风格 | Minimalism, Conceptual Art, Installation Art, Environmental Art |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1968 | Robert Smithson 提出"Earthworks"概念 |
| 1970 | Smithson《螺旋形防波堤》——大地艺术经典 |
| 1970s | Christo 包裹海岸线——大尺度介入 |
| 1977 | Walter De Maria《闪电原野》 |
| 1990s | Andy Goldsworthy——自然材料的诗意 |
| 2020s | James Turrell "Roden Crater"——持续50年的项目 |

### 核心哲学

大地艺术的精神是**"画廊太小了——地球才是画布"**：
- 尺度 = 崇高（"艺术可以是一座山的大小"）
- 自然 = 材料（"石头、泥土、水——不需要颜料"）
- 短暂 = 真实（"潮水会冲走它——这就是时间"）
- 场地 = 意义（"这件作品只能存在于这个地方"）
- Smithson: "我的作品不在画廊里——在犹他州的盐湖里"

## 视觉语法

### 色彩系统

```
主色：
  泥土色 (#8B4513) — 大地
  岩石灰 (#808080) — 石头
  天空蓝 (#87CEEB) — 天空
  植物绿 (#228B22) — 生命

辅色：
  水色 — 湖泊、河流
  沙色 — 沙漠
  雪白 — 冬季
  日落色 — 光线

规则：
  - 只用自然色
  - 与环境融合或对比
  - 光线是核心元素
  - 季节和天气改变作品

质感：
  自然 — 石头、泥土、树叶
  巨大 — 航拍才能看全
  短暂 — 会消失
  精细 — Goldsworthy的微观
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 材料 | 石头、泥土、水、树枝、冰、沙 |
| 尺度 | 从微观到山脉 |
| 时间 | 短暂(潮水冲走)到永久(Roden Crater) |
| 记录 | 摄影、视频（作品本身可能消失） |
| 场所 | 沙漠、湖泊、海岸、森林、山脉 |
| 态度 | 崇高、谦卑、与自然对话、反商业 |
