# Impasto 厚涂法

> "I want to touch the paint, to feel its weight and texture." — Frank Auerbach

## 概述

厚涂法（Impasto，意大利语"面团"）是将颜料以极厚的层次涂抹在画布上的绘画技法——颜料不是平滑地覆盖表面，而是保留笔触和刮刀的痕迹，形成浮雕般的质感。从伦勃朗的金色厚涂到梵高的旋转笔触，从德库宁的狂暴刮擦到弗洛伊德的肉体堆积，厚涂法将绘画从平面的幻觉提升为物质的存在。

厚涂法的哲学在于：绘画不仅是图像——它也是物质、是痕迹、是身体行动的记录。

## 核心特征

| 特征 | 描述 |
|------|------|
| 厚度 | 颜料层极厚——可达数毫米 |
| 质感 | 保留笔触和工具的痕迹 |
| 物质性 | 强调颜料作为物质的存在 |
| 触觉性 | 可以"看到"触觉质感 |
| 即时性 | 记录创作的即时动作 |
| 表现力 | 厚涂增强情感表现力 |

## 视觉特征

- **浮雕**：颜料形成的浮雕质感
- **笔触**：清晰可见的笔触方向
- **光影**：颜料凸起产生的真实光影
- **色彩混合**：颜料在画布上的直接混合
- **刮痕**：刮刀和画笔的痕迹
- **堆积**：颜料的层层堆积

## 中国语境

厚涂法在中国油画中有广泛应用——从早期留法画家到当代表现性绘画。中国当代画家如刘小东、毛焰等在厚涂技法上有独特探索。中国传统绘画虽然以薄涂为主，但也有"积墨法"等厚涂的传统。当代中国的"新表现主义"绑画大量使用厚涂技法。

## 与其他风格的关系

- **Expressionism** → 表现主义大量使用厚涂
- **Abstract Expressionism** → 抽象表现主义的物质性
- **Post-Impressionism** → 后印象派（梵高）的厚涂
- **Realism** → Freud的写实厚涂
- **Mixed Media** → 厚涂与其他材料的结合
- **Sculpture** → 极端厚涂接近浮雕
