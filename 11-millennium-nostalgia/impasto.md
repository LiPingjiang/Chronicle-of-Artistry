# Impasto 厚涂法

> "I dream my painting and I paint my dream." — Vincent van Gogh

## 概述

厚涂法（Impasto，意大利语"面团"之意）是一种将颜料以厚重的、可见的笔触或刮刀痕迹直接堆积在画布上的绘画技法。颜料层厚到足以从画面表面凸起，形成三维的肌理和质感，使画面在光线下产生真实的阴影和高光。

从伦勃朗的珠宝高光到梵高的旋转星空，从德·库宁的狂放笔触到弗洛伊德的肉体质感，厚涂法贯穿了从巴洛克到当代的整个西方绘画史。

## 核心特征

| 特征 | 描述 |
|------|------|
| 颜料厚度 | 颜料从画面凸起，形成三维肌理 |
| 可见笔触 | 画笔或刮刀的痕迹清晰可见 |
| 物质性 | 强调颜料本身作为物质的存在感 |
| 表现力 | 笔触的方向和力度传达情感 |
| 光影效果 | 厚涂表面在真实光线下产生阴影 |
| 即时性 | 保留了创作瞬间的能量和速度 |

## 视觉特征

- **表面**：凹凸不平的三维肌理
- **笔触**：粗犷有力，方向明确
- **颜料**：浓稠的、未稀释的油画颜料
- **光线**：画面表面在侧光下产生真实阴影
- **色彩**：纯色直接从管中挤出，少混合
- **工具**：画笔、调色刀、手指、甚至直接挤管

## 代表人物

| 画家 | 厚涂特点 | 时期 |
|------|---------|------|
| Rembrandt | 珠宝和金属的高光厚涂 | 巴洛克 |
| Vincent van Gogh | 旋转的厚涂笔触表达情感 | 后印象派 |
| Willem de Kooning | 狂放的刮刀和画笔堆积 | 抽象表现主义 |
| Frank Auerbach | 极端厚涂，颜料层数厘米厚 | 当代 |
| Lucian Freud | 肉体质感的厚涂表现 | 当代写实 |
| Anselm Kiefer | 混合材料的极端厚涂 | 新表现主义 |

## 技法要点

| 方法 | 描述 | 效果 |
|------|------|------|
| 画笔厚涂 | 用硬毛笔蘸取大量颜料 | 有方向性的笔触肌理 |
| 刮刀涂抹 | 用调色刀平铺或刮擦 | 平滑或锋利的边缘 |
| 挤管直涂 | 直接从颜料管挤到画布 | 最厚的线条和点 |
| 手指涂抹 | 用手指推动颜料 | 柔和的厚涂过渡 |
| 混合介质 | 加入沙子、石膏等增加体积 | 极端的三维效果 |

## 历史演变

1. **16-17世纪**：提香和伦勃朗在局部使用厚涂增强高光
2. **19世纪**：库尔贝和印象派画家更大面积使用
3. **后印象派**：梵高将厚涂发展为全面的表现手段
4. **20世纪**：抽象表现主义将厚涂推向极端
5. **当代**：厚涂作为物质性和触觉性的核心手段

## 与其他技法的关系

- **Sfumato** → 完全相反——极薄 vs 极厚
- **Glazing** → 互补关系——厚涂底层 + 透明罩染
- **Expressionism** → 厚涂是表现主义的核心技法
- **Abstract Expressionism** → Action Painting 的物质基础
- **Palette Knife Painting** → 刮刀画是厚涂的专门分支
