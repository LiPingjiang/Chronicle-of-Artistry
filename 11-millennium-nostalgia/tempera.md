# Tempera 蛋彩画

> "Tempera is the medium of patience and precision — each stroke is a commitment." — Andrew Wyeth

## 概述

蛋彩画（Tempera）是以蛋黄为粘合剂的古老绘画技法——在油画发明之前，它是西方绘画的主要媒介，统治了从古埃及到文艺复兴早期的数千年。蛋彩画以其精细的笔触、明亮的色彩和持久的耐久性著称。波提切利的《维纳斯的诞生》和安德鲁·怀斯的《克里斯蒂娜的世界》都是蛋彩画的杰作。

蛋彩画的精神在于它的纪律性——快干的特性不允许犹豫，每一笔都必须精确而果断。

## 核心特征

| 特征 | 描述 |
|------|------|
| 蛋黄粘合 | 以蛋黄为颜料粘合剂 |
| 快干 | 极快的干燥速度 |
| 精细 | 适合极精细的笔触 |
| 明亮 | 色彩明亮而持久 |
| 耐久 | 数百年不褪色 |
| 不可混合 | 干后不可重新混合 |

## 视觉特征

- **精细**：极其精细的笔触和细节
- **明亮**：清澈明亮的色彩
- **哑光**：自然的哑光表面
- **线性**：倾向于线性的表现
- **层次**：通过薄层叠加建立色彩
- **硬边**：相对清晰的边界

## 中国语境

蛋彩画在中国主要作为西方美术史的知识被了解。中国传统绘画中虽然没有蛋彩的传统，但中国的工笔画在精细度和耐心要求上与蛋彩画有相似之处。当代中国有少数艺术家尝试蛋彩画创作，将其与中国传统工笔的精神结合。

## 与其他风格的关系

- **Oil Painting** → 油画在15世纪取代了蛋彩
- **Gouache** → 水粉与蛋彩有相似的哑光质感
- **Fresco** → 湿壁画与蛋彩常结合使用
- **Icon Painting** → 圣像画是蛋彩的重要传统
- **Miniature Painting** → 微型画常使用蛋彩
- **Gongbi** → 中国工笔画与蛋彩精神相通
