# Tempera 蛋彩画

> "Tempera demands patience and precision — each stroke dries in seconds, and the painter must build the image like a mosaic of tiny marks." — Unknown

## 概述

蛋彩画（Tempera）是一种使用蛋黄（或全蛋）作为粘合剂将颜料固定在画面上的绘画技法。在油画发明之前的数百年间，蛋彩画是欧洲绑画的主要媒介——从拜占庭圣像到意大利文艺复兴早期的杰作，几乎都是蛋彩画。蛋彩画的特点是：干燥极快（几秒钟内）、色彩明亮持久、表面呈现细腻的哑光质感。由于干燥快，艺术家无法像油画那样在画面上混合颜色，而必须通过细密的交叉排线（hatching）和薄层叠加来建立色调和明暗。这赋予蛋彩画独特的精细、明亮和清晰的视觉品质。

蛋彩画的哲学在于：耐心的积累——一笔一笔地建造图像，如同用砖块砌墙。

## 核心特征

| 特征 | 描述 |
|------|------|
| 蛋黄 | 蛋黄作为粘合剂 |
| 速干 | 几秒钟内干燥 |
| 明亮 | 色彩明亮持久 |
| 哑光 | 细腻的哑光表面 |
| 精细 | 需要精细的笔触 |
| 耐久 | 极其耐久不变色 |

## 视觉特征

- **明亮**：明亮清晰的色彩
- **哑光**：细腻的哑光质感
- **精细**：精细的笔触可见
- **清晰**：清晰的轮廓
- **层次**：薄层叠加的层次
- **纯净**：纯净不浑浊的色调

## 中国语境

蛋彩画在中国传统绑画中没有直接对应，但中国的工笔画与蛋彩画有相似的精神——都强调精细的笔触、耐心的层层叠加和明亮的色彩。当代中国的一些艺术家开始学习和实践蛋彩画技法，将其与中国传统绘画的题材和意境结合。中央美术学院等院校开设蛋彩画课程。蛋彩画的"三矾九染"式的层层叠加与中国工笔画的"分染"技法有异曲同工之妙。
