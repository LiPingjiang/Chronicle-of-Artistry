## 历史脉络

### 从情人节到全年美学

| 年份 | 事件 |
|------|------|
| 古罗马 | 丘比特/维纳斯——爱的视觉符号起源 |
| 中世纪 | 心形符号成为"爱"的通用图标 |
| 1900s | 情人节卡片产业——心形+玫瑰商业化 |
| 2020 | Lovecore 作为独立美学在 TikTok 兴起 |
| 2022 | 与 Coquette 美学融合 |
| 2024 | 持续流行，与 romantic maximalism 交叉 |

### 核心哲学

Lovecore 的精神是**"爱是最美的装饰——把浪漫变成视觉语言"**：
- 爱 = 美学（不只是情感，是视觉风格）
- 红色 = 激情（不需要理由）
- 心形 = 万能符号
- "每一天都是情人节"
- 浪漫不需要对象——可以是自我表达

## 视觉语法

### 色彩系统

```
主色：
  红色 (#FF0000) — 激情、爱
  粉色 (#FF69B4) — 甜蜜、浪漫
  白色 (#FFFFFF) — 纯洁、蕾丝
  金色 (#FFD700) — 丘比特、奢华

辅色：
  深红 (#8B0000) — 成熟的爱
  玫瑰金 (#B76E79) — 温柔
  黑色 (#000000) — 对比（Dark Lovecore）

质感：
  丝绸 — 光滑、浪漫
  蕾丝 — 精致、女性
  天鹅绒 — 奢华、触感
  缎带 — 装饰、礼物
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 符号 | 心形、丘比特、箭、玫瑰、嘴唇 |
| 物件 | 情书、巧克力盒、香水瓶、蜡烛 |
| 服装 | 红色连衣裙、心形首饰、蕾丝 |
| 空间 | 玫瑰花瓣、烛光、红色调 |
