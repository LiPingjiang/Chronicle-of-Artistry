## 历史脉络

| 年份 | 事件 |
|------|------|
| 1960s | Ska 在牙买加诞生——Reggae 的前身 |
| 1964 | Ska 传入英国——Mod/Rudeboy 文化 |
| 1979 | 2 Tone Records 成立——Jerry Dammers |
| 1979 | The Specials "Gangsters"——2 Tone 运动开始 |
| 1981 | "Ghost Town"——2 Tone 的巅峰与终结 |
| 1990s | 第三波 Ska——Sublime, No Doubt, Reel Big Fish |
| 2000s | Ska-Punk 继续活跃 |

### 核心哲学

2 Tone 的精神是**"黑人和白人一起跳舞——音乐面前人人平等"**：
- 团结 = 核心（反种族主义）
- 黑白 = 象征（"两种颜色，一种节奏"）
- 跳舞 = 政治（"一起跳舞就是一种声明"）
- 工人阶级 = 骄傲（"我们的音乐，我们的街道"）
- "如果你能一起 skank，你就是兄弟"

## 视觉语法

### 色彩系统

```
主色：
  黑色 (#000000) — 棋盘格、西装
  白色 (#FFFFFF) — 棋盘格、衬衫
  
辅色：
  红色 (#FF0000) — 配饰、领带
  绿色 (#006400) — 牙买加元素
  金色 (#FFD700) — 牙买加元素

规则：
  - 黑白棋盘格 = 2 Tone 的视觉符号
  - 修身、整洁
  - 与 Mod 共享精确感
  - Walt Jabsco 人物 = 品牌标志

质感：
  羊毛 — 西装
  棉 — 衬衫、Polo
  尼龙 — Harrington 夹克
  皮革 — 鞋（Loafer）
```

## 与千禧怀旧的关系

### 90s Ska-Punk 的记忆
- 第三波 Ska (1990s) = 很多人的青春记忆
- No Doubt "Don't Speak" = 90s 流行文化
- Warped Tour = Ska-Punk 的舞台
- "90s 的孩子都跳过 skank"

### 永恒的反种族主义视觉
- 黑白棋盘格 = 最简洁的"团结"符号
- 2 Tone 的设计 = 平面设计经典
- Walt Jabsco = 亚文化品牌的典范
- "好的设计可以传递政治信息"
