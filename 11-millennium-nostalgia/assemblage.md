# Assemblage 集合艺术

> "I see a piece of junk and I see a work of art." — Louise Nevelson

## 概述

集合艺术（Assemblage）是将各种现成物品、废弃材料和日常物件组合成三维艺术作品的创作方式。它是拼贴（collage）从二维向三维的延伸——如果拼贴是在平面上粘贴纸片和图像，集合艺术就是在空间中组装物品和碎片。

从毕加索的立体主义雕塑到施维特斯的Merzbau、从劳森伯格的"组合"到内维尔森的黑色木箱墙，集合艺术模糊了绘画与雕塑、艺术与垃圾、高雅与低俗的边界。

## 核心特征

| 特征 | 描述 |
|------|------|
| 三维拼贴 | 将物品在空间中组合而非在平面上粘贴 |
| 现成材料 | 使用找到的、回收的、日常的物品 |
| 积累 | 大量物品的堆积和组合 |
| 转化 | 废弃物通过组合获得新的意义 |
| 混合媒介 | 不限于单一材料或技法 |
| 叙事碎片 | 每个物品携带自己的历史和故事 |

## 视觉特征

- **材料**：木头、金属、布料、塑料、纸——任何物品
- **质感**：粗糙的、风化的、有时间痕迹的
- **色彩**：Nevelson的统一黑色/白色/金色；或多彩混杂
- **结构**：盒子、格子、架子——容纳碎片的框架
- **尺度**：从桌面小品到墙面覆盖的巨型装置
- **密度**：密集的、充满的、horror vacui

## 代表作品

| 作品 | 艺术家 | 年代 | 意义 |
|------|--------|------|------|
| *Sky Cathedral* | Louise Nevelson | 1958 | 黑色木箱的纪念碑——集合艺术的标志 |
| *Merzbau* | Kurt Schwitters | 1923-37 | 将整个房间变成集合作品 |
| *Canyon* | Robert Rauschenberg | 1959 | 绘画+物品的"组合" |
| *Accumulations* | Arman | 1960s | 同类物品的大量积累 |
| *Poubelles* | Arman | 1960 | 垃圾桶中的废弃物封存 |
| *Guitar* | Pablo Picasso | 1912 | 立体主义的三维拼贴——先驱 |

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1912 | Picasso的*Guitar*——立体主义的三维拼贴 |
| 1920s | Schwitters的Merz作品——达达的集合 |
| 1950s | Rauschenberg的"Combines"——绘画+物品 |
| 1958 | Nevelson的*Sky Cathedral*——集合艺术的经典 |
| 1961 | MoMA的"The Art of Assemblage"展览——正式命名 |
| 1960s | 新现实主义——Arman、César、Spoerri |
| 1970s | 集合艺术融入装置艺术 |
| 1980s-至今 | 集合作为当代艺术的基本语汇继续存在 |

## 子类型

| 子类型 | 特征 |
|--------|------|
| 墙面集合 | Nevelson——挂在墙上的三维组合 |
| 组合绘画 | Rauschenberg——绘画与物品的混合 |
| 积累 | Arman——大量同类物品的堆积 |
| 废品雕塑 | 金属废料焊接的雕塑 |
| 盒子艺术 | Joseph Cornell——微型世界的盒子 |
| 环境集合 | Schwitters——整个空间的集合 |

## 中国语境

集合艺术在中国当代艺术中有广泛实践。中国快速城市化产生的大量废弃物为集合艺术提供了丰富素材。艺术家如宋冬的"物尽其用"（展示母亲一生积攒的物品）、徐冰的"凤凰"（建筑废料组装的巨型凤凰）都是中国集合艺术的杰出代表。中国传统的"百宝嵌"工艺——将各种材料镶嵌组合——可视为集合艺术的古老先驱。

## 与其他风格的关系

- **Cubism** → 立体主义的拼贴是集合艺术的直接先驱
- **Dadaism** → 达达的反美学为集合艺术提供精神基础
- **Found Object Art** → 现成品艺术与集合艺术共享日常物品
- **Installation Art** → 装置艺术是集合艺术的空间化延伸
- **Pop Art** → 波普艺术使用商品作为集合材料
- **Arte Povera** → 贫穷艺术使用贫穷材料的集合
