# Assemblage 集合艺术

> "I see the discarded as the beginning of something new." — Louise Nevelson

## 概述

集合艺术（Assemblage）是将各种现成物品、废弃材料和日常物件组合成三维艺术作品的创作方式。从毕加索的早期拼贴实验到路易丝·内维尔森的黑色木箱墙，从约瑟夫·康奈尔的诗意盒子到罗伯特·劳森伯格的"组合绘画"，集合艺术模糊了绘画与雕塑、艺术与生活的边界。

集合艺术的哲学在于：任何物品都可以成为艺术——关键不在于材料本身，而在于艺术家如何重新组合和赋予意义。

## 核心特征

| 特征 | 描述 |
|------|------|
| 现成物 | 使用现成的、非艺术的物品 |
| 三维 | 从平面走向三维空间 |
| 组合 | 将不同物品组合在一起 |
| 废弃物 | 常使用废弃和回收材料 |
| 叙事性 | 物品携带自身的历史和故事 |
| 跨界 | 模糊绘画、雕塑、装置的边界 |

## 视觉特征

- **混杂**：各种不同材料的混合
- **质感**：丰富的表面质感对比
- **层次**：物品的层层叠加
- **意外**：意想不到的材料组合
- **时间**：物品携带的时间痕迹
- **空间**：从墙面延伸到空间

## 中国语境

集合艺术在中国当代艺术中有广泛实践。中国艺术家利用本土的废弃材料——旧家具、工业零件、传统物件——创造具有中国特色的集合作品。徐冰的《凤凰》用建筑废料组装巨型凤凰，是中国集合艺术的代表。中国传统的"百宝嵌"工艺也可视为集合艺术的古老先驱。

## 与其他风格的关系

- **Collage** → 拼贴是集合艺术的平面前身
- **Found Object Art** → 现成品艺术是集合的基础
- **Installation Art** → 装置艺术是集合的空间扩展
- **Mixed Media** → 混合媒介包含集合的方法
- **Dada** → 达达主义是集合艺术的精神源头
- **Junk Art** → 废品艺术是集合的一个分支
