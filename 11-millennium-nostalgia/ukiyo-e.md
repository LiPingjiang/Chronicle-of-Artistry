# Ukiyo-e 浮世绘

> "Ukiyo-e is the art of the floating world — beauty captured in the fleeting moment." — 葛饰北斋

## 概述

浮世绘（Ukiyo-e，字面意思"浮世之画"）是日本江户时代（1603-1868）发展起来的木版画和绘画形式。它描绘"浮世"——都市生活的享乐世界：美人、歌舞伎演员、相扑力士、风景和花鸟。浮世绘是日本对世界艺术最重要的贡献之一——它深刻影响了法国印象派和后印象派。

浮世绘的革命性在于它是大众艺术——通过木版印刷大量复制，普通市民也能拥有精美的艺术品。

## 核心特征

| 特征 | 描述 |
|------|------|
| 木版印刷 | 多色木版套印技术 |
| 大众性 | 面向普通市民的商业艺术 |
| 平面性 | 不使用西方透视——平面装饰 |
| 线条性 | 以线条为主要表现手段 |
| 题材性 | 美人、役者、风景、花鸟 |
| 协作性 | 画师、雕师、摺师的分工协作 |

## 视觉特征

- **线条**：流畅的、有力的轮廓线
- **平涂**：大面积的平涂色彩
- **构图**：大胆的裁切和不对称构图
- **色彩**：鲜艳的植物和矿物颜料
- **留白**：有意义的空白空间
- **图案**：精美的和服图案和装饰

## 中国语境

浮世绘与中国有深厚的渊源——日本木版画技术源自中国，浮世绘的许多题材和构图也受中国绘画影响。中国的明清版画（如《十竹斋画谱》）在技法上与浮世绘有相似之处。当代中国对浮世绘有广泛的欣赏和收藏，浮世绘展览在中国各大城市频繁举办。

## 与其他风格的关系

- **Impressionism** → 浮世绘深刻影响了印象派
- **Post-Impressionism** → 梵高大量临摹浮世绘
- **Art Nouveau** → 新艺术运动借鉴了浮世绘的线条
- **Woodcut Art** → 浮世绘是彩色木版画的极致
- **Printmaking** → 浮世绘是版画艺术的重要传统
- **Manga** → 日本漫画继承了浮世绘的视觉语言
