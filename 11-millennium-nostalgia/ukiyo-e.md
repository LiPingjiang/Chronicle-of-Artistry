## 历史脉络

| 年份 | 事件 |
|------|------|
| 1603 | 江户时代开始——浮世绘萌芽 |
| 1765 | 多色木版印刷(锦绘)技术成熟 |
| 1831 | 北斋《富岳三十六景》——《神奈川冲浪里》 |
| 1853 | 日本开国——浮世绘流入西方 |
| 1860s | "日本主义"(Japonisme)席卷欧洲 |
| 1890s | 影响印象派、后印象派、新艺术运动 |
| 2020s | 浮世绘美学在当代设计/AI生成中的持续影响 |

### 核心哲学

浮世绘的精神是**"浮世——转瞬即逝的美——值得被记录"**：
- 浮世 = 当下（"不画神话——画此刻的欢愉"）
- 版画 = 民主（"不是贵族的油画——是平民买得起的艺术"）
- 自然 = 敬畏（"一座山、一个浪——足以震撼灵魂"）
- 平面 = 选择（"不需要透视——平面本身就是美"）
- "浮世绘证明了：'流行文化'可以成为永恒的艺术"

## 视觉语法

### 色彩系统

```
主色：
  普鲁士蓝 (#003153) — 北斋蓝、海、天
  朱红 (#FF4500) — 印章、太阳、和服
  墨黑 (#1C1C1C) — 轮廓、头发
  和纸白 (#FAF0E6) — 纸张、留白

辅色：
  金色 (#DAA520) — 装饰、高级
  草绿 (#6B8E23) — 自然、松
  紫色 (#4B0082) — 和服、贵族

规则：
  - 平面色块（无渐变）
  - 粗线条轮廓
  - 大面积留白
  - 有限色数（木版限制）

质感：
  木版 — 印刷纹理
  和纸 — 纤维、温暖
  墨 — 浓淡变化
  平面 — 无阴影
```

## 与千禧怀旧的关系

### 对西方现代艺术的深远影响
- 浮世绘 → 印象派（莫奈收藏浮世绘）
- → Art Nouveau（线条和平面）
- → 当代平面设计（Flat Design的远祖）
- "没有浮世绘——就没有现代西方艺术"

### 当代流行文化中的浮世绘
- 动漫/漫画 = 浮世绘的精神后代
- "Great Wave" = 全球最被引用的艺术图像之一
- AI生成中"ukiyo-e style"是热门prompt
- 浮世绘 × 当代题材 = 流行的创作方向
