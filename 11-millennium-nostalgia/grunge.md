# Grunge 垃圾摇滚美学

![Grunge 概念图](../assets/artworks/grunge/grunge-concept-01.png)

> **"法兰绒衬衫、破洞牛仔裤、不洗头——西雅图的愤怒改变了一切。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1988–1997 原版 / 2018–至今 复兴 |
| 别名 | Grunge, Seattle Sound, Anti-Fashion |
| 核心色彩 | 暗红、军绿、黑色、褪色牛仔蓝、棕色 |
| 关键元素 | 法兰绒衬衫、破洞牛仔裤、Doc Martens、乱发 |
| 代表人物 | Kurt Cobain、Pearl Jam、Soundgarden |
| 关联风格 | Punk, Indie Sleaze, Soft Grunge, Pale Grunge |

## 历史脉络

### 从西雅图地下到全球主流

| 年份 | 事件 |
|------|------|
| 1988 | Sub Pop 唱片公司成立 |
| 1991 | Nirvana《Nevermind》发行——改变一切 |
| 1992 | Marc Jacobs "Grunge Collection" for Perry Ellis |
| 1993 | Grunge 成为全球青年文化 |
| 1994 | Kurt Cobain 去世 |
| 1997 | Grunge 作为音乐运动结束 |
| 2018 | Grunge Revival 开始 |

### 它反对什么？

| 80年代主流 | Grunge |
|-----------|--------|
| 华丽 | 邋遢 |
| 昂贵 | 二手店 |
| 完美 | 破损 |
| 快乐 | 愤怒/忧郁 |
| 消费主义 | 反消费 |
| "我很成功" | "我不在乎" |

### 核心哲学

Grunge 的精神是**"我不在乎你怎么看我——这就是我"**：
- 反时尚 = 最强的时尚宣言
- 穿二手衣不是因为穷——是因为不在乎
- 不完美是真实的
- 愤怒是合理的
- "与其假装快乐，不如诚实地痛苦"

## 视觉语法

### 色彩系统

```
主色：
  暗红 (#8B0000) — 法兰绒
  军绿 (#4B5320) — 军装外套
  黑色 (#000000) — T恤、靴子
  褪色蓝 (#6B8E9F) — 破洞牛仔
  棕色 (#8B4513) — 皮革、泥土

辅色：
  灰色 (#696969) — 混凝土、阴天
  米白 (#F5F5DC) — 旧T恤
  深紫 (#301934) — 暗色调

规则：
  - 低饱和度
  - 褪色、旧化
  - 不协调的搭配
  - "看起来像从地上捡的"
  - 暗色调为主

质感：
  法兰绒 — 格纹、柔软
  牛仔 — 破洞、褪色
  棉 — 旧T恤、松垮
  皮革 — 靴子、皮带
  毛线 — 松散、手工
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 上装 | 法兰绒衬衫、乐队T恤、军装外套 |
| 下装 | 破洞牛仔裤、工装裤 |
| 鞋 | Doc Martens、Converse、军靴 |
| 配饰 | 无、或极简（这就是重点） |
| 发型 | 不洗头、乱发、遮脸 |
| 态度 | 无所谓、愤怒、真实 |

## 与千禧怀旧的关系

### 90s 怀旧的核心
- Grunge = 90年代最具标志性的文化运动
- Kurt Cobain = 一代人的精神偶像
- 对千禧一代来说 = 童年/青少年的背景音乐
- Grunge Revival (2018–) = "我想回到那个更真实的时代"

### 后代风格
- Soft Grunge (2011–2015) = Tumblr 版
- Pale Grunge (2012–2016) = 更苍白的版本
- Grunge Revival (2018–) = Zara 版
- 每一代都重新诠释 Grunge

## 中国语境

- "垃圾摇滚风"/"颓废风"在中国的讨论
- 与中国独立摇滚/地下音乐的交叉
- 中国版：破洞牛仔+乐队T恤+不修边幅
- 对"精致"审美的反叛
- 摇滚乐迷的穿搭文化

## 设计应用

| 场景 | 应用方式 |
|------|----------|
| 品牌 | 粗糙字体+褪色+手写+反光滑 |

| 时尚 | 破损+层叠+二手+不协调 |
| 摄影 | 胶片颗粒+低对比+自然光+不修图 |
