# Minimalism 极简主义

> "Less is more." — Ludwig Mies van der Rohe
> "What you see is what you see." — Frank Stella

## 概述

极简主义（Minimalism）是1960年代在美国兴起的艺术运动，追求将艺术简化为最基本的形式和材料——去除一切叙事、象征、情感和装饰，只留下纯粹的物体存在。极简主义艺术品不"代表"任何东西，它就是它自己——一个方块就是一个方块，不是隐喻。

极简主义是对抽象表现主义主观情感的反叛，也是对波普艺术商业图像的拒绝——它追求一种冷静的、客观的、数学般的纯粹。

## 核心特征

| 特征 | 描述 |
|------|------|
| 极度简化 | 去除一切不必要的元素 |
| 几何形式 | 基本几何形——方、圆、线 |
| 工业材料 | 钢、铝、有机玻璃、荧光灯 |
| 重复序列 | 相同单元的系统性重复 |
| 去个性化 | 消除艺术家的手迹和情感 |
| 物体性 | 作品就是物体本身，不代表其他 |

## 视觉特征

- **形式**：纯粹的几何形——立方体、网格、条纹
- **色彩**：单色或极少色彩——黑、白、金属色
- **表面**：光滑的、工业的、无手工痕迹的表面
- **材料**：工业材料——钢板、荧光灯管、胶合板
- **空间**：作品与展示空间的关系
- **重复**：相同单元的系统性排列

## 代表人物

| 艺术家 | 代表作 | 特点 |
|--------|--------|------|
| Donald Judd | 金属方盒系列 | "特定物体"——不是绘画也不是雕塑 |
| Dan Flavin | 荧光灯管装置 | 光作为材料 |
| Carl Andre | 金属板地面雕塑 | 水平的、可踩踏的 |
| Frank Stella | 黑色条纹绘画 | "你看到的就是你看到的" |
| Sol LeWitt | 墙面绘画和立方体 | 概念先于执行 |
| Agnes Martin | 铅笔网格绘画 | 极简中的诗意和宁静 |
| Robert Morris | 灰色几何体 | 极简雕塑理论家 |

## 与其他风格的关系

- **De Stijl** → 蒙德里安的几何抽象是直接先驱
- **Bauhaus** → 包豪斯的"少即是多"理念
- **Abstract Expressionism** → 对抽象表现主义情感的反叛
- **Conceptual Art** → 概念艺术从极简主义发展而来
- **Japanese Aesthetics** → 侘寂美学的西方回响
- **Architecture** → 极简主义建筑（安藤忠雄）
