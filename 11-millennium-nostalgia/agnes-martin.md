# Agnes Martin 阿格尼丝·马丁

> "When I think of art, I think of beauty. Beauty is the mystery of life." — Agnes Martin

## 概述

阿格尼丝·马丁（Agnes Martin，1912–2004）是加拿大裔美国画家，以极其细腻的铅笔网格线和柔和的色彩薄层闻名。她的画面看似极简，实则充满微妙的手工颤动和冥想般的宁静，被视为极简主义与抽象表现主义之间的桥梁。

## 核心特征

| 特征 | 描述 |
|------|------|
| 铅笔网格 | 极细的手绘水平线与垂直线 |
| 柔和色层 | 淡粉、淡蓝、淡黄的薄涂 |
| 手工颤动 | 线条的微小不规则——人的呼吸 |
| 正方形画布 | 几乎所有作品都是6×6英尺正方形 |
| 冥想品质 | 观看即是静修 |
| 自然暗示 | 标题常指向自然——晨曦、露水、海洋 |

## 代表作品

| 作品 | 年代 | 意义 |
|------|------|------|
| *The Tree* | 1964 | 网格中的自然 |
| *Friendship* | 1963 | 金色箔片的温暖 |
| *Untitled #5* | 2001 | 晚期的纯粹宁静 |
| *Happy Holiday* | 1999 | 色带中的喜悦 |
