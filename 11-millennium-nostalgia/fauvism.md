# Fauvism 野兽派

![Fauvism 概念图](../assets/artworks/fauvism/fauvism-concept-01.png)

> **"颜色不需要'正确'——红色的树、蓝色的脸——颜色本身就是表达。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1904–1908/影响至今 |
| 别名 | Fauvism, Les Fauves, 野兽派 |
| 核心色彩 | 非自然的纯色、高饱和、大胆对比 |
| 关键元素 | 纯色平涂、简化形体、非自然用色、情绪化色彩 |
| 代表人物 | Henri Matisse, André Derain, Maurice de Vlaminck, Raoul Dufy |
| 关联风格 | Expressionism, Post-Impressionism, Abstract Art, Color Field |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1904 | Matisse 在南法开始用纯色实验 |
| 1905 | 秋季沙龙——评论家称他们为"野兽"(Les Fauves) |
| 1906 | Derain 的伦敦系列——野兽派巅峰 |
| 1907 | 野兽派开始分化——Matisse走向装饰性 |
| 1908 | 野兽派作为运动结束——但精神延续 |
| 2020s | Matisse 的剪纸成为当代设计灵感 |

### 核心哲学

野兽派的精神是**"色彩从描述中解放——色彩本身就是主题"**：
- 色彩 = 自由（"树不一定是绿色的——如果我感觉它是红色的"）
- 简化 = 力量（"不需要细节——色块就够了"）
- 快乐 = 合法（"艺术可以只是快乐——不需要沉重"）
- 直觉 = 真实（"不思考颜色——感受颜色"）
- Matisse: "我梦想一种平衡、纯净、宁静的艺术"

## 视觉语法

### 色彩系统

```
主色：
  纯红 (#FF0000) — 热情、生命
  纯蓝 (#0000FF) — 天空、自由
  纯黄 (#FFFF00) — 阳光、快乐
  纯绿 (#00FF00) — 自然、活力

辅色：
  橙色 (#FF8C00) — 温暖
  紫色 (#800080) — 对比
  粉色 (#FF69B4) — 柔和

规则：
  - 直接从管中挤出的纯色
  - 非自然用色（蓝色脸、红色树）
  - 色彩对比而非和谐
  - 平涂而非渐变
  - 色彩 = 情绪，不是描述

质感：
  平涂 — 大面积纯色
  粗笔触 — 快速、直接
  简化 — 去除细节
  装饰 — Matisse后期
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 色彩 | 非自然纯色、高饱和、大胆对比 |
| 形体 | 简化、平面化、装饰性 |
| 笔触 | 粗放、直接、可见 |
| 题材 | 风景、人物、室内、静物 |
| 态度 | 快乐、自由、直觉、大胆、装饰 |
| 遗产 | Matisse剪纸 → 当代平面设计 |

## 与千禧怀旧的关系

### Matisse 剪纸的当代设计影响
- Matisse 的剪纸 = 当代平面设计的灵感源泉
- "有机形状+纯色" = 2020s设计趋势
- 野兽派的"快乐色彩" → 当代品牌设计
- "野兽派教会了设计师：色彩可以不'正确'——只要它'感觉对'"

### 色彩解放的遗产
- 野兽派 → 表现主义 → 抽象 → 当代一切
- "没有野兽派——就没有色彩的自由"
- 当代插画中的"大胆用色" = 野兽派的后代
