# Kidcore

> **别名**：Toycore, 90s Kid Aesthetic, Rainbow Aesthetic  
> **活跃年代**：2019 – 至今（作为怀旧美学）；怀念对象为 1990s – 2000s 童年  
> **核心平台**：TikTok、Tumblr、独立时尚品牌、Depop

![Kidcore 概念图](../assets/artworks/kidcore/kidcore-concept-01.png)

---

## 一句话定义

Kidcore 是对 **90 年代/2000 年代初童年视觉文化**的极致怀旧——用原色积木、Lisa Frank 彩虹、塑料玩具、卡通贴纸和游乐场色彩，重建一个成年人已经失去的"一切都很简单"的世界。

| 字体 | 手写体、蜡笔字、积木字母、Comic Sans |

### 色彩系统详解

Kidcore 的色彩使用有严格的（虽然是直觉性的）规则：

**必须使用的色彩**：
- 纯红（消防车红）、纯黄（向日葵黄）、纯蓝（天空蓝）
- 草绿、橙色、紫色——完整彩虹光谱
- 粉色（泡泡糖粉，非千禧粉）

**绝对禁止的色彩**：
- 黑色（除非是轮廓线）
- 灰色（任何灰度都暗示"成人世界"）
- 米色/卡其色（"办公室色"）
- 任何降低饱和度的处理

**与其他彩色美学的区别**：
| 美学 | 色彩特征 |
|------|----------|
| Kidcore | 纯原色，无渐变，像蜡笔盒 |
| McBling | 粉+金+水钻反光 |
| Frutiger Aero | 渐变+透明+光泽 |
| Vaporwave | 粉+青+紫，带噪点 |

## 文化内核

### 拒绝长大

Kidcore 的核心情感是**对成年世界的温和抗议**。在一个要求你"专业"、"极简"、"成熟"的社会中，穿一件彩虹毛衣、背一个卡通书包，是一种微小但真实的反叛。

这不是 Peter Pan 综合征（拒绝承担责任），而是一种**审美层面的自我保护**：承认成年生活的压力，但选择在视觉环境中保留一个"安全空间"。

### 90s 童年的物质文化

Kidcore 怀念的不是抽象的"童年"，而是非常具体的**物质记忆**：

**文具与学校**：
- Lisa Frank 的彩虹海豚文具套装
- Crayola 64 色蜡笔盒（带削笔器）
- 果味橡皮擦（闻起来像草莓但不能吃）
- Trapper Keeper 活页夹

**玩具与游戏**：
- Fisher-Price 的红黄蓝塑料玩具
- 麦当劳开心乐园餐的玩具
- Tamagotchi / 拓麻歌子
- Polly Pocket / Mighty Max
- Beanie Babies 豆豆公仔

**电视与媒体**：
- Nickelodeon 的橙色 slime
- PBS Kids 的彩色方块
- Disney Channel 的魔杖 logo
- *Teletubbies* 的圆润世界

**空间与环境**：
- 学校里的彩色塑料椅子
- 麦当劳 PlayPlace 游乐区
- Discovery Zone / Chuck E. Cheese
- IKEA 儿童区（Småland）

### 与极简主义的对抗

Kidcore 在审美上是对 2010s 极简主义的直接反动：

| 极简主义 | Kidcore |
|----------|---------|
| 黑白灰 | 彩虹全色 |
| 少即是多 | 多即是多 |
| 成熟克制 | 天真放肆 |
| 功能优先 | 快乐优先 |
| 隐藏接缝 | 暴露结构 |
| 无品牌 | 品牌 logo 作为装饰 |
| 数字化 | 物质化/触觉化 |

### 疫情加速器

COVID-19 疫情对 Kidcore 的爆发起到了关键催化作用：
- 人们被困在家中，渴望"安全"和"舒适"的视觉环境
- 童年记忆成为心理避难所
- *Animal Crossing: New Horizons*（2020年3月发售）提供了一个可以实践 Kidcore 的虚拟空间
- 居家办公模糊了"专业"和"个人"的边界，人们开始在工作空间中加入玩具和彩色物品

## 时尚实践

### 服装

- **上衣**：彩色条纹毛衣、卡通印花T恤、oversize 连帽衫
- **下装**：彩色灯芯绒裤、牛仔背带裤、彩虹短裙
- **鞋**：Crocs（挂满 Jibbitz 装饰）、彩色 Converse、平台鞋
- **配饰**：串珠手链、发夹墙、徽章/别针、卡通耳环

### 空间设计

- **墙面**：彩色挂毯、贴纸墙、LED 彩灯
- **家具**：彩色塑料椅、豆袋沙发、地毯拼图
- **收纳**：透明塑料盒展示玩具收藏
- **桌面**：文具收纳、贴纸、彩色便签

### 数字空间

- *Animal Crossing* 岛屿设计
- 手机壳（透明壳+内置贴纸/小玩具）
- 社交媒体配色和排版
- Notion 模板和桌面壁纸

## 中国语境

在中国，Kidcore 有独特的本土记忆对应物：

- **大白兔奶糖**的蓝白红包装
- **小霸王学习机**的彩色卡带
- **旺旺**系列产品的卡通形象
- **奥特曼**和**数码宝贝**的周边文具
- **学校门口小卖部**的一元玩具
- **QQ 宠物**和**摩尔庄园**的虚拟童年

2020 年代中国的"多巴胺穿搭"热潮与 Kidcore 高度重合，但更强调色彩搭配的"高级感"，试图在童趣和时尚之间找到平衡。

## 争议与批评

### "消费主义怀旧"

批评者指出，Kidcore 本质上是对**品牌化童年**的怀旧——Lisa Frank、Fisher-Price、McDonald's 都是商业品牌。怀念它们是否等于怀念消费主义本身？

### "特权化的童年"

并非所有人的 90s 童年都充满 Lisa Frank 和 McDonald's PlayPlace。Kidcore 呈现的是一种**中产阶级、西方中心**的童年想象，可能排斥了其他文化和经济背景的童年经验。

### 年龄焦虑

Kidcore 的流行是否反映了一种更深层的**社会性年龄焦虑**？当成年生活越来越不确定（经济压力、气候焦虑、政治动荡），退回童年美学是一种健康的自我调节，还是一种逃避？
