# Bobbin Lace 棒针蕾丝

> "Bobbin lace is weaving in miniature — dozens of threads dance on a pillow, crossing and twisting into frozen lace." — Unknown

## 概述

棒针蕾丝（Bobbin Lace）是将多根线缠绕在木质或骨质棒针（bobbin）上，通过在枕垫上交叉、扭转这些线来编织蕾丝的传统手工艺。与梭编或钩针蕾丝不同，棒针蕾丝同时操作数十甚至数百根线——每根线都缠绕在自己的棒针上，棒针的重量提供张力。图案通过在枕垫上插针来引导线的走向。这是最复杂、最耗时的蕾丝制作技法之一。

棒针蕾丝的魅力在于：有序的复杂性——数十根线在看似混乱中遵循精确的规则交织，如同一场精心编排的舞蹈。

## 核心特征

| 特征 | 描述 |
|------|------|
| 多线 | 同时操作多根线 |
| 棒针 | 使用加重的棒针 |
| 枕垫 | 在枕垫上工作 |
| 交叉 | 线的交叉与扭转 |
| 插针 | 用针固定图案点 |
| 复杂 | 极其复杂的工艺 |

## 视觉特征

- **精细**：极其精细的线条
- **通透**：通透的网状结构
- **流动**：流动的曲线图案
- **对称**：对称的重复图案
- **轻盈**：轻盈如蛛网
- **优雅**：优雅精致的整体效果

## 中国语境

棒针蕾丝在中国是相对小众的手工艺。中国传统上没有西方意义上的蕾丝传统，但有类似的精细编织技法——如抽纱（drawn thread work）和花边编织。近代以来，山东烟台、浙江萧山等地发展了出口蕾丝产业。当代中国有一小群热情的棒针蕾丝爱好者，通过网络社区学习和交流这一古老的欧洲技艺。
