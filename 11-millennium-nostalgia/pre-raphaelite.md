# Pre-Raphaelite Brotherhood 前拉斐尔派

> "Have no master but Nature." — Pre-Raphaelite Brotherhood motto

## 概述

前拉斐尔兄弟会（Pre-Raphaelite Brotherhood, PRB）是1848年由三位年轻的英国画家——但丁·加百利·罗塞蒂（Dante Gabriel Rossetti）、约翰·埃弗里特·米莱（John Everett Millais）和威廉·霍尔曼·亨特（William Holman Hunt）——在伦敦创立的艺术运动。

他们反对皇家美术学院推崇的拉斐尔以后的学院派传统，主张回到拉斐尔之前（Pre-Raphael）的中世纪和早期文艺复兴的真诚与细致，追求对自然的绝对忠实、宝石般的色彩和文学性的叙事主题。

## 核心特征

| 特征 | 描述 |
|------|------|
| 自然忠实 | 对每一片叶子、每一根草的绝对精确描绘 |
| 宝石色彩 | 在湿白底上作画产生的透明宝石般色彩 |
| 文学叙事 | 莎士比亚、丁尼生、亚瑟王传说等文学题材 |
| 中世纪迷恋 | 对中世纪骑士、淑女和宗教的浪漫化 |
| 女性形象 | 红发、苍白、忧郁的理想化女性 |
| 道德目的 | 艺术应当有道德和精神意义 |

## 视觉特征

- **色彩**：宝石般的饱和色——翡翠绿、红宝石红、群青蓝
- **细节**：显微镜般的自然细节——每片叶子都可辨认
- **光线**：均匀的、无阴影的明亮光线
- **构图**：密集的、充满象征物的画面
- **人物**：苍白皮肤、红色长发、忧郁表情的女性
- **背景**：精确描绘的英国乡村或中世纪场景

## 代表人物

| 画家 | 代表作 | 特点 |
|------|--------|------|
| Dante Gabriel Rossetti | *Beata Beatrix*, *Proserpine* | 神秘的女性肖像 |
| John Everett Millais | *Ophelia*, *Christ in the House of His Parents* | 最精确的自然描绘 |
| William Holman Hunt | *The Light of the World*, *The Awakening Conscience* | 最虔诚的道德画家 |
| Edward Burne-Jones | *The Golden Stairs*, *King Cophetua* | 第二代——走向装饰性 |
| John William Waterhouse | *The Lady of Shalott*, *Hylas and the Nymphs* | 晚期——古典神话 |
| William Morris | 装饰设计、壁纸、家具 | 艺术与工艺运动 |

## 影响与遗产

- **Arts and Crafts Movement** → William Morris 将 PRB 理念延伸到设计
- **Art Nouveau** → 曲线和自然图案的灵感来源
- **Symbolism** → 象征主义的英国先驱
- **Aesthetic Movement** → "为艺术而艺术"的英国版本
- **Fantasy Art** → 当代奇幻插画的直接祖先

## 与其他风格的关系

- **Art Nouveau** → PRB 的装饰性直接影响了新艺术运动
- **Symbolism** → 共享文学性和神秘主义
- **Romanticism** → 浪漫主义的英国延续
- **Gothic Revival** → 共享对中世纪的迷恋
- **Mucha** → 穆夏的女性形象受 PRB 影响
- **Arts and Crafts** → Morris 将 PRB 延伸到装饰艺术
