# Photorealism 照相写实主义

> "I wanted to make something that was more real than real." — Chuck Close

## 概述

照相写实主义（Photorealism / Hyperrealism / Super Realism）是1960年代末至1970年代在美国兴起的绘画和雕塑运动，艺术家以照片为基础，创作出与照片难以区分的极度精细的绘画作品。

照相写实主义不是简单的"画得像照片"——它是对摄影视觉本身的绘画再现，包括景深、焦点模糊、镜头畸变、反光等摄影特有的视觉效果。它质疑了绘画与摄影的关系，也挑战了抽象艺术对具象的排斥。

## 核心特征

| 特征 | 描述 |
|------|------|
| 照片基础 | 以照片（而非实物）为绘画参考 |
| 极度精细 | 超越肉眼的细节精度 |
| 摄影视觉 | 再现镜头特有的视觉效果 |
| 客观冷静 | 排除情感表达和笔触个性 |
| 技术至上 | 极端的技术控制力 |
| 日常题材 | 街景、汽车、商店橱窗、人像 |

## 视觉特征

- **精度**：每一个细节都精确到像素级
- **反光**：金属、玻璃、水面的完美反射
- **焦点**：摄影式的景深——前景清晰背景模糊
- **尺度**：通常是大尺幅——放大照片的效果
- **笔触**：完全隐藏——看不到任何手工痕迹
- **题材**：城市街景、汽车、肖像、静物

## 代表作品

| 作品 | 艺术家 | 年代 | 意义 |
|------|--------|------|------|
| *Big Self-Portrait* | Chuck Close | 1968 | 巨型肖像——照相写实的标志 |
| *'61 Pontiac* | Robert Bechtle | 1968-69 | 美国郊区的平凡诗意 |
| *Diner* | Richard Estes | 1971 | 城市反光的极致再现 |
| *Blue Vase* | Audrey Flack | 1973 | 静物的照相写实——女性视角 |
| *Supermarket Lady* | Duane Hanson | 1969 | 超写实雕塑——令人不安的真实 |
| *Self-Portrait* | Ron Mueck | 2000s | 变换尺度的超写实人体雕塑 |

## 中国语境

照相写实主义在中国有广泛的实践。冷军被认为是中国超写实绘画的代表，他的静物画精细程度令人惊叹。中国美术学院体系对写实基本功的强调为照相写实提供了技术基础。然而，中国的照相写实也面临"炫技"的批评——极致的技术是否等于艺术的深度？在AI可以生成照片级图像的今天，手工照相写实的意义需要重新思考。

## 与其他风格的关系

- **Pop Art** → 波普艺术对日常图像的关注是照相写实的先驱
- **Minimalism** → 极简主义的客观冷静影响了照相写实的态度
- **Conceptual Art** → 概念艺术质疑再现——照相写实回应这一质疑
- **Realism** → 写实主义传统的极端化
- **Digital Art** → 数字渲染的超写实是新的挑战
- **Photography** → 摄影是照相写实的参照和对话对象
