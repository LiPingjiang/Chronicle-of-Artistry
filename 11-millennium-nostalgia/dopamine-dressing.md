# Dopamine Dressing 多巴胺穿搭

![Dopamine Dressing 概念图](../assets/artworks/dopamine-dressing/dopamine-dressing-concept-01.png)

> **"穿上让你快乐的颜色——时尚的目的是让自己开心。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2021–至今 |
| 别名 | Dopamine Dressing, Joy Dressing, Color Blocking |
| 核心色彩 | 全色谱高饱和度——粉、黄、绿、蓝、橙 |
| 关键元素 | 高饱和色彩、大胆撞色、快乐、自我表达 |
| 代表人物 | Valentino, Bottega Veneta, Versace |
| 关联风格 | Maximalism, Barbiecore, Clowncore, Y2K |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1960s | Mod 运动——色彩解放 |
| 1980s | Power Dressing——色彩=力量 |
| 2021 | 疫情后"报复性穿搭"——Dopamine Dressing 命名 |
| 2022 | Valentino Pink PP——单色高饱和度 |
| 2023 | Barbiecore 粉色浪潮 |
| 2024 | 持续流行，与 Maximalism 融合 |

### 核心哲学

Dopamine Dressing 的精神是**"颜色可以改变心情——穿快乐的颜色，成为快乐的人"**：
- 色彩 = 情绪调节工具
- 穿衣 = 自我疗愈（"今天需要黄色"）
- 快乐 > 时尚规则（"不需要'搭配'"）
- 对疫情灰暗的反弹
- "如果穿黑色让你开心，那也是 Dopamine Dressing"

## 视觉语法

### 色彩系统

```
主色：
  所有高饱和度颜色都可以：
  粉色 (#FF69B4) — Barbiecore
  黄色 (#FFD700) — 阳光、快乐
  绿色 (#00FF00) — Bottega Green
  蓝色 (#0066FF) — Klein Blue
  橙色 (#FF6600) — 活力
  紫色 (#9B59B6) — 创意
  红色 (#FF0000) — 力量

规则：
  - 高饱和度
  - 大面积单色 或 大胆撞色
  - 没有"太亮"
  - 没有"不搭配"
  - 快乐是唯一标准

质感：
  光滑 — 缎面、皮革
  蓬松 — 羽毛、毛绒
  结构 — 建筑感剪裁
  流动 — 丝绸、雪纺
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 色彩 | 单色全身、大胆撞色、渐变 |
| 服装 | 彩色西装、亮色连衣裙、彩色包 |
| 配饰 | 彩色太阳镜、亮色鞋、大耳环 |
| 品牌 | Valentino PP Pink、Bottega Green |
| 态度 | 快乐、大胆、自信、不解释 |
| 禁忌 | 没有禁忌——"如果让你开心就穿" |

## 与千禧怀旧的关系

### 疫情后的色彩反弹
- 2020 疫情 = 居家、灰色、无聊
- 2021 解封 = "我要穿最亮的颜色出门"
- Dopamine Dressing = 集体情绪的视觉表达
- 从"生存模式"到"快乐模式"

### 与 Quiet Luxury 的对立
- Quiet Luxury = 低调、驼色、无Logo
- Dopamine Dressing = 高调、彩色、大胆
- 两者同时流行 = 时尚的"分裂"
- "你选哪边？"——答案是"看心情"
