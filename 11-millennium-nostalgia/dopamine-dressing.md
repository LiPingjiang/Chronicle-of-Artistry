## 历史脉络

### 2021–2022：后疫情的色彩爆发

Dopamine Dressing 在 2021 年后疫情时代爆发，是对两年灰暗封城生活的**直接反弹**：

**疫情期间（2020–2021）**：
- 居家穿搭 = 灰色运动裤、黑色T恤
- 心情低落 = 穿着也低调
- 极简主义/Normcore 达到顶峰

**后疫情（2021–2022）**：
- "我要把失去的快乐穿回来"
- 色彩心理学研究被大量引用：鲜艳色彩确实能提升情绪
- Valentino 2022 秋冬全粉色系列成为文化事件
- Harry Styles 的彩色西装成为男性 Dopamine Dressing 标杆

### 文化基因

| 来源 | 贡献 |
|------|------|
| 色彩心理学 | 科学背书：颜色影响情绪 |
| 70s Disco | 亮片、彩色、"穿出去跳舞" |
| 80s Power Dressing | 大胆色彩 = 自信 |
| Kidcore | 童年的彩虹色 = 快乐 |
| 非洲时尚 | 大胆印花和色彩的传统 |

### 2022–2023：高峰

- Valentino "PP Pink" 系列：全粉色成为年度色彩事件
- Bottega Veneta 的"Bottega Green"：品牌色成为身份标识
- Pantone 年度色彩 "Viva Magenta" (2023)
- "全身单色"穿搭成为 TikTok 热门格式

## 视觉语法

### 色彩系统

```
规则：没有"禁忌色"——一切高饱和色都是好色

经典 Dopamine 色：
  电光蓝 (#0000FF)
  荧光粉 (#FF69B4)
  柠檬黄 (#FFF44F)
  翠绿 (#00FF7F)
  橙红 (#FF4500)
  紫罗兰 (#8B00FF)

搭配方式：
  1. 全身单色（monochrome）— 从头到脚同一色
  2. 撞色（color blocking）— 2-3种高饱和色拼接
  3. 彩虹渐变 — 多色渐变
  4. 互补色 — 蓝+橙、紫+黄

禁忌：
  - 不要"安全"
  - 不要"低调"
  - 不要"百搭"
  - 不要灰色/米色/黑色（除非是全黑的极端版本）
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 穿搭 | 全身单色套装、撞色搭配、彩色西装 |
| 配饰 | 彩色包、彩色墨镜、彩色珠宝 |
| 鞋 | 彩色运动鞋、彩色高跟鞋 |
| 妆容 | 彩色眼影、彩色唇色、彩色腮红 |
| 指甲 | 每指不同色、彩虹渐变 |
| 空间 | 彩色墙壁、彩色家具、彩色厨具 |

## 与千禧怀旧的关系

### 2000s 色彩的回归
- 2000s McBling 的鲜艳色彩 → Dopamine Dressing 的直接前身
- iPod 的彩色广告 → 色彩=快乐=年轻的等式
- 2000s 的 Juicy Couture 彩色运动套装 → 2022 的全身单色

### 对 2010s 极简的反动
- 2010s：黑白灰+极简+Normcore → "成熟"
- 2020s：彩虹色+极繁+Dopamine → "快乐比成熟重要"

## 中国语境

- **"多巴胺穿搭"**：2023年小红书/抖音最热穿搭标签之一
- 中国版 Dopamine Dressing 更偏向糖果色和马卡龙色

- 彩色防晒衣在中国夏季的流行
- "穿出好心情"的消费心理
