# Persian Miniature 波斯细密画

> **"画中有诗，诗中有画——波斯细密画是文字与图像的永恒婚姻。"**

## 概述

波斯细密画（نگارگری ایرانی / Persian Miniature）是伊朗/波斯文明中最精致的视觉艺术传统，起源于13世纪蒙古入侵后的伊尔汗国时期，在帖木儿王朝（15世纪赫拉特）和萨法维王朝（16–17世纪伊斯法罕）达到巅峰。这些小尺幅的精美画作主要作为手抄本插图存在，为《列王纪》（Shahnameh）、《五卷诗》（Khamsa）等波斯文学经典赋予视觉生命。

## 时间线

| 年份 | 事件 |
|------|------|
| 13世纪 | 伊尔汗国时期，中国绘画技法传入波斯 |
| 1370–1507 | 帖木儿王朝，赫拉特画派黄金时代 |
| 1430s | Behzād 大师活跃，被誉为"波斯的拉斐尔" |
| 1501–1736 | 萨法维王朝，大不里士和伊斯法罕画派 |
| 16世纪 | 影响莫卧儿印度和奥斯曼土耳其细密画 |
| 17世纪 | 受欧洲影响，开始出现透视和明暗法 |
| 当代 | 伊朗当代艺术家重新诠释细密画传统 |

## 核心特征

- **手抄本插图**：为诗歌和史诗提供视觉叙事
- **鸟瞰视角**：多重视点并存，无单一消失点
- **平面化空间**：装饰性优先于写实透视
- **极致精细**：单根毛笔绘制的微小细节
- **鲜艳色彩**：矿物颜料（青金石蓝、朱砂红、金箔）
- **花园意象**：波斯花园（Pardis）作为天堂的隐喻

## 代表画派

| 画派 | 时期 | 特征 |
|------|------|------|
| 大不里士画派 | 14世纪 | 中国影响，动态构图 |
| 赫拉特画派 | 15世纪 | Behzād 的人文主义巅峰 |
| 伊斯法罕画派 | 16–17世纪 | 萨法维宫廷的奢华精致 |
| 设拉子画派 | 14–16世纪 | 商业化生产，色彩明快 |

## 视觉特征

- 精美的装饰边框（hashiye）
- 岩石、云朵的程式化表现（中国影响）
- 建筑空间的展开式描绘（同时看到室内外）
- 人物的理想化面容和优雅姿态
- 花卉地毯般的草地
- 金色天空和彩色云朵

## 与其他风格的关系

| 风格 | 关系 |
|------|------|
| 中国工笔画 | 蒙古时期传入的云纹、岩石画法 |
| 莫卧儿细密画 | 直接后裔，波斯画家赴印度宫廷 |
| 奥斯曼细密画 | 平行发展，互相影响 |
| 拉斐尔前派 | 共享对细节和色彩的极致追求 |
| 当代伊朗艺术 | Shirin Neshat 等重新诠释传统 |
