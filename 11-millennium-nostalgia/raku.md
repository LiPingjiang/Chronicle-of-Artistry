# Raku 乐烧

> "In raku, the fire decides — the potter can only prepare and accept." — Paul Soldner

## 概述

乐烧（Raku/楽焼）是一种源自16世纪日本茶道文化的陶瓷烧制技法——将陶器在高温窑中快速烧制后立即取出，放入可燃材料中进行还原反应，产生独特的金属光泽、裂纹和烟熏效果。每一件乐烧作品都是火、烟和偶然的共同创作——不可预测、不可复制、充满生命力。

乐烧的精神在于"接受偶然"——陶艺家准备好一切，然后将最终的决定权交给火。

## 核心特征

| 特征 | 描述 |
|------|------|
| 快速 | 快速烧制和冷却 |
| 还原 | 在可燃材料中还原 |
| 偶然 | 不可预测的效果 |
| 裂纹 | 热冲击产生的裂纹 |
| 金属光泽 | 还原产生的金属色 |
| 唯一 | 每件都独一无二 |

## 视觉特征

- **裂纹**：热冲击产生的细密裂纹
- **金属**：铜色、金色的金属光泽
- **烟熏**：黑色烟熏的痕迹
- **对比**：光泽与哑光的对比
- **不规则**：有意的不规则形态
- **质感**：丰富的表面质感

## 中国语境

乐烧在中国的陶瓷艺术圈中有一定的实践和关注。中国传统陶瓷虽然没有乐烧的传统，但中国的"窑变"概念——窑火中的偶然变化产生意外之美——与乐烧的精神有深刻的相通。中国当代陶艺家中有人实践乐烧技法，将其与中国陶瓷传统结合。景德镇等陶瓷产区也有乐烧的工作坊和教学。

## 与其他风格的关系

- **Wabi-sabi** → 侘寂美学是乐烧的精神基础
- **Ceramics** → 陶瓷是乐烧的上位类别
- **Tea Ceremony** → 茶道是乐烧的文化背景
- **Kintsugi** → 金缮与乐烧有接受不完美的共同哲学
- **Experimental Art** → 乐烧鼓励实验和偶然
- **Fire Art** → 火是乐烧的核心元素
