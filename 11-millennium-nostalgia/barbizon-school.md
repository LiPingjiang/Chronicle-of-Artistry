# Barbizon School 巴比松画派

> "Go to the country — the muse is in the woods." — Théodore Rousseau

## 概述

巴比松画派（École de Barbizon）是1830–1870年代活跃于法国枫丹白露森林边巴比松村的一群风景画家。他们拒绝学院派的历史风景画传统，转而直接面对自然——在户外写生，忠实记录法国乡村的树木、池塘、农田和天空。

巴比松画派是从浪漫主义到印象派的关键桥梁——他们开创了户外写生的传统，将"普通风景"提升为值得描绘的主题，直接启发了莫奈、雷诺阿等印象派画家。

## 核心特征

| 特征 | 描述 |
|------|------|
| 户外写生 | 在自然中直接观察和写生 |
| 普通风景 | 拒绝理想化，描绘真实的法国乡村 |
| 自然崇拜 | 对自然的深厚情感和敬畏 |
| 反学院派 | 拒绝历史风景画的人工构图 |
| 光线研究 | 对不同时间和天气光线的观察 |
| 农民题材 | 米勒等人描绘农民的劳动和生活 |

## 视觉特征

- **色调**：深绿、褐色、灰色的朴素色调
- **光线**：柔和的、真实的自然光
- **树木**：枫丹白露森林的橡树是核心题材
- **天空**：真实的云层和大气效果
- **笔触**：比学院派更自由，但仍较克制
- **构图**：自然的、非人工安排的构图

## 代表人物

| 画家 | 代表作 | 特点 |
|------|--------|------|
| Théodore Rousseau | 枫丹白露森林风景 | 画派领袖，"风景画的拉斐尔" |
| Jean-François Millet | *The Gleaners*, *The Angelus* | 农民画家——劳动的尊严 |
| Jean-Baptiste-Camille Corot | 意大利和法国风景 | 最抒情的风景画家 |
| Charles-François Daubigny | 瓦兹河风景 | 在船上写生——最接近印象派 |
| Narcisse Díaz de la Peña | 森林内部光影 | 色彩最丰富的成员 |
| Constant Troyon | 牛群和动物 | 动物画大师 |

## 历史背景

1. **1830年代**：画家们开始聚集在巴比松村
2. **1848年革命**：社会变革推动了对农民题材的关注
3. **1850–60年代**：画派鼎盛期
4. **1863年**：落选者沙龙——新一代（印象派）崛起
5. **1870年代**：巴比松画家获得官方认可，但印象派已超越他们

## 与其他风格的关系

- **Impressionism** → 印象派的直接先驱——户外写生传统
- **Romanticism** → 从浪漫主义的自然崇拜发展而来
- **Realism** → 与库尔贝的现实主义同时代
- **Constable** → 受英国风景画家康斯太勃尔影响
- **Plein Air** → 法国户外写生运动的开创者
- **Tonalism** → 美国色调主义受巴比松影响
