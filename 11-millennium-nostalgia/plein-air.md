# Plein Air 户外写生

> "The sun will not wait for you to finish your painting." — Claude Monet

## 概述

户外写生（Plein Air，法语"在户外"）是直接在自然环境中完成绑画创作的艺术实践——不是在画室里根据素描或记忆创作，而是面对真实的风景、光线和天气，在现场完成作品。19世纪中叶，便携式颜料管和折叠画架的发明使户外写生成为可能，印象派画家将其推向了艺术革命的高度。

户外写生的精神在于：直面自然——没有中介、没有记忆的过滤、没有画室的安全感，只有你和不断变化的光线之间的赛跑。

## 核心特征

| 特征 | 描述 |
|------|------|
| 户外 | 在自然环境中创作 |
| 即时 | 捕捉即时的光线和氛围 |
| 速度 | 需要快速完成 |
| 光线 | 对自然光线的敏感 |
| 便携 | 使用便携式绘画工具 |
| 真实 | 直接面对真实场景 |

## 视觉特征

- **光线**：自然光线的真实记录
- **色彩**：户外色彩的鲜明和丰富
- **笔触**：快速的、即兴的笔触
- **氛围**：特定时刻的氛围感
- **自然**：自然场景的直接描绘
- **生动**：现场创作的生动感

## 中国语境

户外写生在中国美术教育中是必修课——"下乡写生"是中国美术学院的传统。中国的油画写生有深厚的传统，从早期留法画家到当代写实画家。中国传统绘画中也有"师法自然"的传统——虽然中国画家更多是"目识心记"而非现场完成。当代中国的户外写生活动非常活跃，各地有大量的写生基地和写生团体。

## 与其他风格的关系

- **Impressionism** → 印象派是户外写生的巅峰
- **Landscape Painting** → 风景画是户外写生的主要题材
- **Watercolor** → 水彩是户外写生的便携媒介
- **Realism** → 写实主义追求真实的户外观察
- **Post-Impressionism** → 后印象派继承了户外传统
- **Photography** → 摄影与户外写生有记录相似
