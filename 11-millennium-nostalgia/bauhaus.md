![Bauhaus 概念图](../assets/artworks/bauhaus/bauhaus-concept-01.png)

> **"形式追随功能、三原色、几何基本形——现代设计从这里开始。"**

## 历史脉络

### 从魏玛到全世界

| 年份 | 事件 |
|------|------|
| 1919 | Walter Gropius 在魏玛创立包豪斯学校 |
| 1923 | "艺术与技术——新的统一" |
| 1925 | 迁至德绍——标志性校舍建成 |
| 1928 | Mies van der Rohe 接任校长 |
| 1933 | 纳粹关闭包豪斯 |
| 1937 | 教师流亡美国——影响全球 |
| 2019 | 包豪斯100周年——全球纪念 |

### 核心哲学

Bauhaus 的精神是**"形式追随功能——艺术与工业的统一"**：
- 没有"纯艺术"和"工艺"的等级
- 好的设计应该人人可及
- 几何 = 理性 = 普遍
- 去掉装饰——留下本质
- "少即是多"（Mies van der Rohe）

## 视觉语法

### 色彩系统

```
主色：
  红色 (#FF0000) — 正方形
  黄色 (#FFFF00) — 三角形
  蓝色 (#0000FF) — 圆形
  黑色 (#000000) — 线条、文字
  白色 (#FFFFFF) — 背景

规则：
  - 三原色为主
  - 几何形状对应颜色
  - 高对比度
  - 不用装饰色
  - 色彩有功能/象征意义

质感：
  光滑 — 钢管、玻璃
  哑光 — 混凝土、纸
  金属 — 钢、铬
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 形状 | 圆、方、三角——三个基本形 |
| 字体 | Universal (Bayer)、无衬线、几何 |
| 家具 | 钢管椅（Breuer）、巴塞罗那椅 |
| 建筑 | 玻璃幕墙、平屋顶、白墙 |
| 布局 | 不对称、网格、功能分区 |
| 材料 | 钢、玻璃、混凝土 |

## 与千禧怀旧的关系

### 现代设计的DNA
- 包豪斯 = 现代设计教育的起点
- 每个设计学生都学过包豪斯
- 它的原则仍然是当代设计的基础
- 2019年百年纪念引发新一轮关注

### 对当代的影响
- Flat Design = 包豪斯在数字时代的回响
- Apple 设计 = Dieter Rams = 包豪斯传承
- 极简主义 = 包豪斯"少即是多"的延续
- Swiss Design/国际主义 = 包豪斯的直系后代
