# Alla Prima 一次完成法

> "Get it right the first time." — Alla Prima 的核心精神

## 概述

一次完成法（Alla Prima，意大利语"一次性"之意，又称 wet-on-wet、直接画法）是指在颜料未干时一次性完成整幅画作的技法，不等待底层干燥、不分多次叠加。画家必须在一次作画过程中（通常数小时内）解决所有问题——构图、明暗、色彩、细节。

这一技法要求极高的技术熟练度和决断力，是印象派以来最主流的油画创作方式，也是当代写生和肖像画的标准方法。

## 核心特征

| 特征 | 描述 |
|------|------|
| 一次完成 | 在颜料湿润时一气呵成 |
| 湿压湿 | 新颜料直接覆盖在湿颜料上 |
| 即时决断 | 每一笔都是最终效果，无法修改 |
| 新鲜感 | 保留了创作瞬间的活力和自发性 |
| 色彩混合 | 颜料在画布上直接混合 |
| 速度 | 通常在一个session内完成（2-6小时） |

## 视觉特征

- **笔触**：自信有力、一次到位的笔触
- **色彩**：湿压湿产生的自然色彩过渡
- **边缘**：柔和的湿边和锐利的干边并存
- **新鲜感**：画面保留了创作的即时活力
- **厚度**：通常比多层画法更厚
- **统一性**：整体色调和谐（同时完成的优势）

## 技法要点

| 要点 | 描述 |
|------|------|
| 预混色 | 开始前在调色板上预混所有需要的色调 |
| 大到小 | 先铺大色块，再逐步细化 |
| 暗到亮 | 通常先画暗部，再画亮部 |
| 果断下笔 | 每一笔都要准确，避免反复涂改 |
| 控制时间 | 在颜料干燥前完成所有工作 |
| 介质选择 | 可加入慢干介质延长工作时间 |

## 历史演变

1. **17世纪**：Frans Hals 开创了快速直接的肖像画法
2. **19世纪**：印象派画家在户外采用 Alla Prima
3. **20世纪**：成为写生和速写的标准方法
4. **当代**：Alla Prima 工作坊和比赛在全球流行

## 与其他技法的关系

- **Glazing** → 完全相反——多层慢干 vs 一次湿画
- **Impasto** → Alla Prima 常伴随厚涂
- **Plein Air** → 户外写生几乎都是 Alla Prima
- **Impressionism** → 印象派的核心创作方式
- **Grisaille** → 传统多层法的对立面
