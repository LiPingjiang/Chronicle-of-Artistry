# J.M.W. Turner 透纳

> "The sun is God." — J.M.W. Turner (据传为其临终遗言)

## 概述

约瑟夫·马洛德·威廉·透纳（Joseph Mallord William Turner，1775–1851）是英国最伟大的风景画家，也是西方艺术史上最具革命性的色彩与光线大师之一。他从古典风景画传统出发，逐步走向对光、色、大气的极致追求，晚期作品几乎消解了具象形体，被誉为"抽象艺术的先驱"。

透纳一生创作了超过550幅油画、2000幅水彩和30000幅素描速写，题材涵盖海景、风暴、日出日落、威尼斯、阿尔卑斯山和工业革命场景。

## 核心特征

| 特征 | 描述 |
|------|------|
| 光线崇拜 | 将光线本身作为绘画的终极主题 |
| 色彩解放 | 晚期作品中色彩脱离形体独立存在 |
| 大气效果 | 雾、蒸汽、暴风雨的极致表现 |
| 崇高美学 | 自然力量面前人类的渺小与敬畏 |
| 技法革新 | 刮刀、手指、抹布等非传统工具 |
| 速度与力量 | 笔触的动态能量感 |

## 视觉特征

- **光线**：金色、白色、柠檬黄的炽热光芒
- **色彩**：从早期的古典褐色到晚期的纯黄、纯白、纯红
- **形体**：逐渐消融在光与色的漩涡中
- **天空**：占据画面80%以上，层次无穷
- **水面**：与天空融为一体的光影镜像
- **笔触**：从精细到狂放，晚期近乎抽象

## 创作分期

| 时期 | 年代 | 特点 | 代表作 |
|------|------|------|--------|
| 早期 | 1790–1805 | 古典风景，受克劳德·洛兰影响 | *Fishermen at Sea* (1796) |
| 成熟期 | 1805–1830 | 浪漫主义崇高，历史与海景 | *The Fighting Temeraire* (1839) |
| 晚期 | 1830–1851 | 光与色的极致，近乎抽象 | *Rain, Steam and Speed* (1844) |

## 历史地位

- **英国国宝**：被选为20英镑纸币人物（2020年版）
- **透纳奖**：以其命名的当代艺术奖是英国最重要的艺术奖项
- **Tate Britain**：专设透纳展厅，收藏其遗赠的全部作品
- **印象派先驱**：莫奈和毕沙罗在伦敦看到透纳后深受启发

## 与其他风格的关系

- **Romanticism** → 浪漫主义崇高美学的巅峰
- **Maritime Art** → 海洋画的最高成就
- **Impressionism** → 直接启发了莫奈等印象派画家
- **Abstract Art** → 晚期作品被视为抽象艺术先驱
- **Luminism** → 对光线的极致追求影响了美国光辉主义
- **Grimshaw** → 同为英国夜景/光线画家，但风格截然不同
