# Terrazzo 水磨石 | Seminato

> **"碎片的民主——威尼斯工匠用大理石废料创造了最平等的奢华。"**

## 概述

水磨石（Terrazzo / Seminato）是一种将碎石、大理石、花岗岩、玻璃或其他骨料嵌入水泥或树脂基底中，经过打磨抛光后形成光滑表面的装饰材料和艺术形式。起源于15世纪的威尼斯，最初是工匠用大理石加工的废料碎片铺设自家露台（terrazza）的经济做法。这种"废物利用"的美学在20世纪中期的现代主义建筑中大放异彩，近年来又在当代设计中强势回归，成为极简主义和孟菲斯风格的宠儿。

## 历史演变

| 时期 | 特征 |
|------|------|
| 15世纪 威尼斯 | 大理石废料+石灰，手工打磨 |
| 18世纪 | 传入欧洲各地 |
| 1920-30s | 水泥基底，机械打磨 |
| 1950-70s | 现代主义建筑大量使用 |
| 1980s | 一度过时 |
| 2010s–至今 | 强势回归，当代设计宠儿 |

## 核心特征

- **碎片嵌入**：不规则碎片嵌入基底
- **打磨抛光**：表面光滑如镜
- **随机图案**：碎片的随机分布
- **耐久性**：极其耐磨耐用
- **可定制**：碎片颜色和大小可选
- **无缝连续**：大面积无缝铺设

## 当代应用

| 领域 | 特征 |
|------|------|
| 室内设计 | 地面、台面、墙面 |
| 平面设计 | Terrazzo图案纹理 |
| 产品设计 | 手机壳、文具、家居 |
| 时装 | Terrazzo印花面料 |
| 包装设计 | 高端品牌包装 |
| 数字设计 | UI背景和纹理 |

## 视觉特征

- 不规则碎片的随机美感
- 柔和的色彩搭配
- 光滑抛光的表面质感
- 大小不一的碎片层次
- 极简而丰富的视觉效果
- 当代感与复古感并存
