# Zentangle 禅绕画

> "Anything is possible, one stroke at a time." — Rick Roberts & Maria Thomas

## 概述

禅绕画（Zentangle）是一种通过绘制结构化的重复图案来达到冥想状态的艺术形式。2004年由Rick Roberts和Maria Thomas创立，禅绕画将简单的线条和图案组合成复杂而美丽的抽象作品。每一笔都是有意识的、专注的——没有橡皮擦、没有错误，只有"意外的机会"。

禅绕画的哲学在于：过程比结果重要——绘画本身就是冥想，每一笔都是当下的觉知。

| 特征 | 描述 |
|------|------|
| 重复 | 重复的结构化图案 |

| 无计划 | 不预先规划整体构图 |
| 无错误 | 没有"错误"的概念 |
| 抽象 | 抽象的图案组合 |
| 简单工具 | 只需要笔和纸 |

## 视觉特征

- **图案**：重复的结构化图案（tangles）
- **黑白**：传统上使用黑白
- **精细**：精细的线条和填充
- **密集**：密集的图案填充
- **有机**：有机和几何图案的混合
- **边界**：图案之间的清晰边界

## 中国语境

禅绕画在中国非常流行——特别是在正念冥想和心理健康领域。中国有大量的禅绕画爱好者和认证教师。禅绕画的"禅"字虽然来自日本禅宗，但其冥想精神与中国传统的书法练习、画兰竹等"修心"活动有深刻的相通。中国的禅绕画社区将传统中国图案（如云纹、回纹）融入禅绕画创作。
