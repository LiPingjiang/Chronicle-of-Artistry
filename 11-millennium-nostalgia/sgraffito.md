# Sgraffito 刮画法

> "To reveal is sometimes more powerful than to add." — Unknown

## 概述

刮画法（Sgraffito，意大利语"刮擦"）是通过刮去表层材料来露出底层不同颜色的装饰技法。从文艺复兴时期的建筑外墙到当代陶瓷艺术，从非洲的泥墙装饰到儿童的蜡笔刮画，刮画法以其"减法"逻辑——通过去除而非添加来创造图像——在艺术史中占有独特地位。

刮画法的哲学在于：有时候，揭示比覆盖更有力量——真相就在表面之下，等待被刮开。

## 核心特征

| 特征 | 描述 |
|------|------|
| 减法 | 通过去除而非添加创造 |
| 双层 | 至少两层不同颜色的材料 |
| 刮擦 | 用工具刮去表层 |
| 对比 | 表层与底层的色彩对比 |
| 线性 | 倾向于线性的表现 |
| 建筑性 | 常用于建筑外墙装饰 |

## 视觉特征

- **线条**：刮出的清晰线条
- **对比**：两层颜色的强烈对比
- **质感**：刮擦产生的粗糙质感
- **图案**：几何或有机的图案
- **深度**：物理的深度——刮入表面
- **手工感**：明显的手工制作痕迹

## 中国语境

刮画法在中国主要以陶瓷装饰的形式存在——中国传统陶瓷中的"剔花"技法就是刮画法的东方版本。宋代磁州窑的剔花装饰是中国刮画法的经典。当代中国的陶瓷艺术家继续探索刮画技法。儿童美术教育中的"刮蜡画"也是刮画法的简化版本。
