# Stained Glass 彩色玻璃 | Vitrail

> **"光线穿过色彩——哥特大教堂用玻璃和铅条书写天堂的故事。"**

## 概述

彩色玻璃（Stained Glass / Vitrail）是中世纪欧洲的传统玻璃艺术，用铅条（came）将不同颜色的玻璃片拼接成图案和叙事场景，安装在教堂窗户上。当阳光穿过彩色玻璃时，产生神圣而梦幻的光影效果。这种艺术在12-13世纪的哥特式大教堂（如沙特尔大教堂、圣丹尼修道院）达到巅峰。彩色玻璃不仅是装饰，更是"穷人的圣经"——为不识字的信众讲述圣经故事。

## 核心技法

| 技法 | 特征 |
|------|------|
| 铅条拼接 | 用H形铅条连接玻璃片 |
| 着色 | 金属氧化物使玻璃着色 |
| 银染 | 银盐涂在玻璃表面烧制 |
| 搪瓷彩绘 | 在玻璃上绘制细节 |
| 酸蚀 | 去除闪光玻璃的表层 |

## 核心特征

- **透光性**：光线穿过产生神圣效果
- **铅条轮廓**：铅条既是结构也是线条
- **叙事性**：讲述圣经和圣人故事
- **鲜艳色彩**：红、蓝、金、绿的宝石色
- **大尺度**：覆盖整面教堂墙壁
- **玫瑰窗**：圆形放射状的经典构图

## 经典色彩

| 颜色 | 来源 |
|------|------|
| 蓝色 | 钴氧化物 |
| 红色 | 金或铜氧化物 |
| 绿色 | 铜或铁氧化物 |
| 黄色 | 银染技法 |
| 紫色 | 锰氧化物 |

## 视觉特征

- 光线穿透的宝石般色彩
- 黑色铅条的强烈轮廓
- 叙事性的场景构图
- 玫瑰窗的放射对称
- 中世纪人物的程式化造型
- 光影随时间变化的动态效果
