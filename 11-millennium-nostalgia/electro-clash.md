## 历史脉络

| 年份 | 事件 |
|------|------|
| 2000 | Fischerspooner "Emerge"——Electroclash 诞生 |
| 2001 | Electroclash Festival NYC——命名时刻 |
| 2002 | Peaches "The Teaches of Peaches"——性别政治+电子 |
| 2003 | Miss Kittin & The Hacker——欧洲交叉 |
| 2004 | 运动衰落——但影响延续到 Nu-Rave |
| 2005+ | 融入更广泛的 Indie Electronic |

### 核心哲学

Electroclash 的精神是**"用80年代的合成器+朋克的态度+2000年代的讽刺——创造新的地下"**：
- 讽刺 = 武器（"我们不是真的在做80s——我们在嘲笑它同时热爱它"）
- DIY = 朋克（"三个和弦变成了三个合成器音色"）
- 性感 = 挑衅（"性是政治的"）
- 表演 = 艺术（"Fischerspooner 不是乐队——是行为艺术"）
- "Electroclash 是朋克精神穿上了合成器的外衣"

### 色彩系统

```
主色：
  黑色 (#000000) — 地下、夜晚
  红色 (#FF0000) — 挑衅、性感
  银色 (#C0C0C0) — 未来、金属

辅色：
  霓虹粉 (#FF1493) — 性感、挑衅
  白色 (#FFFFFF) — 对比
  金色 (#FFD700) — 华丽

规则：
  - 高对比
  - 80s参考+现代讽刺
  - 性感但不色情

  乙烯基 — 唱片、服装
  金属 — 合成器、配饰
```

## 与千禧怀旧的关系

### 2000年代初的"反主流"
- Electroclash = 2000-2004 最"酷"的地下运动
- 对抗当时的 Trance/House 主流
- "我们不要完美的制作——我们要态度"
- 纽约+柏林 = Electroclash 的双城

### 对后续的影响
- Electroclash → Nu-Rave (2006)
- Electroclash → Lady Gaga 的早期美学
- Electroclash → 2010s Synth-pop 复兴
- "没有 Electroclash 就没有 Lady Gaga"
