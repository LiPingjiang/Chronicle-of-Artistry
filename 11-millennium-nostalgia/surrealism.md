# Surrealism 超现实主义

> "Surrealism is destructive, but it destroys only what it considers to be shackles limiting our vision." — Salvador Dalí

## 概述

超现实主义（Surrealism）是1924年由法国诗人安德烈·布勒东（André Breton）发起的文学和艺术运动，追求通过自动写作、梦境记录和潜意识探索来解放人类的想象力。受弗洛伊德精神分析理论的直接影响，超现实主义者相信真正的现实存在于理性之外——在梦境、幻觉和无意识的深处。

超现实主义是20世纪持续时间最长、影响最广泛的艺术运动之一，从绘画到电影、从摄影到广告，它彻底改变了人类对"可能性"的想象。

## 核心特征

| 特征 | 描述 |
|------|------|
| 潜意识 | 探索弗洛伊德式的潜意识和梦境 |
| 自动主义 | 自动绘画/写作——绕过理性控制 |
| 荒诞并置 | 不相关事物的超现实组合 |
| 梦境逻辑 | 梦的非理性逻辑取代现实逻辑 |
| 双重图像 | 一个形象同时是另一个形象 |
| 解放想象 | 打破一切理性和道德的束缚 |

## 两大方向

| 方向 | 代表 | 特点 |
|------|------|------|
| 自动主义 | Miró, Masson, Ernst | 自动绘画，偶然性，抽象倾向 |
| 梦境写实 | Dalí, Magritte, Delvaux | 精确写实技法描绘梦境场景 |

## 代表人物

| 画家 | 代表作 | 特点 |
|------|--------|------|
| Salvador Dalí | *The Persistence of Memory* | 偏执狂批判法——精确的梦境 |
| René Magritte | *The Treachery of Images* | 概念性的——"这不是一个烟斗" |
| Joan Miró | *The Harlequin's Carnival* | 自动主义——有机的符号语言 |
| Max Ernst | *The Elephant Celebes* | 拼贴和擦印技法 |
| Frida Kahlo | 自画像系列 | 个人痛苦的超现实表达 |
| Yves Tanguy | 无题风景 | 外星般的荒凉景观 |

## 与其他风格的关系

- **Dada** → 达达主义的直接继承者
- **Freudian Psychology** → 弗洛伊德理论的视觉化
- **Expressionism** → 共享对内心世界的关注
- **Pop Art** → 达利的自我营销预示了波普
- **Magic Realism** → 文学中的魔幻现实主义
- **Advertising** → 超现实主义深刻影响了广告视觉
