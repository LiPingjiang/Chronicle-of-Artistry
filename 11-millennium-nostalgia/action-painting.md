# Action Painting 行动绘画

![Action Painting 概念图](../assets/artworks/action-painting/action-painting-concept-01.png)

> **"画布是竞技场——不是画画，是行动。泼洒、滴落、甩动——身体的痕迹就是艺术。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1940s–1960s |
| 别名 | Action Painting, 行动绘画, Gestural Abstraction |
| 核心色彩 | 黑白为主+爆发性色彩——滴落的轨迹 |
| 关键元素 | 身体动作、滴落泼洒、巨幅画布、即兴、过程 |
| 代表人物 | Jackson Pollock, Willem de Kooning, Franz Kline |
| 关联风格 | Abstract Expressionism, Color Field, Performance Art |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1947 | Pollock开始"滴画"(drip painting) |
| 1948 | 评论家Harold Rosenberg命名"Action Painting" |
| 1950 | Hans Namuth拍摄Pollock作画——过程成为艺术 |
| 1952 | Rosenberg发表《美国行动画家》 |
| 1956 | Pollock去世——行动绘画的神话化 |

### 核心哲学

行动绘画的精神是**"画布不是再现世界的窗户——是行动发生的竞技场"**：
- Rosenberg："重要的不是画面上的东西——是发生了什么"
- Pollock："我在画里面——我不知道我在做什么"
- "绘画是事件——不是产品"
- "身体的每一个动作都留下痕迹——这就是真实"
- "控制和失控之间——就是艺术发生的地方"

## 视觉语法

### 技法系统

```
核心技法：
  滴落 (Dripping) — 让颜料从棍子/刷子滴落
  泼洒 (Pouring) — 直接倾倒颜料
  甩动 (Flinging) — 用身体力量甩出颜料
  刮擦 (Scraping) — 用刮刀或手

工作方式：
  画布在地上 — 不在画架上
  四面可进入 — 没有上下左右
  全身运动 — 不只是手腕
  即兴 — 没有草图

色彩：
  黑色 (#000000) — Pollock/Kline的主色
  白色 (#FFFFFF) — 底色/对比
  铝银 (#C0C0C0) — Pollock的工业漆
  红黄蓝 — 爆发性点缀

规则：
  - 过程 > 结果
  - 身体 > 头脑
  - 即兴 > 计划
  - 巨幅 > 小幅
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 痕迹 | 滴落线条、泼洒斑点、甩动弧线 |
| 层次 | 多层叠加、交织、深度 |
| 节奏 | 快慢交替、密疏对比 |
| 尺寸 | 巨幅——与身体等大或更大 |
| 材料 | 工业漆、搪瓷漆、沙子、玻璃碎片 |
| 态度 | 即兴、身体性、英雄主义、存在主义 |
