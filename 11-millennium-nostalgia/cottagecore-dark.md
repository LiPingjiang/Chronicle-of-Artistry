## 历史脉络

### 2020：Cottagecore 的暗面

Dark Cottagecore 是 Cottagecore 的**哥特变体**——同样热爱自然和田园，但拥抱了自然中黑暗、危险和死亡的一面：

| 维度 | Cottagecore | Dark Cottagecore |
|------|------------|-----------------|
| 天气 | 阳光明媚 | 暴风雨、浓雾 |
| 植物 | 向日葵、薰衣草 | 毒蘑菇、荆棘、枯花 |
| 动物 | 兔子、蝴蝶 | 乌鸦、黑猫、蛾子 |
| 时间 | 白天、黄金时刻 | 黄昏、月夜 |
| 故事 | 田园牧歌 | 格林童话原版（暗黑） |
| 食物 | 面包、果酱 | 草药、毒药、黑莓 |

### 文化基因

| 来源 | 贡献 |
|------|------|
| 格林童话原版 | 森林中的危险和黑暗 |
| 民间草药学 | 毒药与药物的双重性 |
| 哥特文学 | 荒野中的恐怖 |
| 《The VVitch》(2015) | 新英格兰殖民地的暗黑田园 |
| 北欧民间传说 | 森林精灵的危险面 |

### 核心哲学

Dark Cottagecore 的吸引力在于它**承认自然不只是美好的**：
- 自然也有毒蘑菇、荆棘和暴风雨
- 田园生活也有孤独、危险和死亡
- 美丽和恐怖可以共存于同一片森林
- 这是一种更"真实"的自然崇拜

### 色彩系统

```
主色：
  深绿 (#006400 暗) — 苔藓、毒藤
  暗紫 (#301934) — 毒蘑菇、黄昏
  枯叶棕 (#8B4513 暗) — 枯叶、泥土
  月光银 (#C0C0C0) — 月光、蛛网
  毒红 (#8B0000) — 毒浆果、血

辅色：
  黑色 (#000000) — 乌鸦、暗影
  骨白 (#F5F5DC) — 骨头、蘑菇
  铁锈 (#B7410E) — 旧铁器

质感：
  苔藓/腐朽 — 覆盖一切的绿
  蛛网 — 被遗弃的空间
  雾气 — 神秘氛围
  枯萎 — 干花、落叶
  月光 — 冷色照明
```

## 与千禧怀旧的关系

### 童话的暗面
- 千禧一代长大后重新发现格林童话的原版
- 原版中的暴力、恐怖和道德模糊
- Dark Cottagecore 是对"迪士尼化"童话的反叛

### 与 Witchcore 的交叉
- Witchcore 更关注"魔法实践"
- Dark Cottagecore 更关注"暗黑自然"
- 两者共享草药、蜡烛、月亮等元素

---

## 中国语境

- "暗黑田园"/"哥特田园"风格
- 与中国民间故事中的"山精水怪"平行
- 聊斋志异式的美丽与恐怖并存
- 小红书上的"暗黑花园"/"毒蘑菇"美学
