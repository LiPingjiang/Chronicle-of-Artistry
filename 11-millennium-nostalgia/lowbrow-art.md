# Lowbrow Art 低眉艺术

> "Lowbrow is the art of the people who grew up on hot rods, comic books, and punk rock." — Robert Williams

## 概述

低眉艺术（Lowbrow Art），也称Pop Surrealism（波普超现实主义），是1970年代起源于美国加州的地下艺术运动。它从漫画、朋克音乐、热棒车文化、冲浪文化、恐怖电影、科幻小说和街头文化中汲取灵感，创造出色彩鲜艳、技法精湛但主题叛逆的作品。

低眉艺术是对"高眉"（Highbrow）艺术体制的反叛——它拒绝学院派的精英主义，拥抱大众文化和亚文化的视觉语言。

## 核心特征

| 特征 | 描述 |
|------|------|
| 亚文化 | 根植于漫画、朋克、热棒车等亚文化 |
| 叛逆性 | 反对艺术体制的精英主义 |
| 技法精湛 | 高超的绘画技巧 |
| 幽默/暗黑 | 黑色幽默和暗黑美学 |
| 叙事性 | 讲述故事——常有超现实情节 |
| 色彩鲜艳 | 饱和的、漫画式的色彩 |

## 视觉特征

- **人物**：大眼睛的女孩、怪物、骷髅、卡通角色
- **色彩**：高饱和度、对比强烈
- **技法**：精细的写实技法用于超现实主题
- **元素**：热棒车、纹身图案、恐怖元素
- **风格**：漫画与古典绘画的融合
- **氛围**：甜美与恐怖的并置

## 代表作品

| 作品/艺术家 | 年代 | 特征 |
|-------------|------|------|
| Robert Williams | 1970s+ | Lowbrow运动的教父——Juxtapoz杂志创始人 |

| Camille Rose Garcia | 2000s+ | 暗黑迪士尼美学 |

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1960s | 地下漫画运动——R. Crumb等 |
| 1970s | Robert Williams开始创作 |
| 1979 | "Lowbrow"一词首次使用 |
| 1994 | Juxtapoz杂志创刊 |
| 1990s | Pop Surrealism的黄金时代 |
| 2000s | 进入画廊体系——从地下到主流 |
| 2010s | 与街头艺术、潮流文化融合 |
| 2020s | NFT和数字平台上的新一代Lowbrow |

## 中国语境

低眉艺术在中国的影响主要通过潮流文化（潮玩、街头服饰）和数字插画传播。中国的"潮流艺术"（如KAWS在中国的巨大影响力）与Lowbrow有精神上的亲缘关系。中国年轻一代的数字插画师大量借鉴Lowbrow的视觉语言——大眼睛角色、暗黑可爱、超现实叙事。

## 与其他风格的关系

- **Pop Art** → 波普艺术对大众文化的拥抱是Lowbrow的先驱
- **Surrealism** → 超现实主义的梦境逻辑影响了Lowbrow
- **Street Art** → 街头艺术与Lowbrow共享亚文化根基
- **Comic Art** → 漫画是Lowbrow的重要视觉来源
- **Neo-Pop** → 新波普与Lowbrow有重叠
- **Outsider Art** → 两者都在主流艺术体制之外
