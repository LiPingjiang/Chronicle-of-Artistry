# Orphism 俄耳甫斯主义

> "Simultaneous contrast is the newest and most profound means of expression." — Robert Delaunay

## 概述

俄耳甫斯主义（Orphism / Orphic Cubism）是1912年前后由罗伯特·德劳内和索尼娅·德劳内在巴黎发展的抽象艺术运动。它从立体主义出发，但用纯粹的色彩圆环和同时对比取代了立体主义的灰褐色调和碎片化形体。

名称来自诗人阿波利奈尔，取自希腊神话中的音乐家俄耳甫斯——暗示这种绘画如音乐般纯粹，通过色彩的节奏和和声直接作用于感官。

## 核心特征

| 特征 | 描述 |
|------|------|
| 色彩圆环 | 同心圆和扇形的色彩排列 |
| 同时对比 | 互补色并置产生的视觉振动 |
| 音乐性 | 色彩如音符般的节奏和和声 |
| 纯粹抽象 | 从立体主义走向完全非具象 |
| 光与运动 | 色彩即光，光即运动 |
| 圆形构图 | 圆形作为基本构图单元 |

## 视觉特征

- **形状**：同心圆、扇形、弧形
- **色彩**：光谱色的完整展开——彩虹般的渐变
- **对比**：强烈的互补色并置
- **构图**：旋转的、向心或离心的动态
- **光感**：色彩本身发光的效果
- **节奏**：重复的色彩单元如音乐节拍

## 代表作品

| 作品 | 年代 | 意义 |
|------|------|------|
| *Simultaneous Windows* (R. Delaunay) | 1912 | 同时对比的宣言 |
| *Circular Forms* (R. Delaunay) | 1913 | 纯粹抽象的里程碑 |
| *Electric Prisms* (S. Delaunay) | 1914 | 城市光线的抽象 |
| *Rhythm, Joie de vivre* (R. Delaunay) | 1930 | 色彩的交响曲 |
| *Propeller* (S. Delaunay) | 1937 | 运动与色彩 |

## 与其他风格的关系

- **Cubism** → 从立体主义的色彩解放
- **Abstract Art** → 最早的纯粹抽象之一
- **Op Art** → 色彩振动影响了欧普艺术
- **Color Field** → 色域绘画的先声
