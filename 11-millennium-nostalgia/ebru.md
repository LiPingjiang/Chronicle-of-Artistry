# Ebru 土耳其水拓画 | Ebru Sanatı

> **"水面上的花园——颜料在水上跳舞，纸张捕捉瞬间的永恒。"**

## 概述

Ebru（土耳其水拓画 / Ebru Sanatı）是一种在水面上作画、再将图案转印到纸上的传统艺术，起源于中亚突厥文化，在奥斯曼帝国时期发展到巅峰。"Ebru"一词可能源自波斯语"abru"（水面）或"ebri"（云彩）。2014年被联合国教科文组织列入人类非物质文化遗产代表作名录。艺术家使用牛胆汁降低颜料表面张力，使其漂浮在角叉菜胶（kitre）增稠的水面上，用针、梳子等工具创造出精美的花卉和几何图案。

## 核心技法

1. **准备水槽**：角叉菜胶（kitre/carrageenan）增稠水面
2. **调配颜料**：天然矿物颜料+牛胆汁（降低表面张力）
3. **洒点底色**：用刷子弹洒背景色点
4. **绘制图案**：用针（biz）和梳子（tarak）拉出花纹
5. **转印**：将纸张轻放水面，吸附图案
6. **晾干**：取出纸张平放晾干

## 主要图案类型

| 类型 | 土耳其名 | 特征 |
|------|----------|------|
| 石纹 | Battal | 随机洒点，大理石纹理 |
| 梳纹 | Taraklı | 梳子拉出的规则波纹 |
| 花卉 | Çiçekli | 郁金香、康乃馨、风信子 |
| 夜莺巢 | Bülbül Yuvası | 螺旋嵌套的同心圆 |
| 帽形 | Şal | 帽子形状的重复图案 |
| 自由形式 | Serbest | 当代自由创作 |

## 视觉特征

- 流动的有机线条和漩涡
- 大理石般的纹理效果
- 鲜艳的矿物颜料色彩
- 每一张都是独一无二的
- 精美的花卉图案（尤其是郁金香）
- 水的流动性赋予的自然韵律

## 历史与传播

| 地区 | 名称 | 特征 |
|------|------|------|
| 土耳其 | Ebru | 花卉图案为主，最精致 |
| 日本 | 墨流し（Suminagashi） | 更简约，墨水为主 |
| 欧洲 | Marbling | 书籍装帧用纸 |
| 波斯 | Abri | 云纹图案 |
| 中国 | 水拓画 | 近年复兴 |

## 与其他风格的关系

| 风格 | 关系 |
|------|------|
| 日本墨流し | 共享水面作画原理，但风格不同 |
| 伊斯兰书法 | Ebru常作为书法作品的装饰背景 |
| İznik陶瓷 | 共享奥斯曼花卉美学 |
| 抽象表现主义 | 共享偶然性和流动性 |
| 当代流体艺术 | Ebru是流体艺术的历史先驱 |
