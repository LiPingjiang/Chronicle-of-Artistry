# Warli Art 瓦尔利绘画

> **"白色的圆圈和三角形——部落的记忆在赭红色的墙上跳舞。"**

## 概述

瓦尔利绘画（Warli Art / वारली चित्रकला）是印度马哈拉施特拉邦（Maharashtra）北部瓦尔利部落（Warli tribe）的传统绘画艺术，历史可追溯至公元前2500年。这种绘画以其极简的几何语言著称——仅使用圆形、三角形和方形三种基本形状，用白色米糊颜料在赭红色泥墙上描绘日常生活、节日庆典和自然世界。其简洁有力的视觉语言使其成为当代设计中广受欢迎的元素。

## 核心特征

- **三种基本形状**：圆形（太阳/月亮）、三角形（山/人体）、方形（土地/神圣空间）
- **白色颜料**：米糊+水+阿拉伯胶，用竹签或草茎绘制
- **赭红底色**：牛粪和红土混合的泥墙
- **火柴人造型**：人物由三角形身体和线条四肢组成
- **叙事性**：连续场景讲述故事
- **集体活动**：描绘舞蹈、狩猎、播种、收获等群体场景

## 常见主题

| 主题 | 描绘方式 |
|------|----------|
| Tarpa舞蹈 | 围成圆圈的舞者，中心有乐手 |
| 婚礼 | 新人、宾客、仪式场景 |
| 狩猎 | 猎人与动物的追逐 |
| 农耕 | 播种、收获、牛车 |
| 生命之树 | 中心大树，周围是动物和人 |
| Palghat（神圣方形） | 婚礼时绘制的神圣图案 |

## 视觉特征

- 白色线条在深色背景上的强烈对比
- 极简的几何化人物和动物
- 鸟瞰和侧面视角的混合
- 重复的节奏感和韵律
- 无透视的平面空间
- 集体场景的环形或带状构图

## 与其他风格的关系

| 风格 | 关系 |
|------|------|
| Madhubani | 共享印度民间绘画传统，但风格截然不同 |
| 澳大利亚原住民艺术 | 共享部落叙事和几何语言 |
| Keith Haring | 共享简化人形和动态线条 |
| 洞穴壁画 | 共享原始的叙事冲动 |
| 极简主义 | 共享几何纯粹性 |
| 当代平面设计 | Warli元素广泛用于品牌和包装 |
