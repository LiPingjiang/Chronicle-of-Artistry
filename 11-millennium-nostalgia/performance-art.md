# Performance Art 行为艺术

> "The body is the most direct medium of expression." — Marina Abramović

## 概述

行为艺术（Performance Art）是以艺术家的身体和行动为主要媒介的艺术形式。它发生在特定的时间和空间中，通常是现场的、不可重复的、直接面对观众的。行为艺术不产生可出售的物品——作品就是行为本身。

从1960年代的先驱（Yoko Ono、Vito Acconci）到Marina Abramović的极限耐力表演、从谢德庆的一年表演到当代的参与式行为，行为艺术持续挑战着艺术的边界和身体的极限。

## 核心特征

| 特征 | 描述 |
|------|------|
| 身体媒介 | 艺术家的身体是核心材料 |
| 时间性 | 发生在特定时间中——有开始和结束 |
| 现场性 | 现场体验不可被完全记录 |
| 不可重复 | 每次表演都是唯一的 |
| 直接性 | 艺术家与观众的直接面对 |
| 去商品化 | 不产生可出售的物品 |

## 视觉特征

- **身体**：艺术家的身体——裸露的、装扮的、受苦的
- **空间**：画廊、街道、自然——任何空间
- **时间**：从几分钟到数年（谢德庆）
- **道具**：极简的——刀、绳、镜子、食物
- **观众**：观众的在场和反应是作品的一部分
- **记录**：照片和视频是行为的"遗物"

| 作品 | 艺术家 | 年代 | 意义 |
|------|--------|------|------|

| *Seedbed* | Vito Acconci | 1972 | 画廊地板下的隐藏表演 |

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1910s | 未来主义和达达的表演晚会 |
| 1950s | Gutai群——日本的身体行动 |
| 1960s | Happening和Fluxus——行为的先驱 |
| 1970s | 行为艺术的黄金时代——Abramović、Burden、Acconci |
| 1978-86 | 谢德庆的五个一年表演 |
| 1980s | 行为艺术的制度化和文档化 |
| 2010 | Abramović的*The Artist is Present*——大众化 |
| 2010s-至今 | 行为艺术的再表演、数字化、参与式 |

## 子类型

| 子类型 | 特征 |
|--------|------|
| 身体艺术 | Abramović、Burden——身体的极限 |
| 耐力表演 | 谢德庆——时间的极限 |
| 参与式行为 | 观众成为表演的一部分 |
| 日常行为 | 将日常动作框定为艺术 |
| 政治行为 | 身体作为政治抗议的工具 |
| 数字行为 | 在网络空间中的表演 |

## 中国语境

行为艺术在中国从1980年代开始发展，经历了从地下到半公开的过程。中国的行为艺术家如张洹（用蜂蜜和苍蝇覆盖身体）、何云昌（24小时铸铜）、马六明（芬·马六明）等创作了具有国际影响力的作品。中国行为艺术面临独特的社会和政治语境——公共空间的限制使许多行为只能在私密空间或偏远地点进行。谢德庆虽然在纽约创作，但作为华人艺术家，他的极限行为对中国当代艺术有深远影响。

## 与其他风格的关系

- **Happening** → 偶发艺术是行为艺术的直接先驱
- **Fluxus** → 激浪派的事件是行为艺术的重要来源
- **Body Art** → 身体艺术是行为艺术的核心分支
- **Conceptual Art** → 概念艺术的去物质化在行为中实现
- **Video Art** → 影像艺术记录和延伸了行为
- **Social Practice Art** → 社会实践继承了行为的参与性
