# Old Money 老钱风

![Old Money 概念图](../assets/artworks/old-money/old-money-concept-01.png)

> **"Polo衫、帆船鞋、常春藤——像继承了三代财富一样穿衣。"**

| 维度 | 描述 |
|------|------|

## 历史脉络

### 从特权到美学

| 时代 | 表现 |
|------|------|
| 1920s–50s | 美国东海岸精英的真实穿着 |
| 1967 | Ralph Lauren 创立——将"老钱"民主化 |
| 1980s | Preppy Handbook 出版 |
| 2010s | Tumblr 上的 "Old Money" 美学板 |
| 2021–至今 | TikTok #OldMoney 标签爆发 |

### 它代表什么？

| 元素 | 含义 |
|------|------|
| 海军蓝西装 | 传统、可靠、"不需要追潮流" |
| 帆船鞋 | 休闲中的特权——"我有船" |
| 珍珠 | 继承、传统、"这是我祖母的" |
| 乡村俱乐部 | 排他性、社交圈、"你需要被邀请" |
| 格纹 | 英国贵族遗产 |

### 核心哲学

Old Money 的精神是**"真正的财富不需要证明"**：
- 穿了三代的外套比新买的更有价值
- 品牌不重要——裁缝更重要
- "我们家一直这样穿"
- 低调是最高形式的炫耀
- 传承 > 购买

## 视觉语法

### 色彩系统

```
主色：
  海军蓝 (#000080) — 西装、毛衣
  白色 (#FFFFFF) — 衬衫、网球
  卡其 (#C3B091) — 休闲裤
  酒红 (#722F37) — 领带、毛衣
  森林绿 (#228B22) — 猎装、格纹

辅色：
  金色 (#DAA520) — 纽扣、配饰
  粉色 (#FFB6C1) — Polo衫
  条纹 — 学院领带

规则：
  - 经典配色
  - 低饱和度
  - 不追求"时髦"——追求"永恒"
  - 图案只用经典款（格纹、条纹、菱形）
  - 颜色搭配"安全"但"昂贵"

质感：
  羊毛 — 西装、毛衣
  棉 — Oxford衬衫、Polo
  丝绸 — 领带、围巾
  皮革 — 帆船鞋、皮带
  羊绒 — 围巾、毛衣
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 上装 | Polo衫、Oxford衬衫、V领毛衣、西装 |
| 下装 | 卡其裤、格纹裤、白色网球裙 |
| 鞋 | 帆船鞋、乐福鞋、牛津鞋 |
| 配饰 | 珍珠、丝巾、金色纽扣、皮带 |
| 运动 | 网球、马球、帆船、高尔夫 |
| 场景 | 乡村俱乐部、常春藤校园、汉普顿 |

## 与千禧怀旧的关系

### TikTok 上的阶级幻想
- 千禧/Z世代面对经济不确定性
- "Old Money" = "如果我出生在有钱人家"的幻想
- 不是真的想当贵族——是想要那种"从容"
- 与 Quiet Luxury 的精神共鸣

### 与 Dark Academia 的交叉
- 两者都热爱"精英"美学
- Old Money = 社交精英
- Dark Academia = 学术精英
- 共同点：常春藤、图书馆、传统

---

## 中国语境

- "老钱风"在小红书的爆火
- 与"高级感"/"松弛感"的交叉
- 中国版 Old Money：高尔夫、马术、红酒
- 对"暴发户"审美的反叛
- "看起来有钱但不炫富"的追求
