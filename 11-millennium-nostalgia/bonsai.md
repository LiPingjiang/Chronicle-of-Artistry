# Bonsai 盆栽 | 盆栽 / 盆景

> **"一盆之中见山河——用数十年的耐心将一棵树塑造成一幅活的山水画。"**

## 概述

盆栽（Bonsai / 盆栽 ぼんさい / 盆景 pénjǐng）是东亚传统的活体植物造型艺术，通过修剪、蟠扎、控制生长环境等技法，将树木培育成微缩的自然景观。"盆栽"源自中国"盆景"（盆中的风景），6世纪传入日本后发展出独特的日本美学。盆栽不是简单的"小树"，而是通过数十年甚至数百年的持续塑造，表达自然之美、时间之力和人与自然的对话。日本盆栽强调侘寂之美，中国盆景则更注重山水意境。

## 主要传统

| 传统 | 特征 |
|------|------|
| 中国盆景 | 山水意境，配石配景 |
| 日本盆栽 | 侘寂美学，单树为主 |
| 越南盆景 | 热带树种，龙形 |
| 韩国盆栽 분재 | 自然主义 |

## 主要树形

| 树形 | 日语 | 特征 |
|------|------|------|
| 直干 | 直幹 Chokkan | 笔直向上 |
| 斜干 | 斜幹 Shakan | 倾斜生长 |
| 悬崖 | 懸崖 Kengai | 向下垂挂 |
| 文人木 | 文人木 Bunjingi | 细长飘逸 |
| 双干 | 双幹 Sokan | 两干并生 |
| 丛林 | 寄せ植え Yose-ue | 多树成林 |

## 核心特征

- **活体艺术**：活着的、持续变化的作品
- **时间性**：需要数十年的持续塑造
- **微缩自然**：在盆中再现自然景观
- **修剪蟠扎**：控制生长方向和形态
- **季节变化**：随四季展现不同之美
- **人与自然**：人的意志与自然力量的对话

## 视觉特征

- 微缩的古树形态
- 苍劲的枝干线条
- 季节变化的色彩
- 盆与树的比例和谐
- 留白和空间感
- 时间沉淀的力量
