# Art Deco 装饰艺术

> "Art Deco is the style of the modern age." — 1925年巴黎博览会精神

## 概述

装饰艺术（Art Deco，法语 Arts Décoratifs 的缩写）是1920–1940年代流行于全球的设计和建筑风格，以1925年巴黎国际装饰艺术博览会为标志性事件。它融合了现代主义的几何简洁与古典的奢华装饰，创造了一种既现代又华丽的视觉语言——从纽约的克莱斯勒大厦到上海的和平饭店，从好莱坞电影到珠宝设计。

Art Deco 是对 Art Nouveau 曲线的反叛——用锐利的几何线条、对称的图案和奢华的材料取代了新艺术运动的有机曲线。

## 核心特征

| 特征 | 描述 |
|------|------|
| 几何图案 | 锐利的几何形——锯齿形、扇形、阶梯形 |
| 对称性 | 严格的轴对称构图 |
| 奢华材料 | 黄金、象牙、黑檀木、铬合金 |
| 速度美学 | 流线型设计——速度和现代性 |
| 异域元素 | 埃及、阿兹特克、非洲的装饰元素 |
| 机器美学 | 工业时代的精密和力量 |

## 视觉特征

- **线条**：锐利的直线、锯齿形、放射状线条
- **形状**：扇形、阶梯形、金字塔形
- **色彩**：黑金、银灰、翡翠绿、深红的奢华组合
- **材料**：铬合金、黑色大理石、镜面玻璃
- **图案**：太阳光芒、喷泉、几何化的花卉
- **字体**：几何化的装饰性字体

## 与其他风格的关系

- **Art Nouveau** → 对新艺术运动曲线的几何化反叛
- **Cubism** → 吸收了立体主义的几何碎片
- **Futurism** → 吸收了未来主义的速度美学
- **Bauhaus** → 共享现代主义的几何简洁
- **Streamline Moderne** → 1930年代的流线型发展
- **Egyptian Revival** → 1922年图坦卡蒙墓发现的影响
