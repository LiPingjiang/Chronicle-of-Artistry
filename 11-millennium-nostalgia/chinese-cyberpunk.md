# Chinese Cyberpunk 中国赛博朋克

![Chinese Cyberpunk 概念图](../assets/artworks/chinese-cyberpunk/chinese-cyberpunk-concept-01.png)

> **"霓虹汉字、城中村天线、外卖骑手——赛博朋克不在东京，在重庆。"**

## 历史脉络

### 从西方想象到中国现实

| 年份 | 事件 |
|------|------|
| 1982 | 《银翼杀手》——赛博朋克以东京为原型 |
| 2017 | 外国摄影师发现"重庆 = 赛博朋克" |
| 2018 | Reddit/Twitter 上 "China is cyberpunk" 热潮 |
| 2019 | 《流浪地球》——中国科幻视觉 |
| 2020 | 赛博朋克2077 的"Watson区"参考香港/重庆 |
| 2022 | 中国独立创作者的赛博朋克作品爆发 |

### 为什么中国 = 赛博朋克？

| 元素 | 现实对应 |
|------|----------|
| 霓虹招牌 | 中国城市的LED广告牌 |
| 高低差城市 | 重庆的立体交通 |
| 科技与混乱并存 | 城中村里的5G基站 |
| 外卖骑手 | "赛博朋克底层劳工" |
| 监控摄像头 | 无处不在的天眼 |
| 巨型建筑 | 中国的超级工程 |

### 核心哲学

Chinese Cyberpunk 的精神是**"高科技、低生活——但这不是虚构，这是现在"**：
- 赛博朋克不需要等到2077——它已经在这里
- 科技发展 ≠ 所有人受益
- 霓虹灯下的外卖骑手 = 真实的赛博朋克
- "未来已来，只是分配不均"
- 中国的现代性本身就是科幻

## 视觉语法

### 色彩系统

```
主色：
  霓虹粉 (#FF1493) — LED招牌
  电子蓝 (#00BFFF) — 屏幕、科技
  深红 (#8B0000) — 中国红、灯笼
  混凝土灰 (#696969) — 城中村、高架
  金色 (#FFD700) — 汉字、装饰

辅色：
  紫色 (#9B59B6) — 夜晚
  绿色 (#00FF00) — 矩阵、数据
  橙色 (#FF8C00) — 外卖骑手

规则：
  - 深色背景（夜晚）
  - 霓虹色点缀
  - 高对比度
  - 中文字体是核心视觉元素
  - 混乱中的秩序

质感：
  霓虹 — 发光、闪烁
  混凝土 — 粗糙、城市
  金属 — 管道、天线
  雨水 — 反射、潮湿
  电子屏 — 像素、信息
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 城市 | 重庆立交桥、城中村、高楼间的缝隙 |
| 招牌 | 霓虹汉字、LED广告、药店十字 |
| 人物 | 外卖骑手、城中村居民、程序员 |
| 交通 | 电动车、高架轻轨、共享单车 |
| 科技 | 监控摄像头、二维码、5G基站 |
| 天气 | 雨夜、雾霾、潮湿 |

## 与千禧怀旧的关系

### 中国Z世代的身份表达
- "我们的城市本身就是赛博朋克"
- 不需要模仿东京/洛杉矶——重庆就够了
- 是一种"自嘲中的自豪"
- 外卖骑手 = 当代中国的视觉符号

### 与 Vaporwave 的区别
| Vaporwave | Chinese Cyberpunk |
|-----------|-------------------|
| 怀旧 | 当下 |
| 虚构 | 真实 |
| 消费主义批判 | 科技发展批判 |
| 日本/美国 | 中国 |
| 慢 | 快 |
