# Tingatinga 坦桑尼亚画派 | Tingatinga

> **"非洲的色彩爆炸——坦桑尼亚画家用自行车漆在硬纸板上画出最快乐的动物。"**

## 概述

Tingatinga是坦桑尼亚的现代民间绘画流派，由Edward Said Tingatinga（1932-1972）于1960年代末在达累斯萨拉姆创立。Tingatinga用自行车漆（enamel paint）在硬纸板或木板上绘制色彩鲜艳的非洲动物和日常生活场景。这种风格以其大胆的色彩、简化的造型、装饰性的图案填充和幽默感著称。Tingatinga在创始人1972年被警察误杀后，由其学生和追随者继续发展，如今已成为东非最具辨识度的艺术品牌，在全球旅游市场广泛流通。

## 核心特征

- **自行车漆**：使用工业搪瓷漆
- **鲜艳色彩**：极度饱和的纯色
- **动物题材**：非洲野生动物为主
- **装饰填充**：动物身体内填满图案
- **平面化**：无透视，平面构图
- **幽默感**：夸张和幽默的造型

## 常见题材

| 题材 | 特征 |
|------|------|
| 大象 | 最经典的Tingatinga题材 |
| 长颈鹿 | 身体填满几何图案 |
| 鱼 | 色彩斑斓的热带鱼 |
| 鸟类 | 装饰性的非洲鸟 |
| 村庄生活 | 日常场景 |
| 树木 | 非洲金合欢树 |

## 视觉特征

- 极度鲜艳的纯色
- 动物身体内的装饰图案
- 简化的轮廓造型
- 平面化的构图
- 黑色轮廓线
- 快乐和幽默的氛围
