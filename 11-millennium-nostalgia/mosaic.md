# Mosaic 马赛克艺术

> "A mosaic is a conversation between fragments — each piece speaks, but only together do they sing." — Unknown

## 概述

马赛克艺术（Mosaic）是用小块石头、玻璃、陶瓷或其他材料（tesserae）拼贴成图案和图像的古老艺术形式。从古罗马的地板到拜占庭的金色教堂，从伊斯兰的几何图案到高迪的碎瓷片建筑，马赛克艺术跨越了数千年的文明，是人类最持久的视觉表达方式之一。

马赛克的哲学在于：碎片可以构成整体——每一块小石头都是微不足道的，但数千块组合在一起就成为永恒。

## 核心特征

| 特征 | 描述 |
|------|------|
| 碎片 | 由小块材料（tesserae）组成 |
| 拼贴 | 将碎片拼贴成图案 |
| 耐久 | 极其持久——可存数千年 |
| 光泽 | 玻璃和金箔的光泽效果 |
| 建筑性 | 常与建筑结合 |
| 装饰性 | 强烈的装饰功能 |

## 视觉特征

- **网格**：可见的碎片网格结构
- **光泽**：玻璃和金箔的闪烁
- **色彩**：鲜艳持久的色彩
- **纹理**：碎片之间的缝隙纹理
- **角度**：不同角度的碎片反射不同光线
- **规模**：从微型到建筑尺度

## 中国语境

马赛克在中国主要以建筑装饰材料的形式存在。中国传统建筑中虽然没有西方式的马赛克传统，但琉璃瓦、花砖和镶嵌工艺有相似的美学逻辑。当代中国的公共艺术项目中，马赛克壁画是常见的形式。中国的"百宝嵌"和螺钿工艺也可视为马赛克精神的东方表达。

## 与其他风格的关系

- **Pixel Art** → 像素艺术是数字时代的马赛克
- **Pointillism** → 点彩派与马赛克有结构相似性
- **Stained Glass** → 彩色玻璃与马赛克是姐妹艺术
- **Islamic Art** → 伊斯兰几何马赛克
- **Byzantine Art** → 拜占庭是马赛克的黄金时代
- **Collage** → 拼贴与马赛克有方法论相似
