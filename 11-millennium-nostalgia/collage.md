# Collage 拼贴艺术

> "I take a piece of the real world and put it in a painting." — Pablo Picasso

## 概述

拼贴（Collage，法语 coller"粘贴"之意）是将现成材料——报纸、布料、照片、票据、包装纸等——粘贴在画面上的艺术技法和形式。1912年由毕加索和布拉克在综合立体主义中首次系统使用，拼贴从此成为20世纪最重要的艺术创新之一。

拼贴的革命性在于它打破了绘画的"窗户"幻觉——将真实世界的碎片直接引入画面，模糊了艺术与现实、高雅与低俗、创造与挪用之间的界限。

## 核心特征

| 特征 | 描述 |
|------|------|
| 现成材料 | 使用非传统的现成材料 |
| 粘贴组合 | 将不同来源的材料粘贴在一起 |
| 打破幻觉 | 真实材料打破了绘画的幻觉空间 |
| 并置对比 | 不同材料和图像的意外并置 |
| 混合媒介 | 拼贴常与绘画、素描结合 |
| 民主材料 | 任何材料都可以成为艺术 |

## 视觉特征

- **材料**：报纸、布料、照片、票据等现成材料
- **层次**：多层叠加的物理层次
- **边缘**：撕裂的、剪切的不规则边缘
- **质感**：不同材料的物理质感对比
- **文字**：报纸标题和印刷文字作为视觉元素
- **混合**：拼贴与绘画、素描的混合

## 发展历程

| 时期 | 代表 | 特点 |
|------|------|------|
| 立体主义 | Picasso, Braque (1912) | papier collé——报纸和壁纸 |
| 达达 | Schwitters, Höch (1916-20s) | 反艺术的随机拼贴 |
| 超现实主义 | Ernst, Cornell (1920-40s) | 梦境般的图像并置 |
| 波普艺术 | Hamilton, Rauschenberg (1950-60s) | 大众媒体图像的拼贴 |
| 当代 | 数字拼贴 (1990s-至今) | Photoshop 时代的数字拼贴 |

## 代表人物

| 艺术家 | 代表作 | 特点 |
|--------|--------|------|
| Pablo Picasso | *Still Life with Chair Caning* (1912) | 第一幅拼贴画 |
| Georges Braque | papier collé 系列 | 立体主义拼贴 |
| Kurt Schwitters | Merz 系列 | 达达——垃圾变艺术 |
| Hannah Höch | 照片蒙太奇 | 女性主义先驱 |
| Robert Rauschenberg | Combines 系列 | 绘画+现成物 |
| Joseph Cornell | 盒子装置 | 诗意的微型世界 |

## 与其他风格的关系

- **Cubism** → 综合立体主义发明了拼贴
- **Dada** → 达达将拼贴推向反艺术极端
- **Surrealism** → 超现实主义的梦境拼贴
- **Pop Art** → 波普艺术的媒体图像拼贴
- **Mixed Media** → 混合媒介艺术的基础
- **Digital Art** → 数字拼贴是当代延续
