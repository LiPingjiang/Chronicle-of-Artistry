# Abstract Expressionism 抽象表现主义

> "Every good painter paints what he is." — Jackson Pollock

## 概述

抽象表现主义（Abstract Expressionism）是1940–1960年代以纽约为中心的美国艺术运动——西方艺术史上第一个由美国主导的国际性前卫运动。它将欧洲超现实主义的自动主义与美国的个人主义精神结合，创造了一种通过纯粹的色彩、笔触和身体动作来表达深层情感和存在状态的绘画。

抽象表现主义标志着世界艺术中心从巴黎转移到纽约，它包含两大分支：行动绘画（Action Painting）和色域绘画（Color Field Painting）。

## 核心特征

| 特征 | 描述 |
|------|------|
| 巨大尺幅 | 画布大到包围观者——"进入"画面 |
| 身体行动 | 绘画是身体的行动——滴洒、泼溅、刮擦 |
| 情感深度 | 表达存在的焦虑、崇高和超越 |
| 非具象 | 完全抽象——没有可辨认的形象 |
| 全面构图 | all-over composition——没有焦点和层次 |
| 即兴创作 | 即兴的、不可预测的创作过程 |

## 两大分支

| 分支 | 代表 | 特点 |
|------|------|------|
| Action Painting 行动绘画 | Pollock, de Kooning, Kline | 身体动作、滴洒、笔触的能量 |
| Color Field 色域绘画 | Rothko, Newman, Still | 大面积纯色、静默的精神性 |

## 代表人物

| 画家 | 代表作 | 特点 |
|------|--------|------|
| Jackson Pollock | 滴画系列 | 行动绘画——在地面上滴洒颜料 |
| Mark Rothko | 色域矩形系列 | 色彩的精神性——"悲剧、狂喜和末日" |
| Willem de Kooning | *Woman* 系列 | 狂暴的笔触和扭曲的人体 |
| Franz Kline | 黑白大笔触 | 建筑般的黑色结构 |
| Barnett Newman | *Vir Heroicus Sublimis* | 巨大的纯色面和"拉链" |
| Clyfford Still | 撕裂的色域 | 最独立的成员 |
| Helen Frankenthaler | 浸染技法 | 稀释颜料浸入画布 |

## 与其他风格的关系

- **Surrealism** → 自动主义是直接灵感来源
- **Expressionism** → 欧洲表现主义的美国发展
- **Minimalism** → 极简主义是对抽象表现主义的反叛
- **Pop Art** → 波普艺术是对其精英主义的反叛
- **Color Field** → 色域绘画是内部分支
- **Action Painting** → 行动绘画影响了行为艺术
