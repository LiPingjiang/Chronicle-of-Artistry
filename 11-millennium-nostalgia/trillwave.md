# Trillwave

> **别名**：Vaportrap, Memphis Rap Revival, Phonk, Swag Era, Purple Aesthetic  
> **活跃年代**：2012 – 至今  
> **起源**：SoundCloud / YouTube 地下嘻哈社区

![Trillwave 概念图](../assets/artworks/trillwave/trillwave-concept-01.png)

---

## 一句话定义

Trillwave 是 Vaporwave 与南方嘻哈（Trap/Memphis Rap）的混血产物——将 90 年代 Three 6 Mafia 式的暗黑节拍与 Vaporwave 的怀旧视觉滤镜融合，创造出一种**紫色迷雾中的街头幻觉**。

---

## 视觉语言

| 元素 | 描述 |
|------|------|
| 色彩 | 紫色、深蓝、品红、金色——"紫药水"色调 |
| 滤镜 | VHS 噪点、扫描线、色彩偏移、低分辨率 |
| 图像 | 90s 嘻哈明星照片、豪车、金链、紫色饮料（Lean） |
| 品牌 | Nike、PlayStation、Windows 95、日本动漫截图 |
| 字体 | 日文片假名混搭英文、全角字符、Gothic 字体 |
| 空间 | 夜间城市街道、霓虹灯、停车场、便利店 |

### 视觉配方

Trillwave 的典型视觉作品遵循一个可预测的配方：

1. **底图**：选取一张 90 年代嘻哈相关的照片（艺人、汽车、街景）
2. **色彩处理**：将整体色调推向紫色/品红，降低对比度
3. **失真叠加**：添加 VHS 扫描线、色彩通道偏移、像素化
4. **文字层**：叠加日文片假名或全角英文（通常无实际含义）
5. **边框/UI**：模拟 Windows 95 对话框、PlayStation 启动画面或 VCR 时间码

这个配方如此标准化，以至于出现了大量在线工具和 Photoshop Action 可以一键生成 Trillwave 风格图片。

## 历史时间线

| 时期 | 事件 |
|------|------|
| 1991-1997 | Memphis Rap 原始时期：Three 6 Mafia、Tommy Wright III、DJ Zirk |
| 2000-2005 | DJ Screw 的 Chopped & Screwed 技术在休斯顿流行 |
| 2010-2011 | Vaporwave 和 Seapunk 在 Tumblr 兴起 |
| 2012 | A$AP Rocky *LiveLoveA$AP* 将 Chopped & Screwed 美学带入主流 |
| 2012-2013 | SoundCloud 上出现 Vaporwave + Trap 的混合实验；"Phonk" 一词开始流通 |
| 2013-2014 | SpaceGhostPurrp、Raider Klan 确立 Phonk 视觉美学 |
| 2014-2016 | DJ Smokey、Soudiere、DJ Yung Vamp 等人将 Phonk 推向国际 |
| 2016-2018 | Trillwave 视觉在 YouTube 混音频道中标准化（Ryan Celsius 等） |
| 2019-2020 | "Drift Phonk" 子流派出现，BPM 更快、更具攻击性 |
| 2021-2022 | TikTok 上 Phonk 音乐病毒式传播（KORDHELL、DVRST） |
| 2022-2023 | Phonk 进入主流：被用于 F1 赛车视频、健身内容、游戏剪辑 |
| 2024+ | 风格成熟分化，影响主流嘻哈 MV 视觉和运动品牌广告 |

## 文化内核

### Vaporwave 的街头兄弟

如果 Vaporwave 是对白领消费主义的讽刺性怀旧，Trillwave 则是对**街头文化黄金时代**的同类操作：

| Vaporwave | Trillwave |
|-----------|-----------|
| 怀念商场 | 怀念街角 |
| 采样 Muzak/Smooth Jazz | 采样 Memphis Rap |
| 用希腊雕像 | 用 90s 嘻哈明星 |
| 粉色+青色 | 紫色+金色 |
| 讽刺消费主义 | 神话化街头生活 |
| 慢速（60-80 BPM） | 中速到快速（130-160 BPM） |

### Chopped & Screwed 的数字化

Trillwave 的音乐手法直接继承了休斯顿 DJ Screw 的"减速+切碎"技术，但将其从物理磁带转移到了数字领域，并叠加了 Vaporwave 的混响和失真处理。

DJ Screw 的原始 Chopped & Screwed 是一种**药物化的听觉体验**——模拟可待因糖浆（Lean/Purple Drank）带来的时间扭曲感。Trillwave 将这种感觉视觉化：紫色色调、模糊边缘、慢动作——一切都像在紫色糖浆中漂浮。

### 紫色的含义

紫色在 Trillwave 中不仅是审美选择，更是多层文化符号：
- **Lean/Purple Drank**：南方嘻哈文化中的标志性饮品，也是致命的成瘾物
- **Prince**：紫色作为音乐传奇的象征
- **夜晚**：街头文化的活跃时段
- **迷幻**：介于清醒和梦境之间的状态
- **皇室**：嘻哈文化中"king"叙事的视觉对应
- **死亡**：Memphis Rap 中反复出现的暗黑主题

### 日文文字的功能

Trillwave 大量使用日文片假名和汉字，但通常不传达实际含义。这些文字的功能是：
- 制造"异域感"和"不可读性"
- 致敬 90 年代日本动漫和游戏（与嘻哈文化的长期交叉）
- 模拟 VHS 录像带上的日文字幕（暗示"从日本进口的稀有录像"）
- 作为纯粹的视觉纹理——字形本身的美感

## 子类型

| 子类型 | 特征 | 代表 |
|--------|------|------|
| **Classic Phonk** | 采样 Memphis Rap，cowbell 节奏，暗黑氛围 | DJ Smokey, Soudiere |
| **Drift Phonk** | 更快 BPM（150+），攻击性强，用于漂移视频 | KORDHELL, DVRST |
| **Brazilian Phonk** | 巴西 Funk 节奏 + Phonk 制作手法 | MC GW, DJ FKU |
| **House Phonk** | House 四拍底鼓 + Phonk 采样 | HARDPHONK 社区 |
| **Vaportrap** | 更接近 Vaporwave 的慢速、迷幻版本 | Blank Body, BLVCK CEILING |
| **Memphiswave** | 纯粹的 Memphis Rap 怀旧重制 | Pharmacist, Baker Ya Maker |

## 从地下到主流的路径

Trillwave/Phonk 的主流化路径是互联网时代音乐传播的典型案例：

```
Memphis 地下磁带 (1991-1997)
    ↓
SoundCloud 重新发现 (2012-2015)
    ↓
YouTube 混音频道标准化 (2016-2019)
    ↓
TikTok 病毒式传播 (2020-2022)
    ↓
品牌/体育/游戏采用 (2022+)
```

每一步都伴随着风格的稀释和简化——从最初的暗黑、药物化氛围，到最终成为"听起来很酷的背景音乐"。

## 争议

### 对 Memphis Rap 的浪漫化

Trillwave 将 Memphis Rap 的暗黑内容（暴力、毒品、贫困）转化为纯粹的审美符号，这引发了批评：
- 原始 Memphis Rap 描述的是真实的街头暴力和系统性贫困
- Trillwave 将这些内容"美化"为可消费的视觉风格
- 制作者和消费者大多与原始文化语境无关

### Lean 文化的美化

紫色饮料（Lean/Codeine）在 Trillwave 美学中被浪漫化，但现实中它导致了多位嘻哈艺人的死亡（DJ Screw、Pimp C、Juice WRLD）。将成瘾物转化为审美符号的伦理问题值得反思。
