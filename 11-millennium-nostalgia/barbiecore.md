# Barbiecore 芭比核

![Barbiecore 概念图](../assets/artworks/barbiecore/barbiecore-concept-01.png)

> **"全粉色、全塑料、全快乐——芭比不只是娃娃，她是一种生活态度。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2022–2023 巅峰 |
| 别名 | Barbiecore, Hot Pink, Plastic Fantastic |
| 核心色彩 | 芭比粉 (#FF69B4)、热粉、白色、金色 |
| 关键元素 | 全粉色、塑料质感、高跟鞋、梦幻屋、过度女性化 |
| 代表人物 | Margot Robbie、Valentino、Greta Gerwig |
| 关联风格 | Dopamine Dressing, Kidcore, Y2K, Coquette |

## 历史脉络

### 从玩具到文化现象

| 年份 | 事件 |
|------|------|
| 1959 | 芭比娃娃诞生 |
| 2000s | "粉色=幼稚"的偏见 |
| 2022 | Valentino 全粉色系列 |
| 2022 | 《Barbie》电影预告片发布 |
| 2023 | 电影上映——全球粉色狂潮 |
| 2023 | Barbiecore 达到巅峰 |

### 为什么粉色回来了？

| 驱动力 | 解释 |
|--------|------|
| 女性赋权 | "粉色不是软弱——是力量" |
| 反讽 | 拥抱"刻板印象"作为反叛 |
| 快乐 | 疫情后渴望纯粹的快乐 |
| 怀旧 | 童年的芭比记忆 |
| 电影 | Greta Gerwig 的《Barbie》 |

### 核心哲学

Barbiecore 的精神是**"粉色是一种态度，不是一种性别"**：
- 女性化不等于软弱
- 塑料不等于肤浅
- 粉色不等于幼稚
- 芭比可以是任何人——医生、总统、宇航员
- "你可以是任何东西" (You can be anything)

## 视觉语法

### 色彩系统

```
主色：
  芭比粉 (#FF69B4) — 标志性
  热粉 (#FF1493) — 更强烈
  白色 (#FFFFFF) — 梦幻屋
  金色 (#FFD700) — 配饰
  浅粉 (#FFB6C1) — 柔和版

辅色：
  天蓝 (#87CEEB) — Ken 的颜色
  黄色 (#FFFF00) — 阳光
  紫色 (#800080) — 变体

规则：
  - 粉色是绝对主角
  - 高饱和度
  - 光泽感（塑料质感）
  - 可以全粉色（单色）
  - 白色和金色作为辅助

质感：
  塑料 — 光滑、反射
  亮片 — 闪亮、派对
  漆皮 — 光泽、人造
  丝绒 — 粉色丝绒
  水晶 — 闪耀
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 颜色 | 全粉色——从头到脚 |
| 服装 | 粉色套装、高跟鞋、太阳镜 |
| 空间 | 梦幻屋、粉色房间、塑料家具 |
| 配饰 | 粉色包、粉色手机壳、粉色一切 |
| 态度 | 自信、快乐、不在乎批评 |
| 符号 | 芭比logo、高跟鞋剪影、星星 |

## 与千禧怀旧的关系

### 童年芭比的回归
- 千禧一代的童年 = 芭比的黄金时代
- 2023年的电影 = "给大人看的芭比"
- 从"我长大了不玩芭比了"到"芭比是女权主义的"
- 这是一种"重新拥抱童年"的行为

### 与 Y2K 的交叉
- 2000s 的芭比 = Y2K 美学的一部分
- 粉色+亮片+塑料 = Y2K 的核心元素
- Barbiecore = Y2K 复兴的一个分支
