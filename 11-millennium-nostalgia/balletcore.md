## 历史脉络

### 2021–2022：从练功房到街头

Balletcore 在 2021 年末开始在 TikTok 和 Instagram 上流行，2022 年达到高峰：

**催化事件**：
- **Miu Miu 2022 春夏系列**：芭蕾元素的高端时尚化
- **《黑天鹅》(2010) 的持续文化影响**：暗黑芭蕾的视觉模板
- **疫情后的"优雅回归"**：从居家运动裤回到精致穿搭
- **TikTok #balletcore**：超过 20 亿播放

### 文化基因

芭蕾作为时尚灵感并非新事物：

| 时期 | 芭蕾×时尚 |
|------|-----------|
| 1950s | Audrey Hepburn 的芭蕾平底鞋 |
| 1990s | Kate Moss 的"heroin chic"芭蕾瘦 |
| 2000s | Repetto 芭蕾鞋的流行 |
| 2010 | 《黑天鹅》的暗黑芭蕾美学 |
| 2022 | Balletcore 作为完整生活方式美学 |

### 为什么是现在？

Balletcore 的流行反映了几种文化趋势的交汇：
1. **"纪律美学"**：在混乱的世界中，芭蕾代表秩序和自律
2. **女性气质的重新拥抱**：粉色、丝带、蕾丝不再"不女权"
3. **身体意识**：强调优雅的身体线条而非极端瘦
4. **Quiet Luxury 的延伸**：低调但精致

## 视觉语法

### 色彩系统

```
主色：
  裸粉 (#FADADD) — 芭蕾鞋的经典色
  白色 (#FFFFFF) — 练功服、tutu
  淡灰 (#D3D3D3) — 暖身裤、针织
  黑色 (#000000) — 紧身衣、《黑天鹅》
  缎面粉 (#F8C8DC) — 丝带、缎面鞋

质感：
  缎面 — 芭蕾鞋、丝带
  薄纱/tulle — tutu裙、覆盖层
  针织 — 暖身袜、裹身衣
  蕾丝 — 装饰细节
  丝绒 — 冬季版本
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 鞋 | 缎面芭蕾平底鞋（系带款）、足尖鞋造型 |
| 上衣 | 裹身上衣（wrap top）、紧身衣、针织开衫 |
| 下装 | tutu裙、百褶裙、紧身裤+暖腿套 |
| 配饰 | 丝带（头发/脖子/手腕）、珍珠发夹 |
| 发型 | 低马尾、芭蕾发髻（bun）、丝带编发 |
| 妆容 | 干净底妆+粉色腮红+裸色唇 |

## 与千禧怀旧的关系

### 2000年代的芭蕾记忆
- 很多千禧一代女孩小时候学过芭蕾
- 粉色芭蕾鞋 = 童年记忆
- 《天鹅湖》VCD = 家庭文化启蒙
- Balletcore 部分是对这种童年记忆的回溯

### 与 Coquette Y2K 的交叉
- 两者都强调"精致女性气质"
- 两者都使用粉色+丝带+蕾丝
- 区别：Coquette 更性感/挑逗，Balletcore 更纯净/纪律
