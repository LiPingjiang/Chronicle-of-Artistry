# Needle Lace 针绣蕾丝

> "Needle lace is architecture in thread — built stitch by stitch over a paper pattern with nothing but a needle and fine linen thread, each buttonhole stitch interlocking with the next to create fabric from air, structures so delicate they seem impossible yet so strong they have survived centuries." — Unknown

## 概述

针绣蕾丝（Needle Lace）是一种完全使用缝针和线，通过扣眼针法（buttonhole stitch/detached buttonhole stitch）及其变体，在纸样或临时基底上逐针构建的蕾丝。与梭芯蕾丝（bobbin lace）不同，针绣蕾丝不需要编织或交叉线——它完全由一根针和一根线构建，每一针都是独立的扣眼针脚，相互连接形成网状结构。

针绣蕾丝是蕾丝家族中最精细、最耗时的类型。历史上最著名的针绣蕾丝包括：威尼斯点蕾丝（Venetian Point/Punto in Aria）、法国阿朗松蕾丝（Point d'Alençon）、布鲁塞尔针绣蕾丝（Point de Gaze）等。这些蕾丝在16-18世纪是欧洲贵族的奢侈品——一件阿朗松蕾丝领饰可能需要数年时间完成。当代针绣蕾丝在艺术创作和文物修复中仍有重要地位。

## 中国语境

针绣蕾丝在中国相对小众，但中国有自己的"透空"刺绣传统——如抽纱（drawn thread work）和雕绣（cutwork）。中国的汕头抽纱是国家级非物质文化遗产，与针绣蕾丝有相似的透空效果。当代中国的一些刺绣艺术家和手工爱好者开始学习西方针绣蕾丝技法。中国的婚纱定制行业中有对蕾丝工艺的需求。中国的一些艺术院校在纤维艺术课程中教授针绣蕾丝。
