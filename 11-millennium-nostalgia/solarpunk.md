# Solarpunk 太阳朋克

![Solarpunk 概念图](../assets/artworks/solarpunk/solarpunk-concept-01.png)

> **"藤蔓缠绕的摩天楼、太阳能帆船、社区花园——一个我们真正想要生活的未来。"**

## 历史脉络

### 从绝望到希望

| 时代 | 对未来的想象 |
|------|-------------|
| 1980s | Cyberpunk — 高科技低生活，反乌托邦 |
| 2000s | Post-apocalyptic — 世界末日后的废墟 |
| 2010s | Dystopia — 《饥饿游戏》《黑镜》 |
| 2014+ | **Solarpunk — 如果我们选择希望呢？** |

### 关键时间线

| 年份 | 事件 |
|------|------|
| 2008 | "Solarpunk" 一词首次出现 |
| 2014 | Tumblr 上的 Solarpunk 社区形成 |
| 2019 | 气候运动推动 Solarpunk 主流化 |
| 2020s | 建筑、时尚、科技领域的实践 |

### 核心哲学

Solarpunk 的精神是**"另一个世界不仅是可能的，而且正在生长"**：
- 技术为人服务，不是人为技术服务
- 自然不是需要征服的，而是需要合作的
- 未来不必是反乌托邦
- 社区 > 公司
- 可持续 ≠ 牺牲，= 更好的生活

## 视觉语法

### 色彩系统

```
主色：
  翠绿 (#00A86B) — 植物、生命
  金黄 (#FFD700) — 阳光、能源
  天蓝 (#87CEEB) — 清洁空气、水
  暖白 (#FFF8DC) — 光明、希望
  珊瑚橙 (#FF7F50) — 社区、温暖

辅色：
  薰衣草 (#E6E6FA) — 花朵
  木色 (#DEB887) — 自然材料
  铜色 (#B87333) — 可持续金属

规则：
  - 自然色为主
  - 温暖、明亮、充满希望
  - 避免灰暗和冰冷
  - 绿色是绝对主角

质感：
  植物 — 藤蔓、苔藓、花朵
  木材 — 自然纹理、竹子
  玻璃 — 温室、太阳能板
  织物 — 天然纤维、手工编织
  水 — 清澈、流动、反射
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 建筑 | 垂直花园、绿色屋顶、温室穹顶 |
| 能源 | 太阳能板、风力发电、生物能 |
| 交通 | 自行车、帆船、电动公交、空中花园步道 |
| 社区 | 社区花园、公共厨房、图书馆 |
| 自然 | 藤蔓缠绕建筑、屋顶农场、城市森林 |
| 技术 | 可见的可持续技术、修复文化 |

## 与千禧怀旧的关系

### 对气候焦虑的回应
- 千禧一代/Z世代面对气候危机
- 反乌托邦叙事让人绝望
- Solarpunk = "我们可以做什么"的视觉答案
- 与 Frutiger Aero 的"自然+科技"精神共鸣

### 与 Frutiger Aero 的对比
- Frutiger Aero = 企业版的"自然+科技"（Windows Vista）
- Solarpunk = 社区版的"自然+科技"（草根运动）
- 两者都相信技术和自然可以共存
- Solarpunk 更政治化、更理想主义
