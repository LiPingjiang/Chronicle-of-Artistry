# Solarpunk 太阳朋克

> "Solarpunk is a movement in speculative fiction, art, and activism that imagines a sustainable future." — Solarpunk Manifesto

## 概述

太阳朋克（Solarpunk）是2010年代兴起的美学和文化运动，想象一个人类与自然和谐共存、可再生能源驱动、社区自治的乐观未来。它是赛博朋克反乌托邦的积极对立面——不是"高科技低生活"，而是"高科技高自然"。

太阳朋克的核心信念是：美好的未来不仅是可能的，而且是可以被设计和建造的。

## 核心特征

| 特征 | 描述 |
|------|------|
| 乐观未来 | 积极的、可实现的未来愿景 |
| 自然+科技 | 绿色植物与清洁技术的融合 |
| 可持续 | 太阳能、风能、循环经济 |
| 社区 | 去中心化的、互助的社区 |
| 新艺术风格 | Art Nouveau的有机曲线回归 |
| 多元文化 | 融合全球各地的建筑和文化 |

## 视觉特征

- **色彩**：翠绿、金色阳光、天蓝、花卉色
- **建筑**：覆盖植物的未来建筑——垂直花园
- **能源**：太阳能板、风力发电、生物发光
- **曲线**：Art Nouveau式的有机曲线
- **材质**：木材、竹子、玻璃、活体植物
- **氛围**：阳光明媚、生机勃勃、社区感
