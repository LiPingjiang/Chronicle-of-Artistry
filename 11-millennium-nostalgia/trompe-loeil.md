# Trompe-l'oeil 错视画

> "The purpose of trompe-l'oeil is to make the eye believe what the mind knows to be false." — Miriam Milman

## 概述

错视画（Trompe-l'oeil，法语"欺骗眼睛"）是一种极度写实的绘画技法，旨在创造三维空间的完美幻觉——让观众在第一眼无法分辨画面与现实的区别。从古罗马的壁画到巴洛克的天顶画，从荷兰静物画到当代的超写实壁画，错视画是人类追求视觉真实的极致表现。

错视画的乐趣在于那个"被骗"的瞬间——当你伸手去触摸画中的物体，才发现那只是颜料和画布。

## 核心特征

| 特征 | 描述 |
|------|------|
| 极度写实 | 追求照片级的写实精度 |
| 空间幻觉 | 在平面上创造三维幻觉 |
| 欺骗性 | 目的是欺骗观众的眼睛 |
| 技法精湛 | 需要极高的绘画技巧 |
| 光影精确 | 精确的光影和透视 |
| 日常题材 | 常描绘日常物品——书、信、昆虫 |

## 视觉特征

- **真实感**：无法与真实物体区分
- **阴影**：精确的投射阴影
- **质感**：完美模拟各种材质
- **透视**：精确的线性透视
- **尺度**：通常是1:1的真实尺度
- **边界**：模糊画面与现实的边界

## 中国语境

错视画在中国主要通过3D壁画和互动拍照装置为人所知。中国的商业空间和旅游景点大量使用错视画技法。中国传统绘画虽然不追求西方式的错视效果，但也有"以假乱真"的追求——如宋代花鸟画的精细写实。当代中国的超写实绘画在某种程度上继承了错视画的精神。

## 与其他风格的关系

- **Photorealism** → 照相写实主义继承了错视画的精神
- **Anamorphic Art** → 变形艺术是错视画的透视变体
- **Realism** → 写实主义追求真实但不一定追求欺骗
- **Baroque** → 巴洛克天顶画是错视画的巅峰
- **Street Art** → 3D街头画是当代错视画
- **Mural Art** → 错视壁画是壁画的重要形式
