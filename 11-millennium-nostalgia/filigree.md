# Filigree 金银丝工艺 | Filigrana

> **"金属的蕾丝——工匠用比头发还细的金银丝编织出凝固的光。"**

## 概述

金银丝工艺（Filigree / Filigrana）是一种精细的金属加工艺术，用极细的金丝或银丝（通常直径不到1毫米）扭绞、编织、焊接成精美的镂空图案。"Filigree"源自拉丁语"filum"（丝线）和"granum"（颗粒）。这种工艺有5000年以上的历史，从美索不达米亚传播到地中海、中亚、南亚和拉丁美洲。每个文化都发展出独特的地方风格——葡萄牙的Filigrana、印度的Tarkashi、中国的花丝镶嵌、印尼的Kerawang。

## 主要传统

| 地区 | 名称 | 特征 |
|------|------|------|
| 葡萄牙 | Filigrana | 心形、蝴蝶，国家象征 |
| 印度 | Tarkashi/Tarakasi | 奥里萨邦银丝工艺 |
| 中国 | 花丝镶嵌 | 宫廷工艺，镶嵌宝石 |
| 马耳他 | Filigrana Maltija | 十字架、船 |
| 厄瓜多尔 | Filigrana | 殖民时期传入 |
| 挪威 | Filigran | 维京传统，胸针 |

## 核心特征

- **极细金属丝**：直径不到1毫米
- **扭绞**：两根丝扭绞成绳
- **镂空**：透空的蕾丝效果
- **焊接**：微小焊点连接
- **颗粒装饰**：金属小球点缀
- **对称图案**：精确的对称构图

## 常见形式

| 形式 | 特征 |
|------|------|
| 首饰 | 耳环、项链、胸针 |
| 宗教器物 | 圣物箱、十字架 |
| 装饰盒 | 珠宝盒、烟盒 |
| 建筑装饰 | 铁艺栏杆 |
| 皇冠/头饰 | 宫廷头饰 |

## 视觉特征

- 极精细的金属丝线条
- 镂空的蕾丝般质感
- 金银的温暖光泽
- 对称的花卉和几何图案
- 微小颗粒的点缀
- 轻盈与精密的矛盾美
