## 历史脉络

### 2017：Facebook 的 Alegria

Corporate Memphis 的起源可以精确定位：

| 年份 | 事件 |
|------|------|
| 2017 | Facebook 委托 Buck Design 创作 "Alegria" 插画系统 |
| 2018 | Google、Slack、Spotify 纷纷采用类似风格 |
| 2019 | 成为科技公司的"默认"插画风格 |
| 2020 | 疫情期间无处不在（远程协作、健康、金融） |
| 2021–22 | 开始遭到广泛批评和讽刺 |
| 2023 | 逐渐被 3D 和 AI 生成插画取代 |

### 为什么它统治了科技界？

| 原因 | 解释 |
|------|------|
| 包容性 | 非自然肤色 = 不需要讨论种族 |
| 可扩展 | 模块化人物 = 快速生产 |
| 无害 | 快乐、简单 = 不会冒犯任何人 |
| 便宜 | 一套系统 = 所有场景 |
| 全球化 | 抽象 = 跨文化通用 |

### 为什么它被讨厌？

| 批评 | 解释 |
|------|------|
| 千篇一律 | 所有公司看起来一样 |
| 虚伪 | 用快乐插画掩盖裁员、隐私侵犯 |
| 无灵魂 | 没有个性、没有情感深度 |
| 居高临下 | 把用户当小孩对待 |
| "Globohomo" | 全球同质化的视觉象征 |

## 视觉语法

### 色彩系统

```
主色：
  紫色 (#7B61FF) — 最标志性的肤色
  蓝色 (#4A90D9) — 科技感
  粉色 (#FF6B9D) — 友好感
  橙色 (#FF8C42) — 活力
  绿色 (#4ECDC4) — 增长

规则：
  - 肤色必须是非自然的（紫、蓝、黄、绿）
  - 高饱和、低对比
  - 背景通常是纯色或极简渐变
  - 没有阴影或极少阴影

质感：
  完全平面 — 没有纹理
  圆角 — 一切都是圆的
  渐变 — 微妙的色彩过渡
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 人物 | 不成比例的四肢（小头大手）、非自然肤色 |
| 表情 | 永远微笑、永远快乐 |
| 动作 | 协作、庆祝、跳跃、握手 |
| 场景 | 抽象空间、浮动元素、无重力 |
| 物品 | 笔记本电脑、手机、植物、咖啡杯 |
| 缺失 | 没有阴影、没有细节、没有个性 |

## 与千禧怀旧的关系

### 2010s 科技乐观主义的遗产
- Corporate Memphis 是硅谷"让世界更美好"叙事的视觉产物
- 当这个叙事崩塌（隐私丑闻、裁员、AI焦虑），风格也随之被抛弃
- 它将成为 2017–2022 时代的视觉标记

### 未来的怀旧对象？
- 就像我们现在怀念 Frutiger Aero
- 10年后人们可能会怀念 Corporate Memphis
- "还记得那个所有人都是紫色的时代吗？"
