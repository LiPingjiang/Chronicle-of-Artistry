## 历史脉络

### 从 Facebook 到"所有科技公司"

| 年份 | 事件 |
|------|------|
| 2017 | Facebook 委托 BUCK 设计 "Alegria" 插画系统 |
| 2018 | Google、Slack、Airbnb 纷纷采用类似风格 |
| 2019 | 成为科技行业默认插画语言 |
| 2020 | 疫情期间无处不在（远程办公宣传） |
| 2021 | 开始被广泛批评和讽刺 |
| 2023 | 逐渐被 3D、AI 生成和更多元的风格取代 |

### 为什么所有科技公司都用它？

| 原因 | 解释 |
|------|------|
| 多样性 | 无脸+各种肤色 = "包容"但不具体 |
| 可扩展 | 模块化人物 = 快速生产 |
| 无争议 | 足够抽象 = 不冒犯任何人 |
| 便宜 | 一套系统 = 无限场景 |
| "人性化" | 有人物 = "我们关心人" |

### 核心哲学（及其批评）

Corporate Memphis 的精神是**"让科技看起来温暖、包容、人性化"**——但批评者认为：
- 它实际上是"用可爱掩盖冷酷"
- 无脸人物 = "我们不把你当个体"
- 所有公司看起来一样 = 没有个性
- "多样性"只是表面的——肤色不同但都没有脸
- 是资本主义的"友善面具"

## 视觉语法

### 色彩系统

```
主色：
  紫色 (#6C63FF) — 科技、创新
  蓝色 (#4A90D9) — 信任、专业
  粉色 (#FF6B9D) — 温暖、人性
  黄色 (#FFD93D) — 乐观、活力
  珊瑚 (#FF6F61) — 友好、现代

辅色：
  绿色 (#6BCB77) — 成长、健康
  橙色 (#FF9F43) — 创意、能量
  深蓝 (#2C3E50) — 背景

规则：
  - 高饱和度
  - 扁平（无渐变或极少渐变）
  - 颜色组合"友好"
  - 肤色多样但都不真实
  - 背景色柔和

质感：
  完全扁平 — 无阴影
  偶尔纹理 — 噪点叠加
  几何 — 圆形、椭圆
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 人物 | 无脸/简化面部、夸张长肢体、不可能的姿势 |
| 植物 | 几何化叶子、简化花朵 |
| 物品 | 笔记本电脑、手机、咖啡杯 |
| 场景 | 办公室、协作、庆祝、远程工作 |
| 构图 | 人物居中、对称、留白 |
| 动作 | 跳跃、击掌、举手、瑜伽 |

## 与千禧怀旧的关系

### 2017–2023 的时代标记
- 如果你在 2020 年打开任何科技产品的网站——你会看到它
- 它定义了一个时代的"科技公司长什么样"
- 现在回看 = "那个所有公司看起来一样的时代"
- 正在成为一种"怀旧"——讽刺的怀旧

### 为什么消亡？
- 审美疲劳——"又是这种画风"
- AI 生成图片的冲击
- 3D 插画的兴起
- 品牌需要差异化
- 公众对"假包容"的反感

---

## 中国语境

- 中国互联网公司大量使用类似风格
- 美团、字节、阿里的产品插画
- "扁平插画"/"运营插画"的行业术语
- 同样面临审美疲劳和批评
- 正在被 3D、国潮插画取代
