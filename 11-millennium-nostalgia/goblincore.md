# Goblincore 哥布林核

![Goblincore 概念图](../assets/artworks/goblincore/goblincore-concept-01.png)

> **"泥巴、蘑菇、闪亮的石头、青蛙——拥抱'不美'的东西，因为它们才是真正有趣的。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2019–至今 |
| 别名 | Goblincore, Gremlincore, Frogcore |
| 核心色彩 | 苔藓绿、泥土棕、蘑菇米、石头灰、金色（闪亮物） |
| 关键元素 | 蘑菇、青蛙、蜗牛、石头、泥巴、闪亮小物件 |
| 代表人物 | Tumblr/TikTok 社区 |
| 关联风格 | Cottagecore, Witchcore, Dark Academia, Forestcore |

---

## 历史脉络

### 从 Tumblr 到 TikTok

| 年份 | 事件 |
|------|------|
| 2019 | Tumblr 上 Goblincore 标签出现 |
| 2020 | TikTok 上爆发（疫情期间户外探索） |
| 2021 | 与 Cottagecore 并列为主流美学 |
| 2022–至今 | 时尚、家居、艺术领域扩展 |

### 它反对什么？

| 主流美学 | Goblincore 的回应 |
|---------|------------------|
| "美"的标准 | "丑"也是有趣的 |
| 整洁 | 混乱是自然的 |
| 精致 | 粗糙才真实 |
| 消费主义 | 路边的石头比钻石有趣 |
| 人类中心 | 蜗牛和青蛙也值得关注 |

### 核心哲学

Goblincore 的精神是**"在'不美'的事物中发现快乐"**：
- 蘑菇比玫瑰有趣
- 泥巴不是脏——是大地的质感
- 收集闪亮的石头是正当爱好
- 青蛙是完美的生物
- "像哥布林一样生活" = 跟随好奇心

## 视觉语法

### 色彩系统

```
主色：
  苔藓绿 (#4A5D23) — 森林地面
  泥土棕 (#8B4513) — 大地
  蘑菇米 (#F5DEB3) — 菌类
  石头灰 (#696969) — 岩石
  金色 (#FFD700) — 闪亮物件

辅色：
  青蛙绿 (#32CD32) — 两栖动物
  深红 (#8B0000) — 毒蘑菇
  紫色 (#4B0082) — 水晶

规则：
  - 自然色、不饱和
  - 泥土质感
  - 潮湿感
  - 偶尔的闪亮（石头、甲虫壳）
  - 不追求"好看"

质感：
  苔藓 — 柔软、潮湿
  泥土 — 粗糙、有机
  蘑菇 — 光滑、奇异
  石头 — 粗糙或抛光
  树皮 — 纹理、层次
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 菌类 | 各种蘑菇（尤其是毒蝇伞） |
| 动物 | 青蛙、蜗牛、甲虫、蝾螈 |
| 矿物 | 石头、水晶、化石、贝壳 |
| 植物 | 苔藓、蕨类、地衣 |
| 收藏 | 闪亮小物件、瓶子、骨头 |
| 环境 | 森林地面、溪流、洞穴 |

## 与千禧怀旧的关系

### 对"精致生活"的反叛
- Instagram 时代 = 一切都要"好看"
- Goblincore = "我不在乎好不好看，我觉得有趣"
- 这是千禧一代/Z世代对"完美主义"的解药
- 与 ADHD/神经多样性社区的共鸣

### 与 Cottagecore 的对比
| Cottagecore | Goblincore |
|-------------|-----------|
| 美丽的花园 | 潮湿的森林地面 |
| 烤面包 | 收集石头 |
| 整洁 | 混乱 |
| 浪漫 | 好奇 |
| 精致 | 粗糙 |
| 田园诗 | 探险 |
