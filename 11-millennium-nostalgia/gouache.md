# Gouache 水粉画

> "Gouache is watercolor's bolder, more opaque sibling." — Traditional saying

## 概述

水粉画（Gouache）是一种不透明的水性颜料绘画技法，与水彩画共享水溶性媒介，但因添加了白色颜料或粉质填料而具有覆盖力。水粉画兼具水彩的流动性和油画的覆盖力，是插画、设计和纯艺术中广泛使用的媒介。

水粉的独特魅力在于它干燥后的哑光质感——平坦的、天鹅绒般的表面，没有油画的光泽也没有水彩的透明，创造出一种独特的"设计感"。

## 核心特征

| 特征 | 描述 |
|------|------|
| 不透明 | 可以覆盖底层——从暗到亮 |
| 水溶性 | 用水稀释和清洗 |
| 哑光表面 | 干燥后平坦的天鹅绒质感 |
| 快干 | 比油画快得多的干燥速度 |
| 可重新激活 | 干后加水可重新溶解 |
| 设计感 | 平涂效果适合插画和设计 |

## 视觉特征

- **表面**：平坦的、哑光的、无光泽
- **色彩**：干后略微变浅——需要经验补偿
- **笔触**：可以非常平滑也可以保留笔触
- **覆盖**：可以从暗色上画亮色
- **边缘**：可以非常锐利的边缘
- **质感**：粉质的、柔和的表面
