> **"2-step节奏、Moschino、香槟——90年代末伦敦最时髦的声音。"**

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1994 | Speed Garage 从 Jungle 中分化 |
| 1997 | 2-Step 风格确立——MJ Cole, Tuff Jam |
| 1999 | Artful Dodger "Re-Rewind"——主流突破 |
| 2000 | Craig David "Fill Me In"——UKG 巅峰 |
| 2001 | So Solid Crew "21 Seconds"——暗面 |
| 2002 | UKG 衰落——分化为 Grime 和 Dubstep |

### 核心哲学

UK Garage 的精神是**"跳舞要穿最好的衣服——派对是认真的事"**：
- 时尚 = 必须（"不穿好不让进"）
- 2-step = 优雅（"比 Jungle 更性感"）
- 香槟 = 态度（"我们值得最好的"）
- 伦敦 = 身份（"这是我们的声音"）
- "Jungle 太快，House 太慢——Garage 刚刚好"

## 与千禧怀旧的关系

### 千禧年伦敦的声音
- UK Garage = 1999-2001 伦敦最流行的音乐
- Craig David = 千禧年英国流行文化的符号
- "如果你在2000年的伦敦——你一定听过 Garage"
- Ayia Napa = UKG 的"伊比萨"

### Grime 和 Dubstep 的直接前身
- UK Garage (2000) → Grime (2002) + Dubstep (2003)
- Wiley, Dizzee Rascal 从 UKG 场景中出来
- "没有 UK Garage 就没有 Grime——没有 Grime 就没有 Stormzy"

---

## 中国语境

- UK Garage 在中国极为小众
- 与中国 R&B/电子音乐的交叉
- 2-step 节奏在中国制作人中的影响
- 作为"英国电子音乐史"的重要章节
