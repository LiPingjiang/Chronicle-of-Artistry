# Ikat 伊卡特 | イカット / Ikat

> **"染在线上的幻影——织布前先把经线扎染出图案，织出来的布自带朦胧的'呼吸感'。"**

## 概述

伊卡特（Ikat / イカット）是一种全球性的扎染织物技法，在织布之前先将经线（warp）和/或纬线（weft）按照预定图案进行扎染，然后再上织机编织。由于扎染的边界不可能完全精确，织出的图案天然带有柔和的模糊边缘——这种"呼吸感"或"羽化效果"是伊卡特最独特的视觉特征。伊卡特在全球多个文化中独立发展：印尼（最著名）、中亚乌兹别克斯坦、日本（絣 kasuri）、印度（Patola）、危地马拉等。

| 地区 | 名称 | 特征 |

| 日本 | 絣 Kasuri | 经纬双扎染 |
| 印度古吉拉特 | Patola | 双面伊卡特，极精密 |
| 危地马拉 | Jaspe | 纬线扎染 |
| 马略卡 | Roba de Llengües | "舌头布" |

## 核心特征

- **先染后织**：织布前扎染纱线
- **模糊边缘**：图案天然的羽化效果
- **经线/纬线/双面**：三种扎染方式
- **精确计算**：需要精确计算图案位置
- **多次浸染**：多色需要多次扎染
- **全球分布**：多文化独立发展

## 视觉特征

- 图案边缘的柔和模糊
- "呼吸感"的独特质感
- 几何或有机的重复图案
- 丝绸的光泽（中亚）
- 棉布的质朴（东南亚）
- 色彩的渐变和层次
