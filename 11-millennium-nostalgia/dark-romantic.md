## 历史脉络

### 从浪漫主义到当代

| 时代 | 表现 |
|------|------|
| 1800s | 浪漫主义文学——拜伦、雪莱、济慈 |
| 1980s | 哥特摇滚——Siouxsie、The Cure |
| 2000s | Tim Burton 电影美学 |
| 2019 | TikTok/Instagram 上的 Dark Romantic 社区 |
| 2022–至今 | 与 Dark Feminine 运动合流 |

### 它融合了什么？

| 来源 | 贡献 |
|------|------|
| 浪漫主义 | 情感、自然、崇高 |
| 哥特 | 黑色、死亡、神秘 |
| 维多利亚 | 蕾丝、束腰、仪式 |
| 巴洛克 | 戏剧、奢华、过度 |
| 当代 | 女性赋权、自我表达 |

### 核心哲学

Dark Romantic 的精神是**"美丽和痛苦是同一枚硬币的两面"**：
- 枯萎的玫瑰比盛开的更美——因为它知道时间
- 黑色不是悲伤——是深度
- 脆弱是一种力量
- 情感不需要隐藏——需要被艺术化
- "我选择在黑暗中寻找美"

## 视觉语法

### 色彩系统

```
主色：
  黑色 (#0D0D0D) — 基础、深度
  深红 (#8B0000) — 玫瑰、血、激情
  暗紫 (#2E0854) — 神秘、贵族
  金色 (#B8860B) — 烛光、装饰
  象牙白 (#FFFFF0) — 蕾丝、肌肤

辅色：
  深绿 (#013220) — 常春藤、苔藓
  铜色 (#B87333) — 古老金属
  灰色 (#696969) — 石头、灰烬

规则：
  - 深色为主
  - 暖色调的黑（不是冷黑）
  - 金色/红色作为点缀
  - 高对比度（黑+白/金）
  - 烛光色温

质感：
  蕾丝 — 精致、脆弱
  天鹅绒 — 深沉、奢华
  丝绸 — 流动、光泽
  枯花 — 时间、美丽的消逝
  蜡 — 烛光、流淌
```

### 标志性元素

## 与千禧怀旧的关系

### Tim Burton 的一代
- 千禧一代成长于 Tim Burton 电影时代
- 《剪刀手爱德华》《僵尸新娘》= 童年记忆
- Dark Romantic = 这些记忆的"成人版"
- "美丽的怪物"比"正常的人"更有趣

### 与 Dark Feminine 的合流
- 2022年的 "Dark Feminine" 运动
- 从"甜美女孩"到"神秘女人"
- Dark Romantic 提供了视觉语言
- 黑色蕾丝+红唇+自信 = 当代表达
