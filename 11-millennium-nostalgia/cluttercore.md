# Cluttercore 杂物核

![Cluttercore 概念图](../assets/artworks/cluttercore/cluttercore-concept-01.png)

> **"每一面墙都挂满东西、每个角落都有故事——'断舍离'的反义词。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2020–至今 |
| 别名 | Cluttercore, Maximalist Living, Anti-Minimalism |
| 核心色彩 | 全光谱——没有限制，越多越好 |
| 关键元素 | 收藏品堆叠、照片墙、书堆、植物丛林、纪念品 |
| 代表人物 | TikTok 社区、Iris Apfel |
| 关联风格 | Maximalism, Goblincore, Kidcore, Grandmillennial |

## 历史脉络

### 对极简主义的全面反叛

| 年份 | 事件 |
|------|------|
| 2015–19 | "断舍离"/"极简生活"统治社交媒体 |
| 2019 | Marie Kondo 的 Netflix 节目 |
| 2020 | 疫情居家——人们开始"筑巢" |
| 2020 | TikTok 上 #Cluttercore 标签爆发 |
| 2021–至今 | 成为与极简主义对等的生活美学 |

### 它反对什么？

| 极简主义说 | Cluttercore 说 |
|-----------|---------------|
| "少即是多" | "多即是多" |
| "不spark joy就扔" | "每样东西都spark joy" |
| "空间要呼吸" | "空间要讲故事" |
| "统一色调" | "什么颜色都要" |
| "买少买好" | "收集是人类本能" |

### 核心哲学

Cluttercore 的精神是**"你的空间应该讲述你的故事"**：
- 每件物品都是一段记忆
- 收藏不是"囤积"——是策展
- 空间应该反映你是谁，不是杂志封面
- "整洁"不等于"好"
- 混乱中有自己的秩序

## 视觉语法

### 色彩系统

```
主色：
  没有限制！
  但通常包含：
  暖色调 — 因为"家"的感觉
  复古色 — 因为很多是旧物
  鲜艳色 — 因为收藏品通常很亮

规则：
  - 没有配色规则
  - 越多颜色越好
  - 不追求"和谐"
  - 让物品本身的颜色说话

质感：
  层叠 — 物品叠物品
  混合 — 新旧混搭
  手工 — DIY、手作
  复古 — 二手、vintage
  自然 — 植物、干花
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 墙面 | 照片墙、画作、海报、挂毯、镜子 |
| 平面 | 书堆、蜡烛、小摆件、植物 |
| 收藏 | 唱片、手办、明信片、贝壳 |
| 植物 | 室内丛林、悬挂植物、多肉 |
| 纺织 | 抱枕堆、毯子层叠、地毯叠地毯 |
| 书籍 | 到处都是书——地上、桌上、床头 |

## 与千禧怀旧的关系

### 对"Instagram 完美"的反叛
- 2015–2020 = 极简、白墙、"高级感"
- 千禧一代被告知"少即是多"
- 但内心渴望"被物品包围"的安全感
- Cluttercore = "我终于可以不扔东西了"

### 与 Grandmillennial 的交叉
- 两者都热爱"奶奶家"的感觉
- 碎花、瓷器、旧家具
- "老派"不是贬义——是温暖

## 中国语境

- "杂物核"/"反断舍离"在小红书的讨论
- 中国版 Cluttercore：满墙的冰箱贴、手办柜、照片墙
- 与"中古风"/"vintage"的交叉
- 对"日式极简"的反叛
- "我的房间我做主"的态度

## 设计应用

| 场景 | 应用方式 |
|------|----------|
| 空间 | 照片墙+收藏展示+植物丛林+层叠纺织 |

| 数字 | 密集排版+多元素+拼贴风格 |
| 零售 | 密集陈列+故事感+发现感 |
