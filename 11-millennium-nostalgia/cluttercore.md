# Cluttercore 杂物核

![Cluttercore 概念图](../assets/artworks/cluttercore/cluttercore-concept-01.png)

> **"满墙收藏品、堆叠的书、每个角落都有故事——极简主义的反义词。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2020–至今 |
| 别名 | Cluttercore, Maximalist Living, Organized Chaos |
| 核心色彩 | 多彩混合、暖色调为主、无固定色板 |
| 关键元素 | 收藏品、书堆、植物、纪念品、手工艺品 |
| 代表人物 | 古着店主、收藏家、艺术家工作室 |
| 关联风格 | Maximalism, Grandmillennial, Goblincore, Kidcore |

## 历史脉络

### 对极简主义的反叛

| 年份 | 事件 |
|------|------|
| 2014 | Marie Kondo《怦然心动的人生整理魔法》 |
| 2019 | Netflix 版 KonMari 方法 |
| 2020 | 疫情期间人们重新审视"拥有" |
| 2020 | TikTok #Cluttercore 出现 |
| 2021 | 成为对"断舍离"文化的正式反叛 |

### 它反对什么？

| 极简主义 | Cluttercore |
|---------|-------------|
| "少即是多" | "多即是多" |
| 扔掉 | 收藏 |
| 空白墙面 | 满墙装饰 |
| "不spark joy就扔" | "一切都spark joy" |
| 统一色调 | 混搭色彩 |
| 消费克制 | 收藏热情 |

### 核心哲学

Cluttercore 的精神是**"我的空间是我人生的博物馆"**：
- 每个物品都有故事
- "乱"不等于"脏"——是有序的混乱
- 收藏是一种自我表达
- 空间应该反映你是谁，不是杂志封面
- "我不需要为拥有东西而道歉"

## 视觉语法

### 色彩系统

```
规则：
  - 没有固定色板——这就是重点
  - 暖色调为主（因为物品多→需要温暖感）
  - 颜色来自物品本身，不是预设
  - 越多越好
  - 和谐来自"密度"而非"统一"

质感：
  书籍 — 纸张、布面
  陶瓷 — 杯子、花瓶
  织物 — 毯子、靠垫
  木头 — 架子、框架
  金属 — 复古器具
  植物 — 绿色、生命
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 墙面 | 画廊墙、明信片、海报、照片 |
| 架子 | 书堆、小摆件、植物、蜡烛 |
| 织物 | 多层毯子、混搭靠垫、挂毯 |
| 收藏 | 黑胶唱片、复古玩具、旅行纪念品 |
| 植物 | 大量室内植物、悬挂植物 |
| 氛围 | "有人住在这里"的温暖感 |

## 与千禧怀旧的关系

### 疫情时代的"拥有"
- 2020 被困在家 → 重新审视自己的空间
- "我的东西让我感到安全"
- 对极简主义"扔掉一切"的反弹
- 怀旧物品 = 情感锚点

### 与 Goblincore 的交叉
- 两者都热爱"收集"
- Goblincore = 收集自然物品（石头、蘑菇）
- Cluttercore = 收集一切
- 共同点：拒绝"少即是多"
