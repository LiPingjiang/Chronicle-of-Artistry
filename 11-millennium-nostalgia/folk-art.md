# Folk Art 民间艺术

![Folk Art 概念图](../assets/artworks/folk-art/folk-art-concept-01.png)

> **"没有学院、没有理论——只有一代代人用双手传递的美。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 史前–至今（跨文化、跨时代） |
| 别名 | Folk Art, Vernacular Art, Traditional Art, 民间美术 |
| 核心色彩 | 因地域而异——中国红、墨西哥彩、北欧蓝白、非洲土色 |
| 关键元素 | 手工制作、地域特色、功能性装饰、代际传承、叙事性 |
| 代表人物 | 匿名的民间艺人群体、Grandma Moses, Howard Finster |
| 关联风格 | Naive Art, Outsider Art, Paper Cut Art, Craft, Kitsch |

---

## 历史脉络

| 年份 | 事件 |
|------|------|
| 史前 | 岩画、陶器装饰——最早的"民间艺术" |
| 中世纪 | 欧洲民间装饰传统——木雕、刺绣、陶瓷 |
| 1800s | 工业革命——民间艺术开始被"发现"和收藏 |
| 1930s | WPA项目——美国民间艺术的系统记录 |
| 1960s | 民间艺术作为"反现代主义"被重新评价 |
| 2000s | 全球化时代——民间艺术的保护与复兴 |
| 2020s | "新民间"——当代设计师对民间元素的重新诠释 |

### 核心哲学

民间艺术的精神是**"艺术不属于美术馆——属于生活"**：
- 功能 = 美（"碗上的花纹不是装饰——是祝福"）
- 传承 = 生命（"母亲教女儿——女儿教孙女——技艺就这样活着"）
- 地域 = 身份（"看花纹就知道你来自哪里"）
- 匿名 = 集体（"不需要签名——因为这是所有人的艺术"）
- "民间艺术是人类最古老、最持久的创造力表达"

## 视觉语法

### 色彩系统

```
因地域而异：

中国：
  红色 (#FF0000) — 喜庆、生命
  金色 (#FFD700) — 富贵、吉祥
  黑色 (#000000) — 墨、力量

墨西哥：
  热粉 (#FF1493) — 生命、庆典
  天蓝 (#00BFFF) — 天空、精神
  橙黄 (#FFA500) — 太阳、丰收

北欧：
  深蓝 (#00008B) — 海洋、冬天
  红色 (#B22222) — 温暖、传统
  白色 (#FFFFFF) — 雪、纯净

规则：
  - 地域决定色彩
  - 天然颜料的限制
  - 高饱和、高对比
  - 象征意义优先

质感：
  手工 — 不完美、温暖
  天然 — 木、陶、布、纸
  重复 — 图案、节奏
  磨损 — 时间的痕迹
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 媒介 | 木雕、刺绣、陶瓷、编织、剪纸、绘画 |
| 图案 | 花卉、动物、几何、叙事场景 |
| 功能 | 装饰+实用（碗、衣服、家具、建筑） |
| 传承 | 口传心授、家族、社区 |
| 象征 | 祝福、保护、丰收、生育、死亡 |
| 态度 | 集体、传承、功能、地域、生活 |

## 与千禧怀旧的关系

### "新民间"运动
- 全球化 → 地域身份焦虑 → 民间艺术复兴
- 设计师重新发现民间元素 → "新民间"设计
- "在所有东西都长一样的时代——民间艺术是最后的'地方性'"
- 手工复兴运动 = 民间艺术精神的当代表达

### 品牌中的民间元素
- Marimekko (芬兰)、Anthropologie——民间美学的商业化
- 中国"国潮"——民间元素的当代重新诠释
- "民间艺术不是'过去的'——是'一直在的'"

## 中国语境

- 中国民间艺术的极其丰富传统
- 剪纸、年画、刺绣、泥塑、皮影、木版画
- 非物质文化遗产保护
- "国潮"设计中的民间元素复兴
