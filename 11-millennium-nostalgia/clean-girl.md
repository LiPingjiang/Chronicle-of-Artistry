# Clean Girl 干净女孩

![Clean Girl 概念图](../assets/artworks/clean-girl/clean-girl-concept-01.png)

> **"光泽肌肤、slicked-back发型、金色耳环——'我没化妆'的妆需要45分钟。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2021–至今 |
| 别名 | Clean Girl, That Girl, Vanilla Girl |
| 核心色彩 | 裸色、奶油白、焦糖棕、金色、橄榄绿 |
| 关键元素 | 光泽肌肤、极简珠宝、中性色调、健康生活方式 |
| 代表人物 | Hailey Bieber、Matilda Djerf |
| 关联风格 | Minimalist Digital, Normcore, Quiet Luxury, Scandinavian |

---

## 历史脉络

### TikTok 时代的"effortless"

| 年份 | 事件 |
|------|------|
| 2021 | "That Girl" 趋势（5am起床、绿色果汁） |
| 2022 | "Clean Girl" 美妆趋势爆发 |
| 2022 | Hailey Bieber 的 "glazed donut skin" |
| 2023 | 扩展到时尚、家居、生活方式 |
| 2023–至今 | 与 "Quiet Luxury" 合流 |

### 它代表什么？

| 元素 | 含义 |
|------|------|
| 光泽肌肤 | 健康、年轻、"不需要遮盖" |
| 极简珠宝 | 品味、不炫耀 |
| 中性色 | "我不需要颜色来吸引注意" |
| 健康生活 | 自律、自我投资 |
| "Effortless" | "我天生就这样"（其实很努力） |

### 核心哲学

Clean Girl 的精神是**"看起来毫不费力的完美"**：
- 少即是多（但那个"少"必须是最好的）
- 健康 > 化妆
- 品质 > 数量
- "自然美" = 精心维护的自然
- 自律是最高形式的自我关爱

## 视觉语法

### 色彩系统

```
主色：
  裸色 (#F5DEB3) — 肌肤、自然
  奶油白 (#FFFDD0) — 干净、纯粹
  焦糖棕 (#D2691E) — 温暖、健康
  金色 (#FFD700) — 珠宝、光泽
  橄榄绿 (#808000) — 健康、自然

辅色：
  黑色 (#000000) — 极简
  灰色 (#808080) — 中性
  米色 (#F5F5DC) — 温暖

规则：
  - 中性色调
  - 低饱和度
  - 温暖色温
  - 光泽感（不是哑光）
  - 极简——每个元素都有目的

质感：
  光泽 — 肌肤、唇部、发丝
  丝滑 — 面料、头发
  金属 — 极简珠宝
  大理石 — 浴室、桌面
  亚麻 — 自然面料
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 美妆 | 光泽肌肤、裸色唇、自然眉 |
| 发型 | Slicked-back、低马尾、claw clip |
| 珠宝 | 金色小耳环、细项链、极简戒指 |
| 服装 | 中性色、基础款、质感面料 |
| 生活 | 绿色果汁、瑜伽、晨跑、日记 |
| 空间 | 白色+木色+极简+植物 |

## 与千禧怀旧的关系

### 对 Y2K 极繁的反应
- Y2K = 闪亮、夸张、"更多更好"
- Clean Girl = 安静、克制、"少即是多"
- 这是钟摆的另一端
- 但两者都是千禧/Z世代的表达

### 与 "Quiet Luxury" 的合流
- Clean Girl (个人) + Quiet Luxury (品牌) = 同一种精神
- "不需要logo来证明品味"
- "看起来贵但不炫耀"
- 2023年的主流美学方向

---

## 中国语境

- "干净感"/"清冷感"在小红书的流行
- "That Girl"早起打卡文化
- 与"高级感"/"氛围感"的交叉
- 中国版 Clean Girl：极简护肤+基础款穿搭
- 对"精致穷"的反思——"少买但买好"
