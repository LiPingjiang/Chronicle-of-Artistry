# Lithography 石版画

> "Lithography is the most painterly of all print techniques." — June Wayne

## 概述

石版画（Lithography，希腊语"石头书写"）是基于油水不相容原理的平版印刷技法——在石灰石板上用油性材料绘画，然后用水和油墨交替处理，使油墨只附着在绘画区域。1796年由阿洛伊斯·塞内费尔德发明，石版画以其能完美再现绘画笔触的特性，成为艺术家最喜爱的版画形式之一。

石版画的革命在于：它是第一种让艺术家可以像在纸上画画一样自由创作的版画技法——不需要雕刻，不需要酸蚀，只需要画。

## 核心特征

| 特征 | 描述 |
|------|------|
| 平版 | 平版印刷——非凸非凹 |
| 油水分离 | 基于油水不相容原理 |
| 自由 | 可以像画画一样自由 |
| 笔触 | 完美保留绘画笔触 |
| 色彩 | 适合多色套印 |
| 大量 | 可以大量印刷 |

## 视觉特征

- **笔触**：保留原始绘画笔触
- **柔和**：柔和的色调过渡
- **色彩**：丰富的多色效果
- **质感**：石头纹理的微妙质感
- **平面**：均匀的墨色分布
- **自由**：自由流畅的线条

## 中国语境

石版画在中国的版画教育体系中占有重要地位。中国的美术学院版画系通常设有石版画工作室。中国当代石版画家在技法和观念上都有独特探索。石版画的"画"的特性使其特别适合中国艺术家的表现需求。中国的石版画在国际版画双年展中有良好声誉。

## 与其他风格的关系

- **Etching** → 蚀刻是凹版，石版是平版
- **Poster Art** → 海报艺术大量使用石版画
- **Printmaking** → 版画是石版画的上位类别
- **Drawing** → 石版画最接近绘画的版画
- **Pop Art** → 波普艺术使用石版画复制
- **Book Art** → 书籍插图中的石版画
