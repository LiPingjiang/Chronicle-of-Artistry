# Lithography 石版印刷

> "Lithography is drawing on stone — the artist's hand transfers directly to print, preserving every nuance of the original mark." — Unknown

## 概述

石版印刷（Lithography）是基于油水不相容原理的平版印刷技法。艺术家用油性蜡笔或墨水在平滑的石灰石板（或金属板）上绘画，经过化学处理后，油性图案区域吸附油墨而排斥水，空白区域吸水而排斥油墨。石版印刷的革命性在于：它是第一种允许艺术家像在纸上画画一样自由绘制，然后精确复制的印刷技法——不需要雕刻或蚀刻。

石版印刷的魅力在于：直接性——艺术家的每一笔、每一个细微的笔触都被忠实地保留和复制，如同绘画的"克隆"。

## 核心特征

| 特征 | 描述 |
|------|------|
| 平版 | 平面的印刷原理 |
| 油水 | 基于油水不相容 |
| 石板 | 传统使用石灰石 |
| 直接 | 直接绘画式创作 |
| 精确 | 精确复制原画 |
| 层次 | 丰富的灰度层次 |

## 视觉特征

- **细腻**：极其细腻的灰度
- **笔触**：保留原始笔触
- **层次**：丰富的明暗层次
- **柔和**：柔和的边缘过渡
- **绘画**：如同原画的效果
- **色彩**：多色套印的可能

## 中国语境

石版印刷在19世纪末传入中国，对中国近代出版业产生了重要影响——上海的石印书局大量出版了中国古典文献。在艺术领域，中国的版画艺术家也使用石版技法创作。中国美术学院等院校设有版画专业，石版是重要的教学内容。当代中国的石版画艺术家在国际版画展中有活跃的表现。
