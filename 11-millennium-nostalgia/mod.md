# Mod 摩德文化

![Mod 概念图](../assets/artworks/mod/mod-concept-01.png)

> **"Vespa 踏板车、Fred Perry Polo衫、The Who——60年代英国工人阶级的优雅反叛。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 1958–1967/1979复兴/至今 |
| 别名 | Mod, Modernist, Mods |
| 核心色彩 | 海军蓝、白色、红色、黑色、卡其 |
| 关键元素 | 修身西装、Vespa踏板车、靶心标志、Parka外套 |
| 代表人物 | The Who, The Kinks, Small Faces, Paul Weller |
| 关联风格 | Skinhead (早期), Britpop, Northern Soul, Ska |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1958 | Mod 文化在伦敦 Soho 区兴起 |
| 1964 | Mods vs Rockers——布莱顿海滩冲突 |
| 1965 | The Who "My Generation"——Mod 圣歌 |
| 1967 | 原始 Mod 衰落——嬉皮士兴起 |
| 1979 | Mod Revival——The Jam, Quadrophenia 电影 |
| 1990s | Britpop 中的 Mod 元素（Oasis, Blur） |

### 核心哲学

Mod 的精神是**"工人阶级也可以比贵族更有品味"**：
- 优雅 = 反叛（"我们穿得比老板好"）
- 细节 = 一切（"纽扣的数量很重要"）
- 现代 = 核心（"我们是现代主义者"）
- 音乐 = 生活（R&B、Soul、Ska）
- "我们骑 Vespa，不是因为买不起车——是因为它更酷"

## 视觉语法

### 色彩系统

```
主色：
  海军蓝 (#000080) — 西装、Parka
  白色 (#FFFFFF) — 衬衫、Polo
  红色 (#FF0000) — 靶心标志
  黑色 (#000000) — 鞋、配饰
  卡其 (#C3B091) — Parka

辅色：
  酒红 (#722F37) — Fred Perry
  森林绿 (#228B22) — Parka 内衬
  灰色 (#808080) — 西装

规则：
  - 干净、修身、精确
  - 不超过3种颜色
  - 靶心 = Mod 的视觉符号
  - 英国国旗 = 文化认同

质感：
  羊毛 — 西装
  棉 — Polo、衬衫
  尼龙 — Parka
  皮革 — 鞋、手套
  铬 — Vespa、镜子
```

| 类别 | 元素 |

## 与千禧怀旧的关系

### Britpop 和 Indie 的根源
- Mod (1960s) → Britpop (1990s) → Indie (2000s)
- Oasis 的 Parka = Mod 遗产
- Arctic Monkeys 的修身西装 = Mod 精神
- "每一代英国年轻人都会重新发现 Mod"

### 永恒的男装美学
- Mod 的修身西装 = 现代男装的基础
- Fred Perry = 从 Mod 到 Streetwear 的桥梁
- "Mod 从未真正消失——它只是变成了'好品味'"
