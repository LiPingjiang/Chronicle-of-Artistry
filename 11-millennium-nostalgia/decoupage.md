# Decoupage 拼贴装饰

> "Decoupage transforms the ordinary into the extraordinary — paper becomes precious." — Unknown

## 概述

拼贴装饰（Decoupage，法语"剪切"）是将剪切的纸片图案粘贴到物体表面，再涂覆多层清漆使其看起来如同绘画或镶嵌的装饰艺术。从17世纪威尼斯工匠模仿东方漆器，到维多利亚时代的淑女手工，从20世纪的现代拼贴到当代的混合媒介，拼贴装饰以其将平凡材料转化为精美艺术品的魔力延续了数百年。

拼贴装饰的哲学在于：美不需要从零创造——通过选择、剪切和重新组合，现有的图像可以获得全新的生命。

## 核心特征

| 特征 | 描述 |
|------|------|
| 剪切 | 将纸质图案剪切出来 |
| 粘贴 | 粘贴到物体表面 |
| 涂漆 | 多层清漆覆盖 |
| 平滑 | 最终表面光滑如绘画 |
| 装饰 | 强烈的装饰功能 |
| 转化 | 将普通物品转化为艺术品 |

## 视觉特征

- **光滑**：多层清漆的光滑表面
- **精细**：精细剪切的图案边缘
- **层次**：图案的层叠组合
- **色彩**：印刷品的丰富色彩
- **整合**：图案与物体的完美整合
- **装饰**：华丽的装饰效果

## 中国语境

拼贴装饰与中国的剪纸艺术有深厚的历史渊源——事实上，欧洲的拼贴装饰部分受到了中国剪纸和漆器的启发。中国传统的剪纸窗花、漆器装饰和贴金工艺都可视为拼贴装饰的东方形式。当代中国的手工艺爱好者中，拼贴装饰（特别是餐巾纸拼贴）是流行的创作形式。

## 与其他风格的关系

- **Collage** → 拼贴是拼贴装饰的现代艺术版本
- **Lacquerware** → 漆器是拼贴装饰的灵感来源
- **Paper Cutting** → 剪纸与拼贴装饰有技法相似
- **Mixed Media** → 混合媒介包含拼贴装饰
- **Folk Art** → 民间手工艺中的拼贴传统
- **Craft** → 拼贴装饰介于艺术和工艺之间
