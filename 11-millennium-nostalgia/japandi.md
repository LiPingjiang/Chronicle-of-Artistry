## 历史脉络

### 2018：两种极简的相遇

Japandi 在 2018 年左右作为一种室内设计趋势出现，是**日本美学和北欧设计的有意融合**：

| 维度 | 日本 (Wabi-Sabi) | 北欧 (Scandinavian) | Japandi |
|------|-----------------|--------------------|---------| 
| 哲学 | 接受不完美 | 功能即美 | 不完美的功能美 |
| 色调 | 更暗、更深 | 更亮、更白 | 温暖的中间地带 |
| 材质 | 竹、纸、石 | 松木、羊毛 | 天然木+手工 |
| 空间 | 极度留白 | 舒适留白 | 有温度的留白 |
| 物品 | 手工、不规则 | 工业设计、规整 | 手工+简洁 |

### 文化基因

| 来源 | 贡献 |
|------|------|
| 侘寂 (Wabi-Sabi) | 接受不完美、自然衰变之美 |
| Hygge | 丹麦式的温暖舒适感 |
| Muji | 日本极简生活方式 |
| IKEA | 北欧民主设计 |
| 茶道 | 空间的仪式感 |
| 包豪斯 | 形式追随功能 |

### 核心哲学

Japandi 的吸引力在于它找到了**极简主义的温暖版本**：
- 纯极简 = 冷、空、不舒服
- Japandi = 简但暖、少但有质感
- 每个物品都是被选择的、有意义的
- 空间是为了"存在"而非"展示"

## 视觉语法

### 色彩系统

```
主色：
  米白 (#F5F5DC) — 墙壁、织物
  浅灰 (#D3D3D3) — 石材、混凝土
  木色 (#DEB887) — 家具、地板
  黑色 (#000000) — 线条、框架
  抹茶绿 (#8B8B00 低饱和) — 植物、陶器

辅色：
  深棕 (#654321) — 深色木材
  靛蓝 (#4B0082 低饱和) — 日本传统色
  白色 (#FFFFFF) — 留白

质感：
  天然木材 — 未上漆、可见纹理
  手工陶器 — 不规则、有触感
  亚麻/棉 — 自然纤维
  石材 — 河石、混凝土
  纸 — 和纸、灯罩
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 家具 | 低矮木质家具、简洁线条、圆角 |
| 器物 | 手工陶碗、铸铁茶壶、木质托盘 |
| 植物 | 盆栽、枯枝、苔藓 |
| 照明 | 纸灯笼、蜡烛、自然光 |
| 纺织 | 亚麻窗帘、棉质坐垫、羊毛毯 |
| 空间 | 大量留白、低家具、自然光 |

## 与千禧怀旧的关系

### 对"极繁主义"的反动
- 2000s–2010s 的信息过载和视觉噪音
- Japandi 是对"太多"的回应——"少一点，好一点"
- 与 Normcore 共享"反过度设计"的精神

### 与 Muji/IKEA 的千禧记忆
- Muji 和 IKEA 是很多千禧一代的"第一次独立生活"记忆
- 第一个自己的公寓 = IKEA 家具 + Muji 收纳
- Japandi 是这种记忆的"升级版"
