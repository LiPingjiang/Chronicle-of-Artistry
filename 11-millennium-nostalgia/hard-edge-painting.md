# Hard-Edge Painting 硬边绘画

> "I want to eliminate all traces of the hand." — Ellsworth Kelly

## 概述

硬边绘画（Hard-Edge Painting）是1950-60年代在美国发展的抽象绘画流派，以清晰锐利的边缘、平坦的色面和几何形态为特征。与抽象表现主义的模糊笔触和情感表达不同，硬边绘画追求的是色彩和形态的纯粹、精确和客观。

术语由洛杉矶艺术评论家Jules Langsner在1959年创造。硬边绘画是从色域绘画向极简主义过渡的重要桥梁。

## 核心特征

| 特征 | 描述 |
|------|------|
| 锐利边缘 | 色块之间有清晰锐利的分界 |
| 平坦色面 | 均匀的、无笔触的色彩表面 |
| 几何形态 | 规则的几何形状——圆、方、三角 |
| 去个性 | 消除艺术家的手工痕迹 |
| 色彩关系 | 色彩之间的关系是核心主题 |
| 大尺幅 | 大画面增强色彩的视觉冲击 |

## 视觉特征

- **边缘**：刀切般锐利——用胶带遮蔽实现
- **表面**：完全平坦——没有笔触、没有肌理
- **色彩**：纯色、饱和、通常2-4种色彩
- **形态**：几何的——条纹、V形、同心圆、靶心
- **构图**：简洁的、对称或不对称的色块分割
- **画布**：有时使用异形画布（shaped canvas）

| 子类型 | 特征 |

| 色彩面板 | Kelly——单色面板的并置 |
| 靶心绘画 | Noland——同心圆的色彩 |

| 异形画布 | Stella——非矩形的画布形状 |
| 几何抽象 | Held——大型几何形态的空间 |

## 中国语境

硬边绘画在中国的直接影响有限，但其精确性和几何美学在中国当代设计和抽象艺术中有回响。中国传统的几何纹样（如窗棂图案）在精神上与硬边绘画的几何纯粹性相通。当代中国的一些抽象画家如丁乙的"十示"系列，在方法论上与硬边绘画的系统性和精确性有相似之处。

## 与其他风格的关系

- **Color Field Painting** → 色域绘画与硬边绘画是同时代的平行发展
- **Minimalism** → 极简主义继承了硬边的简约和去个性
- **Op Art** → 光效应艺术使用硬边的精确图案
- **Geometric Abstraction** → 几何抽象是硬边绘画的上位类别
- **Constructivism** → 构成主义的几何精确是硬边的先驱
- **Neo-Geo** → 新几何是硬边绘画的1980年代回响
