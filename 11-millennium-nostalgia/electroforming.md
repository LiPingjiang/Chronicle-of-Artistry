# Electroforming 电铸工艺

> "Electroforming is nature's patience accelerated — atom by atom, copper builds its own sculpture." — Unknown

## 概述

电铸工艺（Electroforming）是利用电解沉积原理，在模具或物体表面逐原子层地沉积金属，形成精确复制品或独立金属壳体的工艺。与电镀不同，电铸的金属层足够厚，可以脱离基底独立存在。这种技法可以复制任何形态的细节——从树叶的脉络到昆虫的翅膀，从微型雕塑到大型工业模具。当代珠宝艺术家利用电铸将有机物（真实的花朵、羽毛、昆虫）永久保存在金属中。

电铸的魅力在于：原子级的忠实——它不是模仿自然，而是让金属"穿上"自然的形态，每一个细胞、每一条纹理都被完美保存。

## 核心特征

| 特征 | 描述 |
|------|------|
| 电解 | 电解沉积金属 |
| 精确 | 原子级的精确复制 |
| 有机 | 可复制有机形态 |
| 厚层 | 足够厚的独立金属层 |
| 慢速 | 需要较长时间 |
| 多样 | 可用多种金属 |

## 视觉特征

- **有机**：自然有机的形态
- **细节**：极其精细的表面细节
- **金属**：铜或其他金属的质感
- **自然**：保存自然物的形态
- **薄壳**：中空的薄壳结构
- **纹理**：自然纹理的金属化

## 中国语境

电铸工艺在中国主要应用于工业领域——精密模具、唱片母版、印刷版等。当代中国的珠宝设计师和艺术家正在探索电铸的艺术可能性，特别是在将自然物（花朵、叶片、昆虫）金属化保存方面。中国的电铸珠宝市场正在快速增长，许多独立设计师品牌以电铸工艺为特色。
