# Marquetry 镶嵌细工

> "Marquetry is painting with wood — each veneer is a brushstroke of nature." — Unknown

## 概述

镶嵌细工（Marquetry）是将不同颜色和纹理的薄木片（或其他材料如象牙、金属、贝壳）拼接成图案和图像的装饰艺术。从文艺复兴时期意大利的intarsia到法国路易十四时代的华丽家具，从荷兰黄金时代的花卉静物到当代的木艺创作，镶嵌细工以其精密的工艺和自然材料的温暖之美成为最精致的装饰艺术之一。

镶嵌细工的魅力在于：它用自然的材料——木头的天然纹理和色彩——来"绘画"，每一件作品都是自然与人工的完美对话。

## 核心特征

| 特征 | 描述 |
|------|------|
| 薄片 | 使用极薄的木片或其他材料 |
| 拼接 | 精密地拼接成图案 |
| 自然色 | 利用材料的天然颜色 |
| 精密 | 极其精密的切割和拼合 |
| 平面 | 拼接后表面平滑 |
| 装饰 | 主要用于家具和建筑装饰 |

## 视觉特征

- **纹理**：木材天然纹理的运用
- **色彩**：不同木材的自然色差
- **精密**：极其精密的拼接缝隙
- **图案**：从几何到写实的图案
- **温暖**：木材的自然温暖感
- **光泽**：抛光后的柔和光泽

## 中国语境

镶嵌细工在中国有悠久的传统——中国的"百宝嵌"将玉石、珊瑚、象牙、螺钿等材料镶嵌在漆器或木器上，是中国传统工艺的瑰宝。苏州的红木家具镶嵌、扬州的漆器百宝嵌都是国家级非物质文化遗产。中国的镶嵌传统与欧洲的marquetry在精神上相通，但材料和美学各有特色。

## 与其他风格的关系

- **Mosaic** → 马赛克与镶嵌有拼接逻辑相似
- **Intarsia** → 意大利镶嵌是marquetry的前身
- **Woodwork** → 木工是镶嵌的基础技艺
- **Decorative Arts** → 装饰艺术包含镶嵌
- **Lacquerware** → 漆器镶嵌是东方传统
- **Furniture Design** → 家具设计是镶嵌的主要载体
