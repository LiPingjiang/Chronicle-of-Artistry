# Lacquerware 漆器 | 漆芸 / Sơn mài

> **"百道漆，百道磨——东亚工匠用树液和时间凝固了永恒的光泽。"**

## 概述

漆器（Lacquerware / 漆芸 うるしげい / Sơn mài）是东亚传统的装饰工艺，使用漆树（Toxicodendron vernicifluum）的天然树液涂覆在木、竹、布胎等基底上，经过数十道涂刷、干燥和打磨，形成坚硬、防水、光泽如镜的表面。中国是漆器的发源地（7000年前河姆渡文化），日本将其发展到极致（蒔絵 Maki-e），越南（Sơn mài）和缅甸（Yun）也有独立的漆器传统。漆器是东亚文明最具代表性的工艺之一——英语中"Japan"一词曾是漆器的代名词。

## 主要传统

| 地区 | 名称 | 特征 |
|------|------|------|
| 中国 | 漆器 | 雕漆、螺钿、描金 |
| 日本 | 漆芸/蒔絵 | 金粉蒔絵、螺钿 |
| 越南 | Sơn mài | 蛋壳镶嵌、现代漆画 |
| 缅甸 | Yun | 刻花填色 |
| 韩国 | 옻칠 | 螺钿（자개） |
| 琉球 | 琉球漆器 | 堆锦 |

## 核心技法

| 技法 | 特征 |
|------|------|
| 蒔絵 Maki-e | 撒金粉/银粉 |
| 螺钿 Raden | 贝壳镶嵌 |
| 雕漆 | 多层漆雕刻 |
| 描金 | 金粉描绘 |
| 变涂 | 随机纹理 |
| 蛋壳镶嵌 | 越南特色 |

## 核心特征

- **天然漆液**：漆树树液的天然聚合物
- **多层涂刷**：数十至上百道漆层
- **极高光泽**：打磨后如镜面
- **极耐久**：防水、防腐、耐酸碱
- **黑红为主**：经典的黑漆和朱漆
- **金银装饰**：蒔絵和描金

## 视觉特征

- 深邃的黑色或朱红色光泽
- 金粉蒔絵的华丽
- 螺钿的彩虹光泽
- 极致光滑的表面
- 东方的含蓄奢华
- 时间沉淀的深度
