# Kintsugi 金缮 | 金継ぎ

> **"破碎是新生的开始——日本人用金粉修补裂痕，让伤疤成为最美的装饰。"**

## 概述

金缮（Kintsugi / 金継ぎ きんつぎ）是日本传统的陶瓷修复艺术，用漆（urushi）混合金粉、银粉或铂金粉修补破碎的陶瓷器物，不隐藏裂痕反而用贵金属突出它。这种修复哲学源自日本的侘寂（wabi-sabi）美学——接受不完美、欣赏无常、在破碎中发现美。金缮起源于15世纪室町时代，传说是将军足利义政将破碎的茶碗送去修复后发展出的技法。金缮不仅是修复技术，更是一种生命哲学——每一道金色裂痕都是器物独特历史的见证。

## 核心哲学

| 概念 | 含义 |
|------|------|
| 侘寂 Wabi-sabi | 接受不完美之美 |
| 無常 Mujō | 万物无常 |
| 物の哀れ Mono no aware | 对事物的感伤 |
| 見立て Mitate | 重新发现价值 |

## 核心特征

- **不隐藏**：突出而非隐藏裂痕
- **贵金属**：用金/银/铂金粉修补
- **漆基底**：天然漆作为粘合剂
- **独一无二**：每件修复品都是唯一的
- **哲学性**：体现侘寂美学
- **功能性**：修复后可继续使用

## 修复类型

| 类型 | 日语 | 特征 |
|------|------|------|
| 裂纹修复 | ひび | 修补裂缝 |
| 碎片拼接 | 欠け | 拼接碎片 |
| 替代填充 | 呼び継ぎ | 用其他陶片替代缺失部分 |

## 视觉特征

- 金色裂纹在陶瓷上的闪耀
- 不规则的有机线条
- 金色与陶瓷色的对比
- 每一件的独特裂纹图案
- 残缺中的完美
- 时间和故事的可见痕迹

## 与其他风格的关系

| 风格 | 关系 |
|------|------|
| 侘寂 Wabi-sabi | 金缮的哲学基础 |
| 漆器 Lacquerware | 共享漆工艺传统 |
| 民藝 Mingei | 共享日本工艺美学 |
| 当代艺术 | 金缮哲学的全球影响 |
| 可持续设计 | 修复而非丢弃的理念 |
