# Synthwave 合成波

> "The future we were promised in the 1980s." — Synthwave community

## 概述

合成波（Synthwave）是2000年代末兴起的复古未来主义美学运动，以1980年代的合成器音乐、霓虹灯光和科幻电影为灵感。它不是对80年代的忠实复制，而是对那个时代"未来想象"的浪漫化重构。

合成波的视觉语言已经超越了音乐，成为一种完整的美学体系——从专辑封面到游戏界面到城市摄影，霓虹网格和落日渐变无处不在。

## 核心特征

| 特征 | 描述 |
|------|------|
| 复古未来 | 80年代想象中的未来 |
| 霓虹色彩 | 粉紫、电蓝、热粉的霓虹光 |
| 网格地面 | 透视网格延伸至地平线 |
| 落日渐变 | 紫-粉-橙的标志性渐变天空 |
| 合成器美学 | 电子音乐文化的视觉化 |
| 赛博城市 | 霓虹灯照亮的未来都市 |

## 视觉特征

- **色彩**：霓虹粉、电紫、青蓝、热橙
- **光效**：发光的、辉光的霓虹效果
- **网格**：透视消失的地面网格线
- **天空**：紫到粉到橙的渐变落日
- **元素**：棕榈树、跑车、VHS噪点
- **字体**：Chrome效果的80年代字体
