# Glitch Art 故障艺术

![Glitch Art 概念图](../assets/artworks/glitch-art/glitch-art-concept-01.png)

> **"像素错位、数据损坏、信号中断——当机器'犯错'时产生的意外之美。"**

## 概述

| 维度 | 描述 |
|------|------|
| 时期 | 2000s–至今 |
| 别名 | Glitch, Databending, Data Moshing, 故障美学 |
| 核心色彩 | RGB分离色（红/青）、霓虹、黑色背景+亮色错位 |
| 关键元素 | 像素错位、色彩通道分离、数据损坏、扫描线、压缩伪影 |
| 代表人物 | Rosa Menkman, Evan Meaney, Nick Briz, Sabato Visconti |
| 关联风格 | Vaporwave, Cyberpunk, Net Art, Generative Art, Noise |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 1960s | Nam June Paik——早期视频干扰实验 |
| 1978 | "Digital TV Dinner"——最早的数字故障艺术 |
| 2000s | Databending 技术——故意损坏文件 |
| 2009 | Rosa Menkman "Vernacular of File Formats" |
| 2010s | Glitch 成为主流设计趋势 |
| 2015 | Instagram 滤镜中的 Glitch 效果 |
| 2020s | AI + Glitch 的新可能性 |

### 核心哲学

故障艺术的精神是**"错误不是失败——是系统在说它自己的语言"**：
- 错误 = 发现（"bug不是问题——是机会"）
- 损坏 = 创造（"当你打破规则——新的美出现"）
- 机器 = 合作者（"让机器犯错——然后倾听"）
- 不完美 = 真实（"完美的图像是谎言——故障是真相"）
- "Glitch Art 是数字时代的侘寂(wabi-sabi)"

## 视觉语法

### 色彩系统

```
主色：
  RGB红 (#FF0000) — 通道分离
  RGB绿 (#00FF00) — 通道分离
  RGB蓝 (#0000FF) — 通道分离
  青色 (#00FFFF) — 互补错位

辅色：
  黑色 (#000000) — 数据缺失
  白色 (#FFFFFF) — 过曝
  霓虹粉 (#FF00FF) — 信号干扰

规则：
  - RGB通道分离/错位
  - 压缩伪影的色块
  - 扫描线的水平条纹
  - 数据损坏的随机色彩

质感：
  像素 — 放大、可见
  条纹 — 扫描线、撕裂
  马赛克 — 压缩伪影
  噪点 — 信号干扰
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 效果 | 像素排序、数据弯曲、通道分离、压缩伪影 |
| 技法 | Databending、Datamoshing、Hex编辑、信号干扰 |
| 工具 | Audacity(音频打开图片)、Hex编辑器、Processing |
| 来源 | JPEG伪影、视频压缩、文件损坏、信号中断 |
| 构图 | 原始图像+故障叠加、完全抽象化 |
| 态度 | 实验、破坏、发现、反完美、数字原生 |

## 与千禧怀旧的关系
