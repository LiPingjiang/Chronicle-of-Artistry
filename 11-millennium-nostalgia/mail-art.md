# Mail Art 邮件艺术

> "The mailbox is my gallery." — Ray Johnson

## 概述

邮件艺术（Mail Art / Postal Art / Correspondence Art）是1960年代兴起的艺术网络，艺术家通过邮政系统交换艺术作品——明信片、拼贴、橡皮章、复印件、小型物品——创造了一个去中心化的、全球性的、反体制的艺术交流网络。

邮件艺术的核心不是单件作品的质量，而是交流行为本身——发送、接收、回应、转发构成了一个活的、不断生长的艺术系统。它是互联网时代社交网络的模拟时代先驱。

## 核心特征

| 特征 | 描述 |
|------|------|
| 邮政媒介 | 邮政系统是作品的传输和展示空间 |
| 网络性 | 全球艺术家网络的去中心化交流 |
| 反体制 | 绕过画廊、博物馆、市场 |
| 民主性 | 任何人都可以参与，无门槛 |
| 小尺度 | 信封大小的微型艺术 |
| 交互性 | 发送-接收-回应的对话循环 |

## 视觉特征

- **尺度**：信封、明信片、小包裹大小
- **材料**：纸、邮票、橡皮章、贴纸、复印件
- **技法**：拼贴、手绘、打字机文字、橡皮章
- **元素**：邮戳、地址、邮票成为作品的一部分
- **美学**：DIY、低保真、手工感
- **积累**：大量作品的档案和收藏

## 中国语境

邮件艺术在中国有独特的历史。1980年代中国的"信札文化"和文学通信网络与邮件艺术有精神上的相似。当代中国的"慢邮"文化（写信给未来的自己）、手账文化、以及独立出版/zine文化都延续了邮件艺术的手工交流精神。在数字化高度发达的中国，邮件艺术作为一种"反速度"的实践有特殊的意义。

## 争议与遗产

- **争议**：大量邮件艺术质量参差不齐——民主化是否意味着平庸化？
- **Johnson之谜**：Ray Johnson的死亡本身被视为他最后的"邮件艺术"
- **数字时代**：邮件艺术在互联网时代是否已经过时？
- **遗产**：为网络艺术、社交媒体、协作创作奠定了去中心化交流的模式
- **当代回响**：zine文化、独立出版、手写信复兴、慢邮运动

## 与其他风格的关系

- **Fluxus** → 激浪派大量使用邮件作为交流和分发媒介
- **Dadaism** → 达达的拼贴和反体制精神是邮件艺术的先驱
- **Conceptual Art** → 概念艺术的去物质化为邮件艺术提供理论支持
- **Net Art** → 网络艺术是邮件艺术的数字时代继承者
- **Zine Culture** → Zine文化共享DIY和自出版精神
- **Situationism** → 情境主义的反体制网络与邮件艺术相通
