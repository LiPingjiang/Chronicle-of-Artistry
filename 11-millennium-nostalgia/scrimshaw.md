# Scrimshaw 鲸骨雕刻 | Scrimshaw

> **"大海上的寂寞艺术——水手用针尖在鲸牙上刻下思乡的画。"**

## 概述

鲸骨雕刻（Scrimshaw）是18-19世纪捕鲸时代水手在鲸牙、鲸骨或海象牙上用针或刀刻画图案，再用墨水或烟灰填色的民间艺术。这种艺术诞生于漫长的捕鲸航行中（通常持续3-5年），水手们在无聊的等待时间里用手边的材料创作。Scrimshaw是美国最早的本土民间艺术形式之一，主要流行于新英格兰的捕鲸港口（南塔克特、新贝德福德）。题材包括船只、鲸鱼、家人肖像、爱国图案和异域风景。

## 核心特征

- **鲸牙/骨材**：在鲸牙或骨头上创作
- **针刻**：用针或刀尖刻画线条
- **填色**：用墨水或烟灰填入刻痕
- **水手创作**：非专业艺术家的民间艺术
- **航海题材**：船只、鲸鱼、港口
- **思乡情感**：家人、爱人、故乡

## 常见题材

| 题材 | 特征 |
|------|------|
| 捕鲸船 | 帆船的精细描绘 |
| 鲸鱼 | 抹香鲸、座头鲸 |
| 女性肖像 | 妻子或爱人 |
| 爱国图案 | 鹰、国旗、自由女神 |
| 异域风景 | 太平洋岛屿 |
| 花卉装饰 | 维多利亚风格花卉 |

## 视觉特征

- 象牙白底上的黑色线条
- 精细的针刻线条
- 航海主题的叙事性
- 民间艺术的质朴感
- 弧形牙面的独特构图
- 黑白对比的版画效果
