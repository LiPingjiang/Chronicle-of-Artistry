# Cottagecore 田园核

> "A romanticized interpretation of rural life." — Cottagecore aesthetic

## 概述

田园核（Cottagecore）是2018年前后在社交媒体上兴起的美学运动，浪漫化乡村生活、手工艺、烘焙、园艺和与自然的亲密关系。它是对数字时代焦虑和城市生活压力的一种诗意逃避。

田园核不是真正的农村生活，而是对"简单生活"的理想化想象——永远是春天的花园、刚出炉的面包、亚麻裙子和蜜蜂嗡嗡的午后。

## 核心特征

| 特征 | 描述 |
|------|------|
| 乡村浪漫 | 理想化的田园生活 |
| 手工艺 | 烘焙、刺绣、陶艺、园艺 |
| 自然亲密 | 花卉、蘑菇、蜜蜂、小动物 |
| 怀旧感 | 维多利亚时代和爱德华时代的回响 |
| 慢生活 | 反对快节奏和数字焦虑 |
| 自给自足 | 自己种植、制作、修补 |

## 视觉特征

- **色调**：柔和的暖色——奶油白、蜜色、淡粉、鼠尾草绿
- **元素**：野花、蘑菇、蜜蜂、兔子、茶壶
- **材质**：亚麻、棉布、陶器、木头、柳条
- **光线**：金色的午后阳光、晨雾
- **场景**：花园、厨房、森林小径、石墙小屋
- **风格**：手绘插画、水彩、压花
