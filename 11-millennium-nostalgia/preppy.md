## 历史脉络

### 从常春藤到全球时尚

| 年份 | 事件 |
|------|------|
| 1950s | 常春藤联盟学生的穿着成为风格模板 |
| 1967 | Ralph Lauren 创立——Preppy 商业化 |
| 1980 | 《The Official Preppy Handbook》出版 |
| 1980s | Preppy 成为美国主流时尚 |
| 1990s | 被 Grunge 和 Hip-Hop 取代 |
| 2010s | "New Preppy" 复兴 |
| 2022 | 与 Old Money 美学融合再次流行 |

### 核心哲学

Preppy 的精神是**"看起来像你不需要努力——但每个细节都经过计算"**：
- 品质 > 潮流（"买好的，用一辈子"）
- 传统 = 品味（"我家三代都穿这个牌子"）
- 运动 = 生活方式（网球、帆船、马球）
- "我不追随时尚——时尚追随我"
- 低调的特权感

## 视觉语法

### 色彩系统

```
主色：
  海军蓝 (#000080) — 基础、权威
  白色 (#FFFFFF) — 干净、经典
  红色 (#FF0000) — 点缀、活力
  卡其色 (#C3B091) — 休闲、经典
  绿色 (#006400) — 常春藤、乡村

辅色：
  粉色 (#FFC0CB) — 男士也可以穿粉色
  黄色 (#FFD700) — 夏天
  条纹组合 — 蓝白、红白

规则：
  - 经典配色永远不会错
  - 海军蓝+白色 = 万能
  - 不超过3种颜色
  - 图案：格纹、条纹、纯色
  - 永远整洁

质感：
  棉 — Polo衫、牛津衬衫
  羊毛 — 毛衣、西装
  帆布 — 帆船鞋、包
  皮革 — 乐福鞋、腰带
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 上装 | Polo衫、牛津衬衫、V领毛衣、西装外套 |
| 下装 | 卡其裤、百慕大短裤、格纹裙 |
| 鞋 | 帆船鞋、乐福鞋、白色网球鞋 |
| 配饰 | 珍珠项链、丝巾、皮带、手表 |
| 品牌 | Ralph Lauren、Brooks Brothers、J.Crew、Lacoste |
| 场景 | 校园、帆船俱乐部、高尔夫球场、乡村别墅 |

## 与千禧怀旧的关系

### Old Money 的"前世"
- Preppy = Old Money 的穿衣指南
- 2022 Old Money 热潮 = Preppy 的重新包装
- TikTok "Old Money aesthetic" = Preppy + 极简
- 从"特权"到"品味"的叙事转变

### Gossip Girl 效应
- 《Gossip Girl》(2007) = Preppy 的电视广告
- Blair Waldorf = 当代 Preppy 偶像
- 头箍、格纹裙、膝袜 = Preppy 标配
- 千禧一代的 Preppy 启蒙
