# Shibori 日本绞染 | 絞り染め

> **"捆扎、折叠、扭曲——在控制与偶然之间，靛蓝留下了风暴的痕迹。"**

## 概述

绞染（絞り染め / Shibori）是日本最著名的古老靛蓝染色技艺，通过捆扎、缝合、折叠、扭曲、夹压等物理防染手法，在布料上创造出独特的图案。"Shibori"源自日语动词"絞る"（shiboru），意为"挤压、拧绞"。这一技艺在江户时代（1603–1868）达到鼎盛，当时下层阶级被禁止穿着丝绸，于是这种物美价廉的印染技术在棉布上大放异彩。如今Shibori已成为全球纺织艺术和时装设计中最受欢迎的传统技法之一。

## 六大技法

| 技法 | 日文 | 方法 | 效果 |
|------|------|------|------|
| �的绞 | Kanoko | 用线捆扎布料小块 | 类似鹿斑的小圆点 |
| 三浦绞 | Miura | 用钩针挑起布料并缠线 | 不规则的水纹效果 |
| 蜘蛛绞 | Kumo | 从中心向外放射状捆扎 | 蜘蛛网状放射图案 |
| �的绞 | Nui | 沿线迹缝合后抽紧 | 精确的线条和形状 |
| 岚绞 | Arashi | 布料缠绕在柱子上对角线捆扎 | 风暴般的斜纹 |
| 板缔 | Itajime | 布料折叠后用板夹压 | 几何重复图案 |

## 核心特征

- **靛蓝为主**：传统使用天然靛蓝染料（藍）
- **物理防染**：不使用蜡，纯粹依靠物理手段
- **偶然之美**：每件作品都是独一无二的
- **白与蓝的对话**：防染区域保持白色
- **手工痕迹**：不完美即是美
- **可逆性**：解开捆扎后图案才显现

## 历史

| 时期 | 发展 |
|------|------|
| 奈良时代 (710–794) | 从中国传入基本扎染技术 |
| 室町时代 (1336–1573) | 技法多样化发展 |
| 江户时代 (1603–1868) | 黄金时代，名古屋有明绞成为名产 |
| 明治以后 | 工业化冲击，手工绞染衰落 |
| 当代 | 全球纺织艺术复兴，时装设计师广泛采用 |

## 视觉特征

- 靛蓝与白色的经典对比
- 有机的、不规则的图案边缘
- 布料的立体褶皱质感
- 从精细点状到大面积渐变
- 对称与不对称的微妙平衡
- 水墨般的渗透和晕染效果

## 与其他风格的关系

| 风格 | 关系 |
|------|------|
| 印尼蜡染 Batik | 共享防染原理，不同技法（蜡 vs 物理） |
| 非洲 Adire | 共享靛蓝染色和防染技术 |
| 中国扎染（大理） | 同源技术，白族扎染传统 |
| 印度 Bandhani | 共享捆扎防染技术 |
| 当代时装 | Issey Miyake 等将绞染带入高级时装 |
| Wabi-sabi | 共享对不完美和偶然性的欣赏 |
