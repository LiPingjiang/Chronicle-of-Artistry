## 历史脉络

| 年份 | 事件 |
|------|------|
| 古代 | 沙漠在各文化中的精神意义 |
| 1920s | Georgia O'Keeffe 的新墨西哥沙漠画 |
| 1960s | 公路电影中的沙漠美学 |
| 2015 | Joshua Tree 成为 Instagram 圣地 |
| 2020 | Desertcore 作为独立美学兴起 |

### 核心哲学

Desertcore 的精神是**"在空旷中找到自我——少即是壮美"**：
- 空旷 = 自由（没有边界）
- 极端 = 力量（生存本身就是胜利）
- 日落 = 每天的奇迹
- "沙漠教会你什么是真正重要的"

### 色彩系统

```
主色：
  赭石 (#CC7722) — 砂岩、大地
  沙色 (#C2B280) — 沙丘
  铁锈红 (#B7410E) — 红岩
  天蓝 (#87CEEB) — 无云的天空
  米白 (#F5F5DC) — 骨头、干燥

辅色：
  紫色 (#4B0082) — 日落
  橙色 (#FF8C00) — 黄昏
  绿色 (#556B2F) — 仙人掌

质感：
  粗糙 — 砂岩、干裂
  光滑 — 沙丘曲线
  多刺 — 仙人掌
  干燥 — 一切都是干的
```
