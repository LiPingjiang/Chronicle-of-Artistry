## 历史脉络

### 从洛可可到 TikTok

| 时代 | 表现 |
|------|------|
| 1700s | 洛可可——蝴蝶结、粉色、过度装饰 |
| 1950s | 好莱坞黄金时代——Marilyn Monroe |
| 2012 | Tumblr "nymphet" 美学 |
| 2020 | Lana Del Rey 视觉风格 |
| 2022 | TikTok #Coquette 爆发 |
| 2024 | 蝴蝶结成为年度配饰 |

### 它代表什么？

| 元素 | 含义 |
|------|------|
| 蝴蝶结 | 精致、礼物、"我值得被宠爱" |
| 粉色 | 女性化、甜美、不道歉 |
| 蕾丝 | 精致、脆弱中的力量 |
| 珍珠 | 经典、优雅、传承 |
| 心形 | 爱、浪漫、自我宠爱 |

### 核心哲学

Coquette 的精神是**"女性化不是软弱——是一种选择和力量"**：
- "我选择可爱"不等于"我是弱者"
- 蝴蝶结是盔甲
- 精致是一种自我关怀
- 对"girl boss"/"strong woman"叙事的温柔反叛
- "我可以又漂亮又聪明"

## 视觉语法

### 色彩系统

```
主色：
  粉色 (#FFB6C1) — 核心色
  白色 (#FFFFFF) — 纯洁、蕾丝
  红色 (#FF0000) — 唇膏、玫瑰
  奶油 (#FFFDD0) — 柔和、温暖

辅色：
  黑色 (#000000) — 对比、"暗黑coquette"
  金色 (#FFD700) — 珠宝、装饰
  淡蓝 (#ADD8E6) — 变体

规则：
  - 粉色为主
  - 高明度、低饱和度
  - 黑色只用于对比或"暗黑版"
  - 大量白色空间
  - 柔和、梦幻

质感：
  蕾丝 — 精致、透明
  丝绸 — 光泽、流动
  缎面 — 蝴蝶结、丝带
  珍珠 — 圆润、光泽
  天鹅绒 — 奢华、触感
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 配饰 | 蝴蝶结（头发/颈部/腰部）、珍珠、丝带 |
| 服装 | 蕾丝上衣、迷你裙、吊带裙、芭蕾鞋 |
| 妆容 | 粉色腮红、樱桃唇、假睫毛 |
| 物品 | 心形镜子、香水瓶、玫瑰花 |
| 图案 | 心形、蝴蝶结、碎花、波点 |
| 氛围 | 粉色房间、梳妆台、花束 |

## 与千禧怀旧的关系

### Y2K Coquette 的回归
- 2000s 的 Paris Hilton = 原版 Coquette 精神
- 粉色翻盖手机、Juicy Couture = Y2K Coquette
- 2022 版 = 更精致、更"高级"
- 从"trashy pink"到"elegant pink"的进化

### 与 Balletcore 的交叉
- 两者都强调"精致女性化"
- Balletcore = 运动中的优雅
- Coquette = 装饰中的优雅
- 共同点：粉色、丝带、柔美
