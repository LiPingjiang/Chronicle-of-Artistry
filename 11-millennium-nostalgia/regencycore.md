## 历史脉络

### 从 Jane Austen 到 Netflix

| 年份 | 事件 |
|------|------|
| 1813 | Jane Austen《傲慢与偏见》 |
| 1995 | BBC《傲慢与偏见》Colin Firth 版 |
| 2005 | 电影版 Keira Knightley |
| 2020 | Netflix《Bridgerton》第一季 |
| 2021–至今 | Regencycore 成为主流时尚趋势 |

### 为什么是现在？

| 驱动力 | 解释 |
|--------|------|
| 《Bridgerton》 | Netflix 最成功的剧集之一 |
| 逃避主义 | 疫情期间渴望"另一个世界" |
| 浪漫主义 | 对"约会App"时代的反叛 |
| 女性赋权 | 摄政时代女性的"有限自由"中的智慧 |
| 美学吸引力 | 帝国腰线确实很美 |

### 核心哲学

Regencycore 的精神是**"优雅是一种态度，不是一个时代"**：
- 礼仪不是束缚——是一种游戏
- 浪漫不需要"直接"——暗示更有力量
- 美不需要暴露——遮盖也是性感
- 社交是一门艺术

## 视觉语法

### 色彩系统

```
主色：
  粉蓝 (#B0E0E6) — 天空、纯真
  薰衣草 (#E6E6FA) — 贵族、浪漫
  奶油白 (#FFFDD0) — 蕾丝、纯洁
  金色 (#FFD700) — 装饰、贵族
  淡粉 (#FFB6C1) — 少女、花朵

辅色：
  翠绿 (#2E8B57) — 花园
  深蓝 (#191970) — 男装
  酒红 (#722F37) — 戏剧

规则：
  - 柔和、低饱和
  - 粉彩色调
  - 金色作为装饰
  - 白色大面积
  - 自然光/烛光色温

质感：
  丝绸 — 光泽、流动
  蕾丝 — 精致、透明
  珍珠 — 圆润、光泽
  天鹅绒 — 深色、奢华
  纸张 — 信笺、手写
```

## 与千禧怀旧的关系

### 对"快节奏"的反叛
- 约会App太快 → 渴望"慢慢来"的浪漫
- 社交媒体太直接 → 渴望"暗示"和"礼仪"
- 现代生活太粗糙 → 渴望"优雅"和"仪式感"
- 这是千禧一代对"效率至上"的浪漫反叛

### 与 Coquette 的交叉
- 两者都热爱蝴蝶结、粉色、女性气质
- Regencycore = 历史版的女性优雅
- Coquette = 当代版的女性魅力
- 共同精神：女性气质是力量
