## 历史脉络

### 从 Nancy Meyers 电影到 TikTok

| 年份 | 事件 |
|------|------|
| 2003 | 《Something's Gotta Give》— 原型电影 |
| 2006 | 《It's Complicated》— Meryl Streep 的白色厨房 |
| 2022 | TikTok 用户 Lex Nicoleta 命名 "Coastal Grandmother" |
| 2022 | 成为当年最热门的时尚趋势之一 |
| 2023–至今 | 从时尚扩展到生活方式 |

### 它代表什么？

| 元素 | 含义 |
|------|------|
| 亚麻 | 自然、舒适、不追求完美 |
| 海边 | 平静、退休梦想、自由 |
| 白色厨房 | 富足、从容、享受生活 |
| Ina Garten | "如果你没有自制的，买的也行" |
| 变老 | 优雅地变老是一种选择 |

### 核心哲学

Coastal Grandmother 的精神是**"我已经不需要证明什么了"**：
- 舒适 > 时髦
- 品质 > 潮流
- 慢生活 > 忙碌
- 享受 > 展示
- "我为自己穿衣，不为别人"

## 视觉语法

### 色彩系统

```
主色：
  沙色 (#C2B280) — 海滩、自然
  白色 (#FFFFFF) — 干净、从容
  海军蓝 (#000080) — 经典、海洋
  淡蓝 (#ADD8E6) — 天空、海水
  亚麻色 (#FAF0E6) — 面料、温暖

辅色：
  橄榄绿 (#808000) — 花园
  珊瑚 (#FF7F50) — 日落
  灰色 (#808080) — 石头

规则：
  - 自然色调
  - 低饱和度
  - 温暖但不热烈
  - 海洋色系
  - 大量白色和中性色

质感：
  亚麻 — 自然皱褶
  棉 — 柔软、透气
  草编 — 手工、自然
  木材 — 漂白木、浮木
  陶瓷 — 手工、不完美
```

### 标志性元素

| 类别 | 元素 |
|------|------|
| 服装 | 亚麻衬衫、白色裤子、条纹、草帽 |
| 配饰 | 草编手提袋、珍珠、围巾 |
| 空间 | 白色厨房、海景、书架、花瓶 |
| 活动 | 海边散步、做饭、读书、园艺 |
| 食物 | 新鲜海鲜、沙拉、白葡萄酒 |
| 文化 | Nancy Meyers 电影、Ina Garten |

## 与千禧怀旧的关系

### "我想成为的老年人"
- 千禧一代开始思考"变老"
- 不想成为"努力年轻"的老人
- 想成为"从容优雅"的老人
- Coastal Grandmother = 理想的退休生活

### 与 Quiet Luxury 的交叉
- 两者都不追求logo和炫耀
- 品质 > 品牌
- 舒适 > 时髦
- "看起来贵但不张扬"
