# Hudson River School 哈德逊河画派

> "The wilderness is yet a fitting place to speak of God." — Thomas Cole

## 概述

哈德逊河画派（Hudson River School，约1825–1875）是美国第一个本土艺术运动，以描绘纽约州哈德逊河谷、卡茨基尔山脉和美国西部荒野的壮丽风景闻名。画家们将美国自然视为神圣的存在，用精细的光线和宏大的构图表达对新大陆的敬畏。

## 核心特征

| 特征 | 描述 |
|------|------|
| 壮丽荒野 | 美国未开发自然的宏大景观 |
| 神圣光线 | Luminism——光线作为神性的象征 |
| 精细写实 | 极其细致的自然细节 |
| 宏大尺幅 | 巨型画布表达自然的崇高 |
| 天命昭昭 | 美国扩张精神的视觉表达 |
| 季节变化 | 秋色、暴风雨、日出日落 |

## 与其他风格的关系

- **Romanticism** → 美国浪漫主义的视觉表达
- **Barbizon School** → 法国的平行运动
- **Luminism** → 画派内部的光线主义分支
- **Constable / Turner** → 受英国风景画传统影响
