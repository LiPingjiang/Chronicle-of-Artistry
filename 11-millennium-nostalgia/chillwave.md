# Chillwave 寒潮

![Chillwave 概念图](../assets/artworks/chillwave/chillwave-concept-01.png)

> **"Lo-fi合成器、VHS噪点、夏日怀旧——用卧室电脑重建一个从未存在的80年代。"**

## 概述

| 维度 | 描述 |
|------|------|

| 别名 | Chillwave, Glo-fi, Hypnagogic Pop |

## 历史脉络

| 年份 | 事件 |
|------|------|
| 2008 | Neon Indian, Washed Out 开始在 MySpace 发布音乐 |
| 2009 | "Chillwave" 一词被博客命名 |
| 2010 | Washed Out "Within and Without" / Toro y Moi "Causers of This" |
| 2011 | 全盛期——Pitchfork、博客圈 |
| 2012 | 开始衰落——但影响延续 |
| 2013 | 融入更广泛的 Indie Electronic |

### 核心哲学

Chillwave 的精神是**"用Lo-fi技术重建一个从未存在的完美夏天"**：
- 怀旧 = 核心（但怀念的是"想象中的过去"）
- Lo-fi = 美学选择（"完美是无聊的"）
- 夏天 = 永恒（"永远是下午4点的阳光"）
- 卧室 = 工作室（"一台笔记本就够了"）
- "我们怀念的不是真正的80年代——是我们想象中的80年代"

## 视觉语法

### 色彩系统

```
主色：
  粉紫 (#DDA0DD) — 日落、梦幻
  日落橙 (#FF7F50) — 温暖、夏天
  柔和蓝 (#87CEEB) — 天空、海洋
  褪色黄 (#F0E68C) — 阳光、老照片

辅色：
  薰衣草 (#E6E6FA) — 柔和
  珊瑚 (#FF6B6B) — 温暖
  薄荷 (#98FB98) — 清新

规则：
  - 褪色/过曝
  - VHS噪点/扫描线
  - 柔焦/模糊
  - 暖色调为主
  - 日落/海滩/泳池意象

质感：
  VHS — 扫描线、色彩偏移
  磁带 — 嘶嘶声的视觉化
  胶片 — 颗粒、褪色
  水 — 泳池、海洋
```

## 与千禧怀旧的关系

### Vaporwave 的"温暖版"
- Chillwave (2009) = 怀旧+温暖+夏天
- Vaporwave (2011) = 怀旧+讽刺+消费主义
- 两者共享"80s怀旧""Lo-fi""互联网"
- "Chillwave 怀念夏天，Vaporwave 怀念商场"

### Instagram 美学的音乐版
- Chillwave 的视觉 = Instagram 早期滤镜的音乐对应
- 褪色/暖色/怀旧 = 2010-2013 的视觉语言
- "Chillwave 是一种'感觉'——不只是音乐"
