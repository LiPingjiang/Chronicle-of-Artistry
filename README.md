# 浮光艺志 | Chronicle of Artistry

> *浮光掠影，艺志千年。*

一部以时间为经、风格为纬的艺术美学图鉴。从洞穴壁画到 AI 生成艺术，从文艺复兴到蒸汽波，每一种视觉语言都是人类精神的一面镜子。

## ✨ 千禧怀旧美学 — 重点章节

这是本书目前最完整的章节，收录了 **35 种**互联网时代的视觉风格。

## 📖 如何阅读

**按时间线**：从上到下，跟随人类视觉表达的演变脉络。

**按兴趣跳转**：点击任何风格名称直接进入详情页，每篇文档底部都有返回链接和相关风格推荐。
