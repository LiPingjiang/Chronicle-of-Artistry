# 浮光艺志 | Chronicle of Artistry

> *浮光掠影，艺志千年。*

一部以时间为经、风格为纬的艺术美学图鉴。从洞穴壁画到 AI 生成艺术，从文艺复兴到蒸汽波，每一种视觉语言都是人类精神的一面镜子。

## ✨ 千禧怀旧美学 — 重点章节

> 20世纪末至21世纪初的怀旧浪潮——当互联网一代尚未老去就开始追忆过去。

这是本书目前最完整的章节，收录了 **76 种**互联网时代的视觉风格。
